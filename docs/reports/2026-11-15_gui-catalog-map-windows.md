## Причины и изменения

Принятый Proton GUI читал endpoint_country, но gui-light backend этого поля не выдавал.
Строка Sidebar показывала только страну вместо имени. Карта без подтверждённой страны
не имела фокуса; её пульсация дополнительно ограничивалась состоянием CONNECTING.

Перенесён локальный GeoIP-индекс IPv4/IPv6 и разбор адресов применённого Xray/sing-box
из принятого GUI_BASE. Backend возвращает страны в API строк и активного выхода пула.
Inventory получает страну IP узла для строк вне применённого конфига. Имена и флаги подписок
не используются как географическое доказательство. Неопределённые/неоднозначные адреса
остаются неизвестными. Новых DNS/HTTP-запросов из GUI или обработчика GET нет. Адреса и
ключи не добавляются в публичный API. Отдельная мировая база — только для интерфейса.

В строке теперь имя и страна на двух строках; Мбит/с и Рейтинг — отдельные колонки.
Нажатие заголовка сортирует, повтор меняет направление. Скорость и рейтинг числовые,
пропуски внизу при обоих направлениях. Имя сортируется по алфавиту. Сохраняются выбор,
прокрутка и правая карточка; сортировка не вызывает команды VPN. Сортировка перенесена
из отдельного dropdown в заголовки. Начальная ширина списка 360 вместо 280, остаётся
изменяемой штатным разделителем, в узком окне доступно раскрытие поверх карты.

Пульсация работает и в CONNECTED, только при известной стране и видимом окне. Нет страны,
отключение или скрытие — таймер останавливается. Перенос фокуса при смене страны остаётся
плавным. Самостоятельный выбор страны по клику/названию сервера не добавлялся.
