## Наблюдения для Codex

1. **GUI-SERVER-PIN принят с первого прогона в окне**: временный
   пин и возврат выполняются полностью из окна (два разрешённых
   POST), поведение совпадает с принятым CLI-сценарием UI06 r3 —
   тот же кандидат, та же геометрия панорамы, исходный IP вернулся.
2. Диалог кандидата соответствует контракту: отмена по умолчанию,
   повторное подтверждение при изменении строки, отдельный путь
   пула; бессрочное закрепление покрыто только offscreen-тестом,
   как и указано в ТЗ.
3. Клиент пробы с белым списком из двух действий показал себя
   практичным предохранителем живого этапа — стоит использовать
   его в будущих GUI-пробах с записью.
4. Мелочь: блок ТЗ читает переменную окна из окружения процесса —
   при запуске её нужно экспортировать до heredoc (в первом
   прогоне было NOT_RUN по этой причине; на результат не повлияло).
