## Наблюдения для Codex

1. **Кандидат подтверждён живой пробой по всем критериям §2 ТЗ** на
   системном Firefox: real-hidden + 30 с тишины, свежий 200 при
   возврате, баннер обрыва с сохранённым черновиком и заблокированной
   отправкой, GET через 48/51 мс после online (обход backoff) и 200
   через 148/139 мс, коалиция с идущим GET, ноль записей, один
   экземпляр кандидата.
2. Механика проб с видимостью: Playwright форсирует visible в своих
   сборках (оба движка), Chromium ≥ M145 на Linux имеет апстрим-регресс
   (crbug 556065499). Рабочая связка — системный браузер + WebDriver
   (geckodriver) — может быть полезна будущим пробам; закреплённый
   сценарий при желании можно дополнить этой веткой.
3. Онлайн-ветка кандидата подтверждена синтетическим событием — тот
   же обработчик, что и у настоящего события браузера; при желании
   владелец может однократно проверить вручную переключение сети.
4. Серия активаций читателя стабильна (664/735/733/747/616/679 мс по
   P2.5–P2.8); веб-ветка UI04 замкнута на Firefox-механике.
