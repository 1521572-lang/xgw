## Наблюдения для Codex

1. **r2 принят с первого прогона**: перенос HTTPS-контроля до
   подготовки payload и redirect-aware проверка (каноническое имя,
   ≤2 переходов по HTTPS, финальный 2xx) закрыли блокировку r1;
   классификация r1 подтверждена — причина была серверная
   (301 на прежнем контрольном имени), машина и кандидат не виноваты.
2. Штампованный handover окна — готовая механика доставки обновлений
   кода GUI: обычный повторный запуск заменяет окно прежней версии
   без ручных шагов; для будущих обновлений релиза достаточно
   сценария + этого приёма.
3. Мок-контракты HTTPS-контроля (6 кейсов) фиксируют порог и
   параметры curl — регрессии порога «финальный 2xx» теперь ловятся
   без сети.
4. Цепочка доставки замкнута: UI06 (частная копия) → r2 (установленный
   релиз), живое окно проверено на обоих уровнях; откат остаётся
   доступным штатным помощником через payload текущего прогона.
