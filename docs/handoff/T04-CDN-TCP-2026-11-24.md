# ThinkCentre · TCP-счётчики прямого CDN-сокета Xray

**Ubuntu 24.04 LTS.** Flash сама запускает закреплённые команды и
публикует обезличенный отчёт. При отсутствии терминала, sudo,
доступа к панели или GitHub запроси доступ. Выполни независимые
проверки при блокере. Код и сценарии готовит Codex.

В [сопоставимой паре](../reports/2026-11-24T201221Z_t04-cdn-pair.md)
VPN дважды подтвердил точный диапазон `206/65536`, включая подготовку.
На том же URL и IPv4 прямой запрос остановился до `ServerHello`.
Xray подтвердил оба выхода. Теперь измеряем счётчики TCP
на исходящем соединении Xray с меткой zapret2, отдельно от
сокета curl, который участвует в прозрачном перехвате.

Наблюдение только читает `ss` для одного адреса, порта и метки.
Сокеты из исходного снимка исключаются. Нужен один новый сокет,
который принадлежит процессу Xray из снимка. Интервал чтения 250 мс
между опросами, предел 64 опроса за окно до 16 с. Маршрут дополнительно
сверяется по журналу Xray. Дампы, ключи TLS и содержимое
ClientHello не собираются. [Поля TCP_INFO в iproute2](https://github.com/iproute2/iproute2/blob/v6.1.0/misc/ss.c#L3010-L3030)

## Запуск

Начни из рабочей копии. Для тестов можно указать существующее
окружение `XGW_TEST_PYTHON`. Для лаборатории и живого окна проверь
`sudo -n true`. При необходимости авторизуйся через `sudo -v`.
Живая фаза использует короткое согласованное окно и прежний
сценарий с временной установкой, паузой VPN в Standalone и откатом.
Если такое окно сейчас недоступно, перед запуском блока задай
`XGW_CDN_LIVE=0` и выполни лабораторию и контракты.

~~~bash
bash <<'BASH'
set -euo pipefail
umask 077
. /etc/os-release
[[ $ID == ubuntu && $VERSION_ID == 24.04 && $EUID != 0 ]]
BR=integration/zapret2-batch1
CODE=0b132f086a3ac33a2c739e72bcc547a8c039f3f1
PY=/usr/bin/python3
TEST_PY=${XGW_TEST_PYTHON:-$PY}
REPO=$(git rev-parse --show-toplevel)
git -C "$REPO" fetch origin "$BR"
git -C "$REPO" merge-base --is-ancestor "$CODE" FETCH_HEAD
D=$(mktemp -d "$HOME/xgw-cdn-tcp.XXXXXXXX")
mkdir "$D/tree"
git -C "$REPO" archive "$CODE" src docs/helpers tests pyproject.toml | tar -x -C "$D/tree"
printf 'OS %s\nPINNED %s\nPRIVATE_ARTIFACTS %s\n' "$PRETTY_NAME" "$CODE" "$D"
uname -r
ss -V
run_phase() {
  local label=$1 rc=0
  shift
  "$@" >"$D/$label.log" 2>&1 || rc=$?
  tail -n 24 "$D/$label.log"
  printf '%s_EXIT %s\n' "$label" "$rc"
  return "$rc"
}
contracts() (
  cd "$D/tree"
  export PYTHONPATH="$D/tree:$D/tree/src:$D/tree/tests"
  export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTEST_ADDOPTS=
  timeout -k 3 120 "$TEST_PY" -B -P -m pytest -o addopts= -p no:cacheprovider \
    --color=no -v --tb=short --basetemp "$D/pytest" tests/test_cdn_tcp_observation.py \
    tests/test_standalone_cdn_compare.py tests/test_selective_probe_watch.py \
    tests/test_desync_route_evidence.py
)
loopback() (
  local root
  root=$(sudo -n mktemp -d /var/tmp/xgw-cdn-tcp.XXXXXXXX) || exit $?
  [[ $root =~ ^/var/tmp/xgw-cdn-tcp\.[A-Za-z0-9]{8}$ ]] || exit 2
  trap 'sudo -n rm -rf -- "$root"' EXIT
  git -C "$REPO" archive "$CODE" src docs/helpers |
    sudo -n tar --no-same-owner -x -C "$root" || exit $?
  timeout -k 2 20 sudo -n unshare --net -- /usr/bin/env -i \
    PATH=/usr/sbin:/usr/bin:/sbin:/bin "PYTHONPATH=$root:$root/src" "$PY" -B -P - <<'PY'
import os
import socket
import subprocess
import time

from docs.helpers.cdn_tcp_observation import watch_transfer
from xgw.zapret2 import MARK

assert os.geteuid() == 0
assert not os.path.samefile("/proc/self/ns/net", "/proc/1/ns/net")
assert socket.if_nameindex() == [(1, "lo")]
subprocess.run(["ip", "link", "set", "lo", "up"], check=True, timeout=3)
with socket.socket() as listener:
    listener.bind(("127.0.0.1", 443))
    listener.listen()
    listener.settimeout(2)
    for reply, expected in (
        (False, "ack_without_tcp_data"),
        (True, "tcp_data_received"),
    ):
        with socket.socket() as client:
            client.settimeout(2)
            client.setsockopt(socket.SOL_SOCKET, socket.SO_MARK, MARK)

            def transfer(reply=reply):
                client.connect(("127.0.0.1", 443))
                with listener.accept()[0] as server:
                    server.settimeout(2)
                    client.sendall(b"fixture")
                    assert server.recv(7, socket.MSG_WAITALL) == b"fixture"
                    if reply:
                        server.sendall(b"reply")
                        assert client.recv(5, socket.MSG_WAITALL) == b"reply"
                    time.sleep(1.4)
                    return {"curl_rc": 28, "tcp": 0.01, "tls": 0}

            _, summary = watch_transfer("127.0.0.1", os.getpid(), transfer)
        assert summary["state"] == expected, summary
        print("LOOPBACK", expected, summary, flush=True)
PY
)
real_trial() (
  cd "$REPO"
  git show "$CODE:docs/helpers/standalone_return_preflight.sh" |
    bash -s -- "$CODE" || return
  git show "$CODE:docs/helpers/standalone_return_live.sh" |
    bash -s -- "$CODE" cdn-pair
)

contracts_rc=0
run_phase CONTRACTS contracts || contracts_rc=$?
loopback_rc=0
run_phase LOOPBACK loopback || loopback_rc=$?
if [[ $contracts_rc == 0 && $loopback_rc == 0 && ${XGW_CDN_LIVE:-1} == 1 ]]; then
  run_phase LIVE real_trial
else
  printf 'CDN_TCP_LIVE_NOT_RUN\n'
  [[ $contracts_rc == 0 && $loopback_rc == 0 ]]
fi
BASH
~~~

## Критерии отчёта

- **CONTRACTS** — версии, SHA, passed, failed, skipped. Отметь старый
  и чужой сокеты, отсутствие владельца, неоднозначность, недостаточное
  окно и три различимых исхода TCP.
- **LOOPBACK** — два опыта с реальными TCP и `ss` в приватном
  netns. В первом есть ACK без входящих данных, во втором есть
  данные. Код таймаута TLS в лаборатории задан фикстурой.
- **LIVE** — отдельно запиши подготовку VPN, итоги HTTPS/Range
  обоих плеч, точный маршрут и `direct_tcp` из `pair-verdict.out`.
  Сверь число выборок, отставание последней выборки, ACK, отправленные,
  принятые и повторно переданные байты. При `path_unconfirmed` или
  другом неполном результате не выводи направление потери.
- **Возврат** — off/off, VPN HTTPS, маркер managed, хеши
  файлов и настроек, остановка таймера. При обрыве терминала
  выполни [готовый возврат](STANDALONE-MANAGED-LIVE-2026-11-23.md#3-независимый-возврат)
  по приватному файлу `restore-location`.

`ack_without_tcp_data` означает, что TCP подтвердил часть полезных
данных, а входящие данные в покрытом окне отсутствовали.
`retransmit_without_payload_ack` означает, что наблюдалась
ретрансляция, а подтверждение полезных данных не наблюдалось.
`tcp_data_received` означает входящие TCP-данные на сокете Xray.
Их тип и источник этот замер не определяет. Для двух выводов об
отсутствии данных нужны таймаут TLS, не менее трёх выборок и
последняя выборка в пределах секунды от конца.

Публикуй только агрегаты, коды и версии. Подписанные URL, peer,
порты, PID и журналы остаются на машине. Исходный вывод `ss`
обрабатывается в памяти.
Критерий допуска Selective остаётся полным диапазоном на обоих плечах.

## Автоматическая публикация

Подставь абсолютный путь к обезличенному Markdown в `REPORT_SRC`.
Выполни из рабочей копии при любом исходе и верни ссылку на коммит.

~~~bash
bash -s -- "$REPORT_SRC" <<'BASH'
set -euo pipefail
umask 077
REPORT_SRC=$1
BR=integration/zapret2-batch1
[[ $REPORT_SRC == /* && -s $REPORT_SRC ]]
REPO=$(git rev-parse --show-toplevel)
PUB=$(mktemp -d "$HOME/xgw-cdn-tcp-report.XXXXXXXX")
git -C "$REPO" fetch origin "$BR"
git -C "$REPO" worktree add --detach "$PUB/repo" FETCH_HEAD
trap 'git -C "$REPO" worktree remove "$PUB/repo" && rmdir -- "$PUB"' EXIT
cd "$PUB/repo"
REPORT="docs/reports/$(date -u +%Y-%m-%dT%H%M%SZ)_t04-cdn-tcp.md"
test ! -e "$REPORT"
install -m 0644 -- "$REPORT_SRC" "$REPORT"
git add -- "$REPORT"
git diff --cached --check
git commit -m 'Report ThinkCentre marked CDN socket TCP evidence'
if ! git push origin "HEAD:refs/heads/$BR"; then
  git fetch origin "$BR"
  git rebase FETCH_HEAD
  git push origin "HEAD:refs/heads/$BR"
fi
git fetch origin "$BR"
git merge-base --is-ancestor HEAD FETCH_HEAD
printf 'PUBLISHED %s %s\n' "$(git rev-parse HEAD)" "$REPORT"
BASH
~~~
