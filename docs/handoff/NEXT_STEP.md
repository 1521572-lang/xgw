# Следующая проверка Flash на ThinkCentre

Проверь на **Ubuntu 24.04 LTS** временный кандидат `d4b9a7b` с одной
попыткой допуска Selective. При прямом TLS-таймауте кандидат проверяет
тот же URL CDN через VPN. При успешном допуске выполни один просмотр
и поймай `pending → active` при штатной ротации. Заверши проверкой
отката и публикацией. [Готовое ТЗ](SELECTIVE-ROUTE-STATUS-2026-11-21.md)

Первый кандидат прошёл тесты, установку и откат. В двух проверенных
прямых путях к CDN был TLS-таймаут. Один URL до этого дал 206/65536
через VPN. Живой статус после ротации остаётся открытым.
[Последний отчёт](../reports/2026-11-20T224355Z_selective-route-status.md)

Код и тесты подготовлены Codex. Flash сама запускает проверку на
машине, при недоступном терминале, панели или sudo запрашивает доступ
и при любом исходе публикует обезличенный отчёт в `integration/zapret2-batch1`.
