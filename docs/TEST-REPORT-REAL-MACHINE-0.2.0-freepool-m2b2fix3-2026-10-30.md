## Дефекты
1. (мелкий) **Три эмодзи в жёлтой полосе «Выбран вручную «<имя сервера>»…» над списком серверов
   на вкладке «Подписки»** (J2 = 3; в строках списка, главной карточке и на вкладке пула — 0).
   Чистка эмодзи не применяется к этой полосе; в данных имя содержит эмодзи. Предложение:
   прогонять через ту же чистку текст полосы.
2. (отклонение, на решение разработчика) **При загрузке после перезагрузки в режиме «весь дом»
   не зафиксированы событие «весь дом снят после перезагрузки» и срочная сборка «режим
   подписок» с перезапуском Xray** (обе счётчика 0; единственное применение с загрузки — не
   пул), при том что итог правильный: режим observe, рабочий конфиг observe, «совпадает: да».
   Судя по пустому журналу загрузки, режим был снят ещё при завершении работы. Главный критерий
   прошлой проверки (конфиг следует режиму) выполняется; при желании разработчик может
   восстановить явную фиксацию снятия событием для отладки и панели.
