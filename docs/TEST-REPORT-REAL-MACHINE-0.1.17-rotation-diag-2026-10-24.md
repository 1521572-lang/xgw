# Отчёт: почему мёртвый участник не меняется (только чтение)

Дата: 2026-10-24 17:28–17:33 MSK. rotcheck.py sha256 b20f6865 — совпал. Шлюз не менялся.

## Итог

Подтверждена причина **Р1: запасных того же класса, что участники, нет — класс исчерпан**.
Класс участников — уровень «высокий», x10; серверов этого класса всего 4, и все четыре —
участники (max_members = 5, 4 < 5), запасных того же класса 0 из 74 (все 74 запасных —
уровень «средний»). Мёртвая Турция (С-2) не могла быть заменена по правилам: на класс хуже
шлюз переходит только когда живых участников нет вовсе. События и журнал это подтверждают:
за 24.10 и последние сутки — 0 замен участников, 0 смен приоритетов, сканов запасных
класса участников — 0 (из 334 в окне испытания А3.2). DEGRADED был и **до** установки
13:26: переход WAN_DOWN в 12:50 шёл из DEGRADED, в 12:52 — снова DEGRADED; «13:27» — лишь
время после перезапуска демона при установке. Интернет при этом работал (3 из 4 участников
живы, весь трафик — через выбранного вручную С-4).

## Наблюдения

- Турция была мёртвой до установки А3.2: переход WAN_DOWN в 12:50:44 шёл **из DEGRADED**
  («DEGRADED → WAN_DOWN») — то есть балансировщик уже был частично мёртв к 12:50, за
