# vpn_ui — окно VPN-клиента на Qt6

Оформление по образцу открытого клиента Proton VPN; имя и логотип Proton не используются.
Есть рабочий запуск с API XGW и отдельная демонстрация исходного дизайн-бандла.

## Рабочее окно XGW

Из корня checkout, от пользователя графической сессии:

```bash
python3 vpn_ui/main_xgw.py --theme dark
python3 vpn_ui/main_xgw.py --theme light --native-titlebar
```

Нужны установленный XGW с работающей локальной панелью, PyQt6 и QtSvg.
Рабочий запуск явно использует PyQt6: существующие страницы XGW нельзя смешивать с PySide6
в одном процессе. Политика входа прежняя: сохранённый пользовательский сеанс панели либо
кнопка «Войти в панель» и polkit; постоянный токен и root-права самому окну не нужны.
Окно использует исходники `src/xgw` из этого же checkout. Данные и команды получает через
`ApiClient` (`/api/state`, `/api/pool` и действия панели), напрямую конфиги/службы не меняет.

- Слева список подписок, ниже серверы выбранной подписки. Отдельные ссылки и бесплатный
  пул сохранены; пустая подписка остаётся видна с ошибкой. Выбор подписки только фильтрует.
- В строке сервера — страна по IP, последняя скорость и рейтинг XGW. При наведении или
  нажатии Enter справа открываются полное имя, статус, протокол и остальные сведения.
  Отдельная кнопка меняет сервер. Автовыбор возвращает
  выбор демону для соответствующего каталога, а не ограничивает его просматриваемой подпиской.
- Показаны реальные статусы, квоты и последние замеры. Нет категорий P2P/Streaming,
  выдуманных профилей/шлюзов, глобального переключателя протокола и неподключённых настроек.
- Справа zapret2, устройства, трафик, диагностика и «Ещё» открывают существующие рабочие
  страницы в дополнительном окне через тот же ApiClient. Подписки и управление серверами
  доступны через «Настройки» и кнопку «Изменить». Эти страницы сохраняют прежнюю светлую тему.
- Центральная кнопка управляет перехватом текущего режима. Она не переключает сама VPN/zapret2.
  Статус берётся из состояния шлюза. При устаревании/потере связи команды закрыты, в том числе
  команды из уже открытых диалогов. HTTP-успех pin/power ещё не подтверждает новый маршрут.
- Текущую скорость и внешний IP API состояния не предоставляет: показано «нет данных».
  Случайных метрик, фиктивного графика и геолокации нет; реальные расходы доступны в «Трафике».
  Карта плавно перемещается к стране IP активного сервера. Страну определяет локальная
  GeoIP-база по адресу точки подключения, в том числе через мост sing-box.
  Для полного покрытия установите `/opt/xgw/xray/geoip-ui.dat` по ТЗ vpn-ui-map.
  При её отсутствии используется штатная база Xray, охват которой зависит от установки.
  Адреса с неизвестной или неоднозначной страной остаются без отметки. Страна VPN-выхода
  может отличаться от страны точки подключения. Для этих данных обновите сервер панели
  по ТЗ vpn-ui-map.

Закрытие окна останавливает только его клиент. Повторный запуск поднимает тот же экземпляр;
после изменения кода окно заменяет свой прежний экземпляр. Штатный `xgw gui`, его ярлык,
службы и установщик пока не заменяются: приёмка нового запуска — по ТЗ vpn-ui-xgw.
Версия XGW остаётся 0.2.0. `main_demo.py` не используется рабочим запуском.

Минимальные проверки разработки — этот набор и Ruff изменённых файлов:

```bash
PYTHONPATH=src:. python3 -m pytest -o addopts= -q tests/test_vpn_ui_xgw.py
```

Основная приёмка — на реальной машине.

## Демонстрация исходного дизайн-бандла

```bash
python3 vpn_ui/main_demo.py --demo                 # окно с имитацией бэкенда
python3 vpn_ui/main_demo.py --demo --theme light   # светлая тема
python3 vpn_ui/main_demo.py --demo --native-titlebar   # системная рамка окна
python3 vpn_ui/verify_layout.py                    # снимки 4 состояний и сверка вёрстки
```

Нужен Python 3.12 и Qt6 с модулем QtSvg. Основная привязка — PySide6; если её нет,
`vpn_ui/qt.py` берёт PyQt6 (код написан в общем подмножестве обеих).

## Как подключить свой бэкенд

Всё общение идёт через `core/bridge.py` → `VpnUiBridge`:

| Окно → бэкенд (сигналы) | Когда |
|---|---|
| `connect_requested(str)` | выбран сервер, профиль, шлюз или `"auto"` (самый быстрый) |
| `disconnect_requested()` | «Отключить» или «Отмена» |
| `feature_toggled(str, bool)` | `kill_switch`, `split_tunneling`, `custom_dns`, `lan_bypass` |
| `protocol_changed(str)` | `xray`, `sing-box`, `wireguard`, `openvpn` |
| `settings_updated(dict)` | тема, маршрутизация, интерфейс, адрес DNS, автоподключение |

| Бэкенд → окно (методы) | Что меняет |
|---|---|
| `update_connection_state(state, server_id=None, detail="")` | свечение, карточку, статус |
| `update_telemetry(down_bps, up_bps, total_down, total_up, ping_ms, client_ip)` | метрики, график |
| `set_server_list(list[ServerNode])` | левую панель и отметки на карте |
| `update_features(FeaturesState)` | плитки справа и переключатели настроек |
| `set_location(LocationInfo)` | нижнюю полосу без VPN и точку на карте |
| `set_notice(str)` | карточку-сообщение над списком серверов |

Окно само состояние не выдумывает: нажатие плитки шлёт `feature_toggled`, а картинка
меняется, когда бэкенд ответит `update_features`. Пример — `MockBackendController`
в `main_demo.py`.

## Устройство

- `core/` — состояния (dataclass) и мост; `theme/` — токены, генератор QSS, загрузчик SVG;
- `components/` — виджеты на QPainter: переключатель, строка статуса, плитка, график, шапка;
- `views/` — левая панель, карта, карточка подключения, настройки, главное окно.

Размеры — в логических единицах XAML (`theme/tokens.py`). Эталонный снимок снят при
масштабе 125 %, поэтому его пиксели делятся на 1,25: окно 1002×650, левая панель 280,
правая 110, шапка 38, кнопка подключения 250×39. Пороги ширины: уже 885 — левая панель
сворачивается в значки, уже 1000 — правая панель без подписей.
