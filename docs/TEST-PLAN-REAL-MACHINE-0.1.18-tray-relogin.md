# Проверка XGW 0.1.18: значок после входа в сеанс

**Для исполнителя.** Выполняй шаги строго по порядку. В каждом шаге — команда (копируй
целиком), «Ожидается» и «Если не так». Ничего не придумывай сверх написанного. Не уверен —
остановись и спроси заказчика. Выводы сохраняй в файлы, как написано (`$HOME/xgw-018-relogin/…`).

Машина: ThinkCentre, Ubuntu 24.04.5 LTS, рабочий стол KDE Plasma (X11), XGW 0.1.18 с кодом
ветки `tspu-speed-tray` — коммит после отчёта «Отчёт: один значок в трее» (5a3b73e). Клон —
`~/zcod/xgw`.

Что исправлено (ASSUMPTIONS п. 241 (д)). Прошлая проверка подтвердила: значок один при
установке, втором запуске и замене. Вход в сеанс заново тогда не проверялся. Разбор кода
показал: сторож значка из прошлого сеанса может пережить выход и держать блокировку, а его
значок с окружением прошлого сеанса в новый сеанс не встанет; автозапуск при входе уступал
ему — и значка не было бы совсем. Теперь автозапуск при входе — `xgw tray --replace`: значок
нового сеанса закрывает остатки прошлого.

## 0. Запрещено

- `xgw net down`, `xgw disable`, `xgw uninstall`, `reboot`, сон машины, `install.sh --force` —
  **никогда**. Запуск, остановка и перезапуск служб `xgw*`, `tailscaled`, NetworkManager,
  `ssh`; ручные `nft` (кроме `nft list`), `ip`, `iptables`, `tc`, `sysctl -w`.
- Править `/etc/xgw`, `/opt/xgw`, `/var/lib/xgw`, `/etc/systemd`, `/etc/xdg`, код XGW.
  Коммитить что-либо, кроме отчёта (§7).
- Закрывать и запускать процессы значка — только командами шагов 3.1 и «Если не так» шага 4.3.
- Писать в отчёт: адреса tailnet, имена `*.ts.net`, имена устройств и пользователей (имя
  пользователя → `<user>`), внешние IP, токены, адреса подписок, IP и домены серверов VPN.
  Номера процессов, пути вида `/run/user/1000/…` и имена групп процессов (`run-….service`,
  `session-….scope`) — можно, не заменять.

Против пункта 1 — **стоп**. Против пункта 3 или «не сейчас» — выполнить §§ 2, 3, 5 и отчёт, в
отчёте §4 — «не выполнялся (заказчик: …)». Когда заказчик позже скажет «можно» — выполнить
шаги 1.2 и §4, дописать отчёт.

Шаг 1.2. Папка и счётчик значков (он не считает сам себя, в отличие от `pgrep` в командной
строке):

```bash
mkdir -p "$HOME/xgw-018-relogin" && chmod 700 "$HOME/xgw-018-relogin" && cd "$HOME/xgw-018-relogin" && cat > count.sh <<'EOF'
#!/bin/sh
# Значки XGW этого человека: значок — «xgw tray --run», сторож — «xgw tray» и «xgw tray --replace».
me=$(id -u)
icons=$(pgrep -u "$me" -f 'x[g]w tray --run$' | tr '\n' ' ')
guards=$(pgrep -u "$me" -f 'x[g]w tray( --replace)?$' | tr '\n' ' ')
lock=$(cat "/run/user/$me/xgw-tray.lock" 2>/dev/null)
echo "значков: $(echo $icons | wc -w) [ $icons], сторожей: $(echo $guards | wc -w) [ $guards], блокировка: ${lock:-нет}"
for p in $guards; do
  echo "сторож $p: запущен $(ps -o lstart= -p "$p"), группа $(sed -E 's#.*/##' "/proc/$p/cgroup" | head -1)"
done
EOF
sha256sum count.sh | cut -c1-16; sh count.sh | tee before.txt
```

Ожидается: первая строка — `abefa2507641e027`; затем `значков: 1 [ N ], сторожей: 1 [ M ],
блокировка: M` и строка `сторож M: запущен …, группа …`. Записать как есть. **Спроси
заказчика**: «Сколько значков XGW сейчас рядом с часами?» — записать ответ.

Если не так: сумма другая — скрипт скопирован с ошибкой: выполнить шаг заново, скопировав
команду целиком; снова другая — **стоп**, сообщить заказчику. Значков или сторожей больше
одного — записать как есть (это до установки, не дефект).

## 3. Как при входе в сеанс (без выхода)

Шаг 3.1. Команда автозапуска — та, что в файле автозапуска, в менеджере сеанса человека:

```bash
cd "$HOME/xgw-018-relogin" && before=$(pgrep -f 'x[g]w tray --run$'); sudo systemd-run --user --machine="$USER@" --quiet --collect --description="XGW: проверка автозапуска" -- $(sed -n 's/^Exec=//p' /etc/xdg/autostart/xgw-tray.desktop); sleep 8; after=$(pgrep -f 'x[g]w tray --run$'); echo "значок был: $before, стал: $after" | tee autostart.txt; sh count.sh | tee -a autostart.txt
```

Ожидается: «значок был: N, стал: M» — разные числа; `значков: 1`, `сторожей: 1`. **Спроси
заказчика**: «Значок мигнул и остался один?»

Если не так: «стал» — то же число, что «был», — **дефект «автозапуск не заменяет»**. Значков
0 или 2 — записать вывод целиком.

