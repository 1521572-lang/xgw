## Опыт `before`: подтверждение не переносится на чужой запуск

Временный green прошёл подготовку и был перезапущен с другим идентификатором запуска
(новый запуск, тот же слот). XGW отклонил коммит через API с причиной «сменился после
проверки моста»; конфиг Xray остался прежним, кандидат снят, активным остался blue,
green остановлен. Старое и новое соединения через blue получили `A`, процесс Xray
сохранён. То есть подтверждение привязано именно к проверенному запуску и не
переносится на перезапущенный слот.

## Опыт `after`: подтверждение исчезает после перезапуска

Green принят через настоящий API: `identity_ok=true` подтвердил прошедший проверку
запуск, переход состоялся, старый поток через blue продолжал получать `A`, новый через
green — `B`. Затем слот green перезапущен: активным остался green, но `identity_ok`
стал `null`, хотя новый запрос через green по-прежнему получает `B`. Старое соединение
через blue продолжало получать `A`, процесс Xray сохранён. Подтверждение относится к
конкретному запуску и исчезает при его смене, не блокируя рабочий трафик.
