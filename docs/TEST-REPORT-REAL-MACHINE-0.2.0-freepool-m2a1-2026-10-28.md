   дефект. Сработал ли запас на практике — по отказам поколений не видно (все отказы
   завершились раньше срока), но запас сокращён до ~3 с сверх работы агента.
2. **«Посредник идёт мимо туннеля».** У всех 4 поднявшихся туннелей «итог туннеля»
   заканчивается «охрана отбила после подъёма 21/20/21/20» — после подъёма туннеля охрана
   пространства имён отбрасывает по ~20 пакетов за поколение: часть трафика поколения
   (проверка изнутри или посредник) пытается идти не через fpt0. Охрана не пропустила
   (наружу ничего не ушло — «из fpv* — сброс: 0»), но по правилу ТЗ «охрана отбила после
   подъёма больше 0» — дефект.
