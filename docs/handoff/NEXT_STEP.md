# Flash — кто пишет конфиг Xray на работающем шлюзе

**Read-Only, ≤15 мин.** Ubuntu 24.04 LTS, текущий режим. Цель — увидеть замену файла и установить, до какого уровня удаётся подтвердить источник. Flash запускает проверку сама из checkout XGW от вошедшего в панель пользователя. Если недоступен терминал, вход в панель или sudo, запроси доступ. При занятом шлюзе зафиксируй BUSY. ТЗ r3 с установкой — отдельное задание после отчёта.

```bash
set -euo pipefail
BR=integration/zapret2-batch1
CODE=6eb92d1f3ebe2efdf6960bc84332e6f54aa096c9
git fetch origin "$BR"
git merge-base --is-ancestor "$CODE" FETCH_HEAD
git show "$CODE:docs/helpers/xray_writer_window.sh" | timeout -k 5 320 bash -s -- "$CODE"
```

Сборщик наблюдает 180 с, читает существующие журналы и базу, проверяет HTTPS через штатный Xray до/после. Приватный каталог напечатан в первой строке. При ошибке сохрани фазу и код. Не меняй режим, nft, параметры сети, audit-правила или пакет.

1. В `watch.jsonl` проверь begin/end, backend, число сигналов и переходов, секции и возраст watchdog. Если файл сменился, сопоставь время с `audit`, `xgw.journal`, `xgw-xray.journal` и `events`. Для `PROCESS_CONFIRMED` нужны успешная операция с конечным файлом и однозначная связка PATH/SYSCALL одного serial. Для одного совпадения по времени пиши `CORRELATED_ONLY`. Без подтверждения — `UNKNOWN`. Пустое полное окно — `NONE_OBSERVED` с указанием режима. Переполнение, таймаут или неполное наблюдение — `PARTIAL`.
2. Проверь `before`, `after`, `settings_rc`. Если сохранилась пара снимков из CDN r2, потрать до 60 с на [ретроспективный запрос из §2](SELECTIVE-DAILY-2026-11-20.md). Запиши результат отдельно от нового окна. В отчёт включи SHA помощника, режим, длительность, число событий/версий, секции, класс процесса при доказанной атрибуции, доступность audit/журналов и состояние VPN. Полные логи, PID/UID, адреса, хэши конфигов и значения JSON остаются на машине.
3. При любом исходе самостоятельно опубликуй один отчёт в `integration/zapret2-batch1` по [блоку публикации §3](MEDIA-COUNTERS-2026-11-20.md). Укажи суффикс `_xray-writer-readonly.md` и тему коммита `docs: report installed Xray writer observation`. Проверь наличие коммита в удалённой ветке и верни ссылку. Отметь отдельно время измерения и публикации.
