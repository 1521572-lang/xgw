# ThinkCentre · HTTPS и TPROXY в изолированном LAN-стенде

**Ubuntu 24.04 LTS.** Flash сама запускает готовые команды и публикует
один обезличенный отчёт на GitHub при любом исходе. При недоступности
терминала, sudo, pytest, установленного Xray или GitHub запроси доступ.
Доступные фазы выполни независимо. Код и тесты подготовлены Codex.

[Отчёт LAN](../reports/2026-11-24T220450Z_t12-lan-https.md) подтвердил
76 контрактов. Живой запрос имеет статус `NOT_RUN`, поскольку отдельный
LAN-клиент недоступен. Этот проход проверяет связку реального nftables,
маркировки, TPROXY, Xray и HTTPS на ядре ThinkCentre, в трёх сетевых
пространствах стенда. Внешняя сеть в стенд не подключается. TLS-сертификат
создаётся для одного теста и передаётся curl через `--cacert`.

Запись `tproxy-in` берётся из stdout реального Xray стенда. Тест
подставляет метаданные для входа анализатора из интервала своего запуска.
Журнал действующей службы уже проверен на локальных входах в предыдущем
[отчёте](../reports/2026-11-24T215502Z_t12-vpn-route.md).

## Запуск на машине

Запусти блок из обычной рабочей копии. Для контрактов и стенда можно
задать имеющийся Python с pytest через `XGW_TEST_PYTHON`. Для стенда
нужны `ip`, `nft`, `unshare`, `curl`, `openssl` и установленный Xray.
Для снимков и стенда сначала проверь `sudo -n true`. При необходимости
авторизуйся через `sudo -v`.

~~~bash
bash <<'BASH'
set -euo pipefail
umask 077
. /etc/os-release
[[ $ID == ubuntu && $VERSION_ID == 24.04 && $EUID != 0 ]]
BR=integration/zapret2-batch1
CODE=1b1a745c57be3fc5d443bc36d162ad65c8ddc816
REPO=$(git rev-parse --show-toplevel)
PY=/usr/bin/python3
TEST_PY=${XGW_TEST_PYTHON:-$PY}
git -C "$REPO" fetch origin "$BR"
git -C "$REPO" merge-base --is-ancestor "$CODE" FETCH_HEAD
D=$(mktemp -d "$HOME/xgw-t12-lan-kernel.XXXXXXXX")
mkdir "$D/tree"
git -C "$REPO" archive "$CODE" src tests docs/helpers vpn_ui packaging pyproject.toml \
  | tar -x -C "$D/tree"
printf 'OS %s\nPINNED %s\nPRIVATE_ARTIFACTS %s\n' "$PRETTY_NAME" "$CODE" "$D"
uname -r
export PYTHONPATH="$D/tree:$D/tree/src:$D/tree/tests:$D/tree/tests/stand"
export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTEST_ADDOPTS=
cd "$D/tree"

snapshot() {
  sudo -n timeout -k 3 60 "$PY" -I -B - snapshot <docs/helpers/audit_host_observe.py &&
    sudo -n sha256sum /etc/xgw/config.toml /etc/xgw/panel.json
}

run_phase() {
  local label=$1 code=0
  shift
  "$@" >"$D/$label.log" 2>&1 || code=$?
  tail -n 18 "$D/$label.log"
  printf '%s_EXIT %s\n' "$label" "$code"
  return "$code"
}

kernel() {
  local name xray_bin=/opt/xgw/xray/xray
  for name in ip nft unshare curl openssl; do
    command -v "$name" >/dev/null || { printf 'STAND_DEPENDENCY_MISSING %s\n' "$name"; return 3; }
  done
  [[ -x $xray_bin ]] || { printf 'STAND_XRAY_UNAVAILABLE\n'; return 3; }
  "$xray_bin" version | head -n 1 || true
  nft --version || true
  sudo -n timeout -k 5 240 unshare --mount --propagation private --pid --fork \
    --kill-child --mount-proc /bin/sh -c '
      mount -t tmpfs -o nosuid,nodev,mode=0755 tmpfs /run || exit 3
      exec "$@"
    ' sh /usr/bin/env -i PATH=/usr/sbin:/usr/bin:/sbin:/bin \
    "PYTHONPATH=$PYTHONPATH" PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 XGW_XRAY_BIN="$xray_bin" \
    "$TEST_PY" -B -P -m pytest -o addopts= -p no:cacheprovider --color=no -v -rs --tb=short \
    --basetemp "$D/kernel-pytest" \
    tests/stand/test_stand_lan.py::test_lan_https_attributes_real_tproxy_socket \
    tests/stand/test_stand_lan.py::test_lan_survives_src_valid_mark \
    tests/stand/test_stand_lan.py::test_bypass_host_goes_direct \
    tests/stand/test_stand_lan.py::test_fail_closed_then_disable_gives_direct_internet
}

before=0
snapshot >"$D/state.before" 2>"$D/snapshot.before.err" || before=$?
run_phase CONTRACTS timeout -k 3 120 "$TEST_PY" -B -P -m pytest \
  -o addopts= -p no:cacheprovider --color=no -v -rs --tb=short --portable \
  --basetemp "$D/pytest" tests/test_desync_lan_control.py tests/test_desync_vpn_control.py \
  tests/test_desync_route_evidence.py tests/test_selective_probe_watch.py || true
run_phase KERNEL kernel || true
after=0
snapshot >"$D/state.after" 2>"$D/snapshot.after.err" || after=$?
if [[ $before == 0 && $after == 0 ]]; then
  if cmp -s "$D/state.before" "$D/state.after"; then
    printf 'T12_GATEWAY_UNCHANGED\n'
  else
    printf 'T12_GATEWAY_SNAPSHOT_DIFF\n'
  fi
else
  printf 'T12_GATEWAY_SNAPSHOT_NOT_AVAILABLE %s %s\n' "$before" "$after"
fi
BASH
~~~

## Итоги фаз

- **CONTRACTS** — числа `passed`, `failed`, `skipped` и время. Проверь,
  что вывод различает отсутствующий следующий хоп, чужой шлюз и
  непригодный сокет. Частные адреса в текст результата не попадают.
- **KERNEL** — исход каждого из четырёх сценариев. В новом сценарии
  ожидаются HTTP 200 с проверкой сертификата, точный сокет клиента в
  записи `tproxy-in` и `group=xray`. Остальные сценарии проверяют
  `src_valid_mark`, прямой выход исключённого устройства и fail-closed
  при остановке лабораторного Xray. При пропуске, ошибке или таймауте
  укажи причину и этап. Все изменения происходят внутри стенда.
- **Реальный клиент** — остаётся `NOT_RUN` до появления доступа. Для
  такого доступа сохранено [отдельное ТЗ LAN](T12-LAN-HTTPS-2026-11-25.md).
  Стендовый результат показывает поведение ядра и сборщика, а фактическая
  конфигурация LAN и работа sing-box проверяются своими сценариями.
- **Шлюз** — исход сравнения снимков и хэшей. При различиях укажи
  категории. Установка, переключение рабочего шлюза и захват трафика
  в этот проход не входят.

## Автоматическая публикация

Публикуй версии, SHA, итоги фаз и категории. Журналы, сертификаты,
ключи, исходные снимки, адреса и пути оставь на машине. Подставь
абсолютный путь к обезличенному Markdown в `REPORT_SRC`, запусти блок
из рабочей копии при любом исходе и верни ссылку на коммит.

~~~bash
bash -s -- "$REPORT_SRC" <<'BASH'
set -euo pipefail
umask 077
REPORT_SRC=$1
BR=integration/zapret2-batch1
[[ $REPORT_SRC == /* && -s $REPORT_SRC ]]
REPO=$(git rev-parse --show-toplevel)
PUB=$(mktemp -d "$HOME/xgw-t12-lan-kernel-report.XXXXXXXX")
git -C "$REPO" fetch origin "$BR"
git -C "$REPO" worktree add --detach "$PUB/repo" FETCH_HEAD
trap 'git -C "$REPO" worktree remove "$PUB/repo" && rmdir -- "$PUB"' EXIT
cd "$PUB/repo"
REPORT="docs/reports/$(date -u +%Y-%m-%dT%H%M%SZ)_t12-lan-kernel.md"
test ! -e "$REPORT"
install -m 0644 -- "$REPORT_SRC" "$REPORT"
git add -- "$REPORT"
git diff --cached --check
git commit -m 'Report ThinkCentre isolated LAN HTTPS and TPROXY'
if ! git push origin "HEAD:refs/heads/$BR"; then
  git fetch origin "$BR"
  git rebase FETCH_HEAD
  git push origin "HEAD:refs/heads/$BR"
fi
git fetch origin "$BR"
git merge-base --is-ancestor HEAD FETCH_HEAD
printf 'PUBLISHED %s %s\n' "$(git rev-parse HEAD)" "$REPORT"
BASH
~~~
