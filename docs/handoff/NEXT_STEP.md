# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** запусти проверку установленной панели
из `f58ab0c`. Она измеряет первый авторизованный запрос
`/api/state` и собирает длительности этапов формирования ответа.
После HTTP 200 проверяет одноразовый вход и выполняет откат.
[Готовое ТЗ r4](PANEL-LOGIN-INSTALLED-TRIAL-2026-11-21.md)

В r3 авторизованный запрос после рестарта успевал завершиться
примерно через 23 с. Задержка была и на восстановленной базе.
Откат и снятие таймера прошли. Живая ротация Selective ждёт
успешного прямого допуска.
[Последний отчёт](../reports/2026-11-21T132112Z_panel-login-installed-trial-r3.md)

запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
