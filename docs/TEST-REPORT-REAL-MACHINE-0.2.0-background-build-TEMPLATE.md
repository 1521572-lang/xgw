# Форма отчёта: сборка конфига в фоне

В настоящий отчёт вставляется целиком конечный вывод helper.py report.
Это завершённые факты помощника, включая отрицательный результат и возврат.
Не заменять None/НЕ ВЫПОЛНЯЛОСЬ ожидаемыми числами и не копировать сюда приватное состояние.

Внизу добавить три строки:

- Проверенный Git commit: `<полный публичный SHA>`.
- Явное согласие владельца на шаг 4: да / нет.
- Кнопка «Обновить»: выполнено / NOT_RUN; безопасный результат.

Без нажатия кнопки результат задания partial даже при успешном помощнике.
Если прогон не завершён, отчёт не подделывать: сообщить в чате этап и фактический код.
Имена, адреса, конфиги, PID, логи, токены и снимки экрана не публиковать.
