# ThinkCentre — допуск Selective на проверенном прямом узле CDN

Ubuntu 24.04 LTS amd64. Установленная база `08d31ee` после возврата, кандидат
`3a00777c21ed017760cb7bfd0bb24478fc1f48ad`. Flash сама запускает команды,
проводит техническую проверку и автоматически публикует один отчёт.
Если не хватает терминала, sudo или доступа к панели, запрашивает сама.
Код, скрипты и критерии подготовил Codex.

Предыдущий проход принял 213 тестов и короткие замеры mpv. Страница давала
HTTP 200. Проба CDN достигала TLS, где получила два последовательных таймаута
около 10 с. Standalone с узлом из VPN-контроля тоже не прошёл. После повторного
извлечения на прямом выходе сменился CDN-узел и прошли curl 206 и mpv 134,1 с.
Сравнить новый прямой узел со служебной пробой на том же IP тогда не удалось.
[Отчёт](../reports/2026-11-20T043221Z_headless-playback.md)

Кандидат сохраняет Range 64 КиБ. В фазе запуска watchdog назначает короткий
интервал для подготовки входа и очереди, ждёт владельца NFQUEUE при закрытом
gate. Матрица сохраняет elapsed_ms и последнее наблюдавшееся состояние перед
trial_timeout. Проверь сначала прямой доступ к актуальному узлу, затем
допуск штатным job. Успех прямого curl и TLS через VPN учитывай по своим
маршрутам.

## 3. Прямой контроль и матрица с наблюдением сокетов

При off настрой Standalone multisplit с выключенной HTTPS-пробой и списком
YouTube. Через панель включи режим, дождись свежего active/without_vpn.
Проверь прежний адрес на прямом пути. Затем получи свежий URL **в этом же
режиме** и проверяй его отдельно. Один формат, два возможных узла A и B.
Новый адрес используем для допуска только после положительного контрольного
GET. Старый URL сохраняется для итогового контроля через VPN.

```bash
live
headless probe --bytes 65536 >"$D/standalone-a.json" || true
FORMAT="$D/format-direct.json"
if resolve "$FORMAT" && headless probe --bytes 65536 >"$D/standalone-b.json"; then
  DIRECT_PROBE="$D/standalone-b.json"
else
  FORMAT=$VPN_FORMAT
  DIRECT_PROBE="$D/standalone-a.json"
fi
read -r CDN_HOST PEER < <("$PY" - "$FORMAT" "$DIRECT_PROBE" <<'PY'
import ipaddress, json, sys
from pathlib import Path
from urllib.parse import urlsplit
from docs.helpers.headless_playback import read_format
url, _, _ = read_format(Path(sys.argv[1]))
probe = json.loads(Path(sys.argv[2]).read_text())
assert probe["ok"] and probe["bytes"] > 0
peer = ipaddress.IPv4Address(probe["remote_ip"])
assert peer.is_global and not peer.is_multicast
print(urlsplit(url).hostname, peer)
PY
)
headless probe --bytes 65536 --peer "$PEER" >"$D/standalone-b-pinned.json"
```

Если свежий прямой формат получить не удалось, используй пригодный A только
после положительного контроля с закреплённым IP. Если ни один прямой контроль
не прошёл, сохрани причины и верни исходную политику. При успехе укажи, совпал
ли адрес двух прямых запросов, и верни off/off перед следующим шагом.

Следующие функции задают штатную пару проб из FORMAT, ждут применённую ревизию,
запускают короткую матрицу и сохраняют её исходный job. Временный лимит
512 МиБ, check=180, retry=120, оба круга для fake_md5 и multidisorder.

```bash
ready() {
  "$PY" - <<'PY'
import time
from xgw.desync.client import Client
client = Client()
deadline = time.monotonic() + 120
while time.monotonic() < deadline:
    s = client.request("/api/zapret2/overview")["zapret2"]
    if (s["fresh"] and s["policy_matched"] and s["mode"] == s["state"] == s["engine_mode"] == "off"
            and not s["blockers"].get("selective")):
        break
    time.sleep(2)
else:
    raise SystemExit("selective_not_ready")
PY
}
set_probe() {
  "$PY" - "$FORMAT" <<'PY'
import sys
from pathlib import Path
from docs.helpers.headless_playback import read_format
from xgw.desync.client import Client
from xgw.desync.schema import YOUTUBE_DOMAINS
url, _, _ = read_format(Path(sys.argv[1]))
client = Client()
view = client.request("/api/zapret2/overview")["zapret2"]
assert view["fresh"] and view["policy_matched"] and view["mode"] == view["engine_mode"] == "off"
reply = client.request("/api/zapret2/settings", {
    "expected": view["config_key"],
    "settings": {"youtube_transport_probe": True, "domains": list(YOUTUBE_DOMAINS),
                 "probe_urls": ["https://www.youtube.com/t/terms", url],
                 "check_seconds": 180, "retry_seconds": 120, "daily_probe_mb": 512},
})
if not reply.get("ok"):
    raise SystemExit(reply.get("code", "settings_failed"))
PY
}
run_matrix() {
  local label=$1
  live || return
  ready || return
  "$PY" -m xgw.desync.client start --candidates fake_md5 multidisorder --rounds 2 \
    --seconds 1100 >"$D/$label-start.json" || return
  "$PY" - "$D" "$label" <<'PY'
import json, sys, time
from pathlib import Path
from xgw.desync.client import Client
d, label = Path(sys.argv[1]), sys.argv[2]
job_id = json.loads((d / f"{label}-start.json").read_text())["id"]
client = Client()
deadline = time.monotonic() + 1300
while time.monotonic() < deadline:
    job = client.request("/api/zapret2/overview")["zapret2"]["job"]
    if job.get("id") == job_id and job["state"] not in ("queued", "running", "restoring"):
        (d / f"{label}-job.json").write_text(json.dumps(job))
        break
    time.sleep(5)
else:
    raise SystemExit("job_timeout")
PY
  "$PY" -m xgw.desync.client matrix "$D/$label-job.json" >"$D/$label-summary.json"
}
```

Сопоставь `started_at`, `elapsed_ms` и `first_tls_timeout_ms` строки CDN
с временны́м рядом, состоянием установленного TCP-сокета и счётчиками.
Контроль `wan-b` относится к первой новой подходящей сессии. Сверь, что она
попала именно в окно CDN, и запиши TCP, TLS, FIB и разницу времени старта.
Для строк `trial_timeout` запиши `wait_stage`. Если короткий сборщик окончил
работу раньше нужной строки, состояние бери из job и укажи предел съёма.

| Наблюдение | Итог |

## 4. Длинный замер при успешном допуске

Выбери профиль из двух HTTPS pass того же job, сохрани через штатный pin,
включи Selective и дождись fresh/active. Для двух фаз 900/300 секунд,
проверки маршрута в коротких парах и суточного контроля используй команды
[раздела 4 ТЗ mpv](HEADLESS-2026-11-20.md#4-длинные-сеансы-selective-и-проверка-пути)
в уже настроенном shell. Сохраняются текущие CODE, BACKUP, HELPER, OVERLAY,
FORMAT и UNIT. Если матрица не дала профиль, длинные фазы и сутки NOT_RUN.
Отчёт о допуске, стадиях ожидания и сравнении адресов всё равно публикуется.

## 5. Возврат и автоматическая публикация

Отмени своё активное задание, если оно осталось, и верни off/off. При
недоступности панели выполни независимый restore. По умолчанию rollback.
После PASS нового пакета можно выбрать accept, чтобы сохранить только
пять новых файлов и восстановить исходную политику.

```bash
RESULT_MODE=${RESULT_MODE:-rollback}
if [[ -n ${BACKUP:-} ]] && sudo test -f "$BACKUP/restore.sh"; then
  if ! sudo test -f "$BACKUP/restore-completed"; then
    sudo /bin/bash "$BACKUP/restore.sh" "$PY" "$HELPER" "$BACKUP" "$PANEL" "$RESULT_MODE" "$OVERLAY"
  fi
  sudo sha256sum -c "$BACKUP/config-before.sha256"
  sudo test -f "$BACKUP/restore-completed"
  systemctl is-active xgw.service
  systemctl show xgw-zapret2.service xgw-nfqws2.service -p ActiveState -p MainPID
  "$PY" -m xgw.desync.client status >"$D/final.json"
fi
```

Проверь новый VPN-сеанс, панель, off/off и хэш фактически оставленных файлов.
