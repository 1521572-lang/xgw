| Требование | Итог контрактов |

| Отказ для действующего пула при пустом новом регионе | **подтверждено**: при активном пуле (маршрут на пул или режим on) и отсутствии пригодного выхода в новом регионе `select` завершается кодом 2, `panel.json` не меняется |
| Допуск нужного региона после появления пригодного выхода | **подтверждено**: после появления проверенного выхода в новом регионе выбор принимается; строгий регион исключает прежнего участника из сборки пула |
| Срочная пересборка | **подтверждено**: смена региона даёт срочную пересборку («бесплатный пул: смена региона») только когда пул несёт трафик; без трафика — обычная пересборка |
| Неполная пара регион/политика | **подтверждено**: пара только с регионом отклоняется при загрузке конфига |
| Сброс возвращает только пару регион/политика | **подтверждено**: TOML побайтно прежний, ручной выбор снят, резервный регион сохранён; сброс при отсутствии пригодного выхода в TOML-регионе отклоняется, панель не меняется |
