## Новое правило владельца: больше работы в одном ТЗ

Владелец потребовал максимально увеличить объём одного задания исполнителю и прекратить
цикл микрозаданий после каждого маленького результата. Следующий пакет объединяет все
независимые безопасные проверки, содержит автоматические переходы при частичных данных
и заканчивается одним отчётом. Не спрашивать разработчика после каждой локальной ошибки;
общие STOP идентичности/рабочего baseline/приватности сохраняются.

[ТЗ wave3t](TEST-PLAN-REAL-MACHINE-0.2.0-wave3t.md) /
[шаблон общего отчёта](TEST-REPORT-REAL-MACHINE-0.2.0-wave3t-TEMPLATE.md):

1. Сохранённые S/R свидетельства и область сопоставления.

не зависит от связи модели; dispatcher сам ждёт завершения. Ошибка необязательного
