# Карта в окне XGW

Контуры: Natural Earth, Admin 0 Countries, 1:110m, public domain.
Источник: https://github.com/nvkelso/natural-earth-vector/blob/9380cca83db5f9aef52d5e762765100745f84b27/geojson/ne_110m_admin_0_countries.geojson
Условия: https://www.naturalearthdata.com/about/terms-of-use/

В `src/xgw/gui/mapdata.py` сохранены код ISO_A2_EH (или ISO_A2), LABEL_X/LABEL_Y
и внешние кольца полигонов без Антарктиды. Контуры упрощены Douglas–Peucker
с допуском 0,18 градуса и округлены до 0,01 градуса. Внутренние кольца опущены.
JSON разбит на строковые литералы Python, чтобы штатная поставка Python-пакета
включала карту без отдельного загрузчика, QtSvg или новых сетевых зависимостей.

Проекция Mercator, широта ограничена ±80°. Масштаб одинаков по осям;
карта центрируется на приблизительной точке страны из данных Natural Earth.
Это не IP-геолокация, не точка размещения VPN-сервера и не доказательство региона выхода.
Если код неизвестен, показывается обзор Европы без маркера подключения.
В интерфейсе нет вымышленных точек других серверов. Внешние карты и шрифты не загружаются.

Компоновка вдохновлена предоставленным владельцем снимком Proton VPN.
Код, логотипы и графические ресурсы Proton VPN не копировались.
