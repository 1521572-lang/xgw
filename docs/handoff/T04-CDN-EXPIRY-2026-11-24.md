# ThinkCentre · срок жизни CDN-пробы Selective и VPN-контроля

Целевая система — **Ubuntu 24.04 LTS**. Flash сама запускает готовые
команды, проверяет результаты и публикует один обезличенный отчёт.
При недоступности терминала, pytest, OpenSSL, прав чтения или GitHub
запроси соответствующий доступ. Выполни доступные этапы независимо.

Контроллер ограничивает общим сроком подписанного CDN-адреса проверку
страницы, прямой медиазапрос и допустимый повтор после таймаута TLS.
VPN-контроль использует тот же срок адреса. Единственный допустимый
переход `302` дополнительно ограничен сроком адреса назначения. В ходе
пробы перевод системных часов назад не продлевает исходный дедлайн.

В этой проверке HTTPS выполняется через локальный CONNECT на
`127.0.0.1` с временным сертификатом. Контроллер, клиент HTTP и TLS
исполняются из закреплённого исходного кода, публикация правил Xray и
состояние nft моделируются фикстурами. Рабочий пакет остаётся в текущем
состоянии. Для этого этапа нужны только Python, pytest, OpenSSL и права
на чтение снимков шлюза. Браузер, WAN-запросы, захват трафика и запуск
плеера выходят за рамки этапа.

## Запуск на ThinkCentre

Запусти блок из рабочей копии. При необходимости укажи абсолютный путь
к существующему окружению с pytest в `XGW_TEST_PYTHON`. Для снимков
проверь право чтения конфигурации через `sudo -v`. При отсутствии
этого доступа запусти тесты и отметь снимки как `NOT_VERIFIED`.

~~~bash
bash <<'BASH'
set -euo pipefail
umask 077
. /etc/os-release
[[ $ID == ubuntu && $VERSION_ID == 24.04 && $EUID != 0 ]]
BR=integration/zapret2-batch1
CODE=e5e4d6342cc8ea42ef2d5612e6f032ffa6434162
REPO=$(git rev-parse --show-toplevel)
TEST_PY=${XGW_TEST_PYTHON:-/usr/bin/python3}
git -C "$REPO" fetch origin "$BR"
git -C "$REPO" merge-base --is-ancestor "$CODE" FETCH_HEAD
D=$(mktemp -d "$HOME/xgw-cdn-expiry.XXXXXXXX")
mkdir "$D/tree"
git -C "$REPO" archive "$CODE" src tests docs/helpers vpn_ui pyproject.toml | tar -x -C "$D/tree"
printf 'OS %s %s\nPINNED %s\nPRIVATE_ARTIFACTS %s\n' "$ID" "$VERSION_ID" "$CODE" "$D"
export PYTHONPATH="$D/tree:$D/tree/src:$D/tree/tests"
export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTEST_ADDOPTS=
cd "$D/tree"

snapshot() {
  sudo -n timeout -k 3 60 /usr/bin/python3 -I -B docs/helpers/audit_host_observe.py snapshot &&
    sudo -n sha256sum /etc/xgw/config.toml /etc/xgw/panel.json
}
run_tests() {
  local tag=$1 rc=0
  shift
  timeout -k 3 120 "$TEST_PY" -B -P -m pytest -o addopts= -p no:cacheprovider \
    --color=no --tb=short --basetemp "$D/pytest-$tag" "$@" >"$D/$tag.out" 2>&1 || rc=$?
  tail -n 18 "$D/$tag.out"
  printf '%s_EXIT %s\n' "$tag" "$rc"
  return "$rc"
}

before=0
snapshot >"$D/state.before" 2>"$D/snapshot.before.err" || before=$?
contracts=0
run_tests CONTRACTS -v --portable tests/test_zapret2.py tests/test_zapret2_panel.py \
  tests/test_selective_admission.py || contracts=$?
redirects=0
run_tests REDIRECTS -v tests/test_zapret2_redirect.py || redirects=$?
loopback=0
run_tests LOOPBACK -vv -rs --durations=4 tests/test_zapret2_expiry_transport.py || loopback=$?
if [[ $loopback == 0 ]] && ! grep -Eq '^=+ 4 passed ' "$D/LOOPBACK.out"; then
  printf 'LOOPBACK_CASES_INCOMPLETE\n'
  loopback=1
fi
after=0
snapshot >"$D/state.after" 2>"$D/snapshot.after.err" || after=$?
gateway=NOT_VERIFIED
if [[ $before == 0 && $after == 0 ]]; then
  gateway=DIFFERENT
  if cmp -s "$D/state.before" "$D/state.after"; then gateway=UNCHANGED; fi
fi
printf 'CDN_EXPIRY_GATEWAY_%s\n' "$gateway"
[[ $contracts == 0 && $redirects == 0 && $loopback == 0 && $gateway == UNCHANGED ]]
BASH
~~~

## Критерии отчёта

Укажи закреплённый SHA, версию Ubuntu, результаты и число
пройденных, упавших и пропущенных контрактов каждой фазы. Для
`CONTRACTS` проверь тест повтора с переводом часов назад, списание
трёх попыток, закрытие маршрута и отсутствие нового `last_transport_ok_at`.
Для `REDIRECTS` проверь три случая с двумя дедлайнами, сохранение
первоначального `302` при истечении срока и отсутствие URL в статусе.

В `LOOPBACK` приведи результат каждого случая отдельно.

| Случай | Критерий |
| --- | --- |
| `active_then_expired` | Локальный `206/65536` активирует тестовый Selective. Разрешение ограничено сроком URL. После истечения контроллер закрывает тестовый gate и возвращает состояние `fallback`. |
| `page_tls_stalled` | Единственный CONNECT к странице. Проба заканчивается за срок CDN и не начинает медиазапрос. Контрольный потолок теста 5 с. |
| `full_range` | Один переход `302` и финальный `206/65536` до обоих дедлайнов. |
| `redirect_tls_stalled` | Два CONNECT, остановка по более короткому сроку цели. В итоге `302` и `redirect.state=expired`. Контрольный потолок теста 4,5 с. |

При несовпавших снимках укажи изменившиеся категории — unit, параметры
слушателей, FIB или хеши настроек. Сырые журналы, PID, адреса, значения
хешей, ключи и тестовый сертификат оставь на машине. При ошибке укажи
конкретную фазу и обезличенную причину. Исполнитель проводит техническую
проверку по заданию. Изменения кода и сценариев остаются за Codex.

Оценка прямого доступа к YouTube, обновление подписанного адреса в
активном шлюзе и маршрутизация реального видео продолжаются по текущему
плану. Для изменения допуска требуется отдельный результат живого теста.
[Последний сопоставимый CDN-отчёт](../reports/2026-11-24T172518Z_standalone-cdn-tls.md)

## Автоматическая публикация

Подставь абсолютный путь к обезличенному Markdown-отчёту в `REPORT_SRC`.
Запусти публикацию также при частичном результате и верни ссылку на коммит.

~~~bash
bash -s -- "$REPORT_SRC" <<'BASH'
set -euo pipefail
umask 077
REPORT_SRC=$1
BR=integration/zapret2-batch1
[[ $REPORT_SRC == /* && -s $REPORT_SRC ]]
REPO=$(git rev-parse --show-toplevel)
PUB=$(mktemp -d "$HOME/xgw-cdn-expiry-report.XXXXXXXX")
git -C "$REPO" fetch origin "$BR"
git -C "$REPO" worktree add --detach "$PUB/repo" FETCH_HEAD
trap 'git -C "$REPO" worktree remove "$PUB/repo" && rmdir -- "$PUB"' EXIT
cd "$PUB/repo"
REPORT="docs/reports/$(date -u +%Y-%m-%dT%H%M%SZ)_t04-cdn-expiry.md"
test ! -e "$REPORT"
cp -- "$REPORT_SRC" "$REPORT"
git add -- "$REPORT"
git diff --cached --check
git commit -m 'Report ThinkCentre Selective CDN probe expiry'
if ! git push origin "HEAD:refs/heads/$BR"; then
  git fetch origin "$BR"
  git rebase FETCH_HEAD
  git push origin "HEAD:refs/heads/$BR"
fi
git fetch origin "$BR"
git merge-base --is-ancestor HEAD FETCH_HEAD
printf 'PUBLISHED %s %s\n' "$(git rev-parse HEAD)" "$REPORT"
BASH
~~~
