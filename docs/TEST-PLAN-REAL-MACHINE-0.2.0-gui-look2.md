# Окно XGW: крупнее подписи, закреплённый сервер первым; отложенный снимок пачек

Выполнять после отчёта gui-look (PASS, 8d2c8e8): на машине установлен 771cde3. Новый код
fe1c2bac1ca294b933ca7943bae0509502a5c5bd (ASSUMPTIONS п. 329).

Что изменилось в окне:
- подписи под значками слева, строки под именами серверов, RTT и «нет замера» крупнее
  (владелец: «несоразмерно мелкие»), имена серверов крупнее, навигация шире;
- сервер, через который идёт трафик (в том числе закреплённый вручную запасной), — всегда
  первая карточка справа, в рамке, с меткой «В РАБОТЕ», тот же, что слева;
- неактивная большая кнопка VPN — прозрачная с пунктирной рамкой;
- в узком окне у строки сервера вместо слова состояния — цветная точка, слово в подсказке;
- нестабильный тест клиента исправлен (демо-панель отдавала состояние раньше первой записи).

Критерии:

- тесты окна на машине (offscreen) — `25 passed` в каждом из трёх прогонов;
- установка, health rc0, совпадение пакета;
- подписи читаются без усилия, ничего не обрезано по краю при 1440×900 и 1024×720;
- при ручном выборе сервера первая карточка в рамке совпадает с сервером слева;
- тёмная тема на новом виде (её переключает владелец сам, мышью);
- снимок пачек new-batch — не раньше чем через 4 ч после установки, только чтение.

Разрешены терминал, чтение status/diag/logs, запуск окна и демо. WAN, LAN, Tailscale,
подписки, пул, pin и настройки не менять; кнопку VPN на настоящем шлюзе не нажимать. В отчёте
— только числа, слова состояний и признаки, без имён серверов, стран, адресов, доменов, кода
входа и cookie. Снимки экрана в репозиторий не добавлять.

## 2. Обычная установка с локальным возвратом

Нужно согласие владельца на обычную установку CODE и на условный возврат штатным установщиком
BASE, если установка или on/HTTPS откажут. Нет согласия — INSTALL_NOT_RUN. Записать время
окончания установки (часы:минуты) — от него отсчитываются 4 ч шага 5.

```sh
sudo sh -s -- "$TARGET" "$PREV" "$HELPER" <<'SH'
umask 077
d=/run/xgw-look2
mkdir -m 700 "$d" || exit 3
sh "$1/packaging/install.sh" --yes >"$d/install.log" 2>&1
i=$?; echo "$i" >"$d/install.rc"
h=3; n=0
while [ "$n" -lt 9 ]; do
    if python3 -I "$3" health >"$d/health.json" 2>&1; then h=0; break; fi
    n=$((n + 1)); sleep 10
done
echo "$h" >"$d/health.rc"
if [ "$i" -ne 0 ] || [ "$h" -ne 0 ]; then
    sh "$2/packaging/install.sh" --yes >"$d/return.log" 2>&1
    echo "$?" >"$d/return.rc"
    python3 -I "$3" health >"$d/return-health.json" 2>&1
    echo "$?" >"$d/return-health.rc"
fi
date +%H:%M
SH
sudo cat /run/xgw-look2/install.rc /run/xgw-look2/health.rc
match_package "$TARGET"
```

Ожидаются 0 и 0 и совпадение пакета. При возврате снять health и закончить с PARTIAL (шаг 5
всё равно выполнить через 4 ч).

## 3. Окно владельца

От имени владельца (не sudo): `xgw gui &`. Окно открывается во «Обзор» без пароля. Записать
(да/нет, без имён):

1. Подписи под значками слева и строки под именами серверов читаются без усилия; подписи
   разделов не обрезаны.
2. Первая карточка справа — в рамке, с меткой «В РАБОТЕ»; это тот же сервер, что слева (при
   ручном выборе слева «выбран вручную»). Если ручного выбора нет — так же для основного.
3. 1024×720 и 1440×900: ничего не уходит за край; в узком окне у строк серверов вместо слова
   состояния цветная точка, при наведении — подсказка со словом.
4. Тема: владелец сам мышью «Тема» → «Тёмная», затем «Светлая», затем «Как в системе» —
   всё читаемо, значки перекрашены (если у владельца нет времени — NOT_RUN).

Машинное зрение и xdotool — только по прямому поручению владельца. Закрыть окно крестиком,
затем `systemctl is-active xgw` и `sudo python3 -I "$HELPER" health` (active, true).

## 5. Снимок пачек new-batch (не раньше чем через 4 ч после установки шага 2)

Каждая установка перезапускает демон, а первое обновление подписки после запуска принимает
все новые серверы сразу, — поэтому прежние снимки (0,8 и 1,3 ч) пачки не показали. Между
установкой шага 2 и этим шагом машину не переустанавливать и демон не перезапускать. Только
чтение:

```sh
cd ~/xgw
systemctl show xgw -p ActiveEnterTimestamp
sudo python3 -I "$HELPER" generations; printf 'generations rc=%s\n' "$?"
```

Записать `hours_since_start`, `refreshes`, `switches`, `switch_parts`, `composition`,
`new_waiting_lines`, `new_waiting_max`, `new_batches`, `new_admitted`, `batch_reasons`,
`copies_max`. Ожидается при `hours_since_start` ≥ 4: если подписка давала новые серверы —
`new_waiting_lines` > 0 и не больше одной-двух пачек за 6 ч; смен поколения заметно меньше 2,5
в час. Если владельцу нужно перезапустить демон раньше — записать фактические часы и PARTIAL
только для этого шага.
