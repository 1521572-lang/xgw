# Программа испытаний XGW на реальной машине: переход на Xray 26.10.21

**Для исполнителя.** Выполняй шаги строго по порядку. В каждом шаге — команда (копируй
целиком), «Ожидается» и «Если не так». Ничего не придумывай сверх написанного. Не уверен —
остановись и спроси заказчика. Выводы команд сохраняй в файлы, как написано: из них
собирается отчёт (§8). Пути в командах — только абсолютные (`$HOME/xgw-xr-test/…`).

Машина: ThinkCentre, Ubuntu 24.04.5 LTS, шлюз дома. Стоит XGW с кодом `main` (с
исправлениями issue #1, версия 0.1.17) на Xray 26.10.10; Tailscale подключён, Funnel
включён, телефон заказчика (Galaxy S25 Ultra) привязан к приложению XGW. Клон репозитория —
`~/zcod/xgw`. Номер версии XGW новый код не меняет (`xgw 0.1.17`).

Что изменилось (ASSUMPTIONS п. 226):

1. **Xray 26.10.21.** 21.10.2026 разработчики Xray отозвали выпуски 26.10.10 и 26.10.17:
   в них корневые сертификаты, ключи которых взломаны. С GitHub их убрали, и установка
   XGW с 26.10.10 перестала работать. XGW теперь ставит только 26.10.21; установленный
   26.10.10 — FAIL в `xgw diag`. В 26.10.21 у входа TUN свой сетевой стек вместо
   прежнего — это трафик самой машины при `capture.method = "tun"` и будущий VPN телефона.
2. **Установка перезапускает Xray, если заменила его файл.** Раньше при установке поверх
   работающего шлюза новый файл Xray ложился на место, а процесс продолжал работать на
   прежнем до перезагрузки.

Цели:

1. Снимок до обновления, копия прежнего Xray для отката (шаг 1.2).
2. Новый код и Xray 26.10.21; работает именно новый процесс (шаг 2).
3. Интернет в домашней сети и у самой машины, приложение на телефоне (шаг 3).
4. Замер скорости из приложения (шаг 4).
5. Полчаса без сбоев (шаг 5), итог (шаг 6), отчёт (§8).

## 0. Запрещено

- `xgw net down`, `xgw disable`, `xgw uninstall`, `reboot`, сон машины, `install.sh --force` —
  **никогда**.
- Команды Tailscale, кроме `tailscale status`; Funnel, Serve и SSH не трогать.
- Запуск, остановка и перезапуск `tailscaled`, `xgw`, `xgw-xray`, `xgw-singbox`, `xgw-net`,
  `xgw-dhcp`, `systemd-resolved`, NetworkManager, `ssh`/`sshd` — кроме §7 (откат).
- Ручные команды `nft` (кроме `nft list`), `ip` (кроме `ip … show`), `iptables`,
  `sysctl -w`.
- Отключать WAN или LAN, кабели, Wi-Fi роутера.
- Править `/etc/xgw/config.toml`, `/etc/xgw/panel.json`, `/etc/systemd`, файлы в `/opt/xgw`
  (кроме §7).
- Нажимать в панели или приложении что-либо, кроме того, что написано в шагах.
- Править код XGW. Коммитить что-либо, кроме отчёта (§8). Файлы из `~/xgw-xr-test` в Git
  **не класть**.
- Писать в отчёт: адреса tailnet (`100.x.y.z`), имена `*.ts.net`, имена устройств и
  пользователей, почту, внешние IP, токены, адреса подписок, UUID, IP и домены серверов
  VPN, MAC-адреса. Внутренние подсети (`192.168.x.0/24`) и коды стран — можно.

Ожидается: «Xray 26.10.21 в коде: есть» и `__version__ = "0.1.17"`. Записать хеш.
Если ветки `xray-26.10.21` нет или строки «Xray 26.10.21 в коде: есть» нет: **стоп**,
сообщить заказчику.

Шаг 2.2. Установка (из каталога кода):

```bash
cd ~/zcod/xgw && date '+%F %T' | tee "$HOME/xgw-xr-test/install-time.txt" && sudo sh packaging/install.sh --yes 2>&1 | tee "$HOME/xgw-xr-test/after/install.txt" | tail -25; echo "код ${PIPESTATUS[0]}"; cd "$HOME/xgw-xr-test"
```

Ожидается: «код 0»; строки «Xray-core v26.10.21 — /opt/xgw/xray», «Xray перезапущен на
новой версии» (или «Xray запущен: участников …» — тоже годится, если конфиг поменялся) и
«демон xgw запущен».

Если код не 0 или «Xray не загружен: …»: **стоп**, сохранить вывод, выполнить §7, сообщить
заказчику.

Шаг 2.3. Работает новый Xray:

```bash
sleep 20; PID=$(systemctl show -p MainPID --value xgw-xray); echo "процесс Xray: $(sudo readlink /proc/$PID/exe)"; sudo /opt/xgw/xray/xray version | head -1; systemctl show xgw-xray -p ActiveEnterTimestamp; cat "$HOME/xgw-xr-test/install-time.txt"; systemctl is-active xgw xgw-xray xgw-net xgw-dhcp xgw-singbox tailscaled; sudo xgw diag > "$HOME/xgw-xr-test/after/diag-install.txt"; tail -1 "$HOME/xgw-xr-test/after/diag-install.txt"; grep -E '^\S+ +Xray' "$HOME/xgw-xr-test/after/diag-install.txt" | head -5
```

Ожидается:

- «процесс Xray: /opt/xgw/xray/xray» — **без** слова `(deleted)`;
- «Xray 26.10.21 (Xray, Penetrates Everything.) 1b1647c (go1.27.3 linux/amd64)»;
- время `ActiveEnterTimestamp` — позже времени установки;
- службы — как в шаге 1.2;
- «FAIL — 0»; строка Xray — OK с версией 26.10.21.

Если не так:

- `(deleted)` в строке процесса — **дефект «Xray не перезапущен после установки»**: шлюз
  работает на старой версии. Записать и **спросить заказчика**, перезапустить ли Xray
  (`sudo systemctl restart xgw-xray`); после перезапуска — повторить шаг 2.3.
- Xray FAIL — записать строку целиком, выполнить §7, сообщить заказчику.

- Интернет дома пропал или Xray не поднимается — вернуть прежний Xray (26.10.10) и

  Ожидается: «Xray 26.10.10 …», состояние как в шаге 1.2. `xgw diag` после отката покажет
  FAIL «XGW работает только с Xray 26.10.21» — так и должно быть, записать. Сообщить
  заказчику.
- Установка не прошла (код не 0) — сеть и прежний Xray не тронуты; ничего не откатывать,
  записать вывод, сообщить заказчику.
