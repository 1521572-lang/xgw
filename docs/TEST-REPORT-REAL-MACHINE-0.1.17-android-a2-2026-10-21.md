## Итог

Приложение установилось на телефон (Success, net.xgw.android 0.1.17-a2) и привязалось
к шлюзу камерой по QR-коду («сразу получилось», экран пульта через 97 с; в панели телефон
отмечен «заходил»). Пульт показывает состояние, совпадающее с `xgw status` (HEALTHY →

устройства дома; кнопки «Проверить запасные» и «Замерить скорость» нажимаются, события
«с телефона …» появляются в журнале шлюза. Ручной выбор сервера (Турция) проходит через
вопрос с подтверждением и отражается в `xgw status`, возврат автовыбора — одной кнопкой.
Вопрос «Выключить VPN шлюза?» показывается с предупреждением; после «Отмена» перехват
остался включён. По мобильной сети (Wi-Fi выключен, чужой VPN выключен) пульт работает,
состояние обновляется, чипа «Нет связи» нет. Отвязка в панели мгновенно видна приложению
(«Шлюз не принят запрос» через 2 с, кнопка «Привязать заново»); повторная привязка
выполнена ссылкой. Падений приложения — 0.

## Наблюдения

1. «Нет связи со шлюзом (connection closed)» на экране около 20:06–20:19: телефон ушёл
   в мобильную сеть с включённым чужим VPN (tуннель tun0 на телефоне); сообщение приложения
   соответствует замыслу («через VPN шлюз недоступен — приложение так и говорит»). После
   выключения чужого VPN связь восстановилась сама. Со стороны шлюза — HEALTHY, LAN работал.
2. В 20:07:00 и 20:07:02 демон дважды записал «правила сети не были загружены — загружены
   заново» (после «события сети» — поднятие xgwtun0). На работу это не повлияло: перехват
   включён, состояние HEALTHY, интернет в LAN был. Для кода main это штатная самопроверка
   пути LAN из issue #1.
3. Кнопка замера в приложении всё время испытания показывала «Замеряю скорость…» — на шлюзе
   шли фоновые замеры всех живых серверов (issue #1). ТЗ это описывает для кода main:
   прогресс «N из M» в приложении появится после слияния А2 в main. Событие
   «с телефона …: Замеряю скорость…» не зафиксировано — запрос кнопки пришёл, когда замер
   уже шёл.
4. Повторная привязка ссылкой (7.2) прошла без диалога «Привязать телефон?» — приложение
   сразу показало пульт (первая привязка камерой диалог показывала). Уточнить на стороне
   приложения: нужен ли диалог подтверждения при открытии ссылки.
5. Первая попытка нажать кнопку замера по «speed» не нашла кнопку (её текст в состоянии
   замера — «Замеряю скорость…»); повторное нажатие по id успешно. Состояние экрана «Dozing»
   один раз дало пустой снимок текстов — после побудки экрана чтение восстановилось.
6. «Устройства дома» показывает имена всех устройств LAN; в отчёте имена скрыты, телефон —
   по модели.
