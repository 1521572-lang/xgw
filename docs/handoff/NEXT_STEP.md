# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** сначала проверь установленную базу. Помощник
`4c9379e` ожидает две отдельные успешные прямые пробы одного CDN URL
с `206/65536` и подтверждение клиентского правила. При fallback
заверши опыт восстановлением политики. При успешном контроле
верни режим off, установи проверенный кандидат `39421a6` и проведи
одно наблюдение ротации во время просмотра.
[Готовое ТЗ](SELECTIVE-DIRECT-PREFLIGHT-2026-11-21.md)

В r4 тесты, установка и откат кандидата прошли. Прямой запрос снова
завершился TLS-таймаутом. VPN-контроль получил два редиректа подряд,
а минутой позже тот же URL через VPN дал `206/65536`. Окно ротации
не состоялось.
[Последний отчёт](../reports/2026-11-21T003445Z_selective-route-status-r4.md)

Код и тесты подготовлены Codex. Flash сама запускает проверку на
машине, при недоступном терминале, панели или sudo запрашивает доступ
и при любом исходе публикует обезличенный отчёт в `integration/zapret2-batch1`.
