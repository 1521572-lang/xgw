## `APPLIER`

`APPLIER=0`: **30 passed, 0 failed, 0 skipped** (9,15 с). Маркер `api-dirty` создаётся до первого вызова API и остаётся после прерывания между записью файла и запуском службы; при отказе запуска сохранённая предыдущая версия используется для отката; при окончательном отказе маркер остаётся. Отдельные контракты: маркер до первого изменения, маркер и прежний конфиг после прерванного перезапуска, сохранение last-good при неудачном перезапуске с тем же конфигом.

- `ROLLBACK_CONTROL=0`, `ROLLBACK_PRESENT=PASS`: при оставшемся теге закрытие кандидата откладывается, прежний путь отвечает.
