   убран через 21 с, лишний маршрут в таблице XGW — через 36 с (лимит 60); с помеченным пакетом

   «local (в Xray, TPROXY)».
3. **Чужие правила маршрутизации**: правило с меткой XGW, но с uidrange (pref 101), пережило
   перезагрузку правил — шлюз трогает только свои правила; правило раньше XGW (pref 50) видно
   предупреждением в `xgw diag` («помеченный трафик может уйти мимо VPN») и помощником

   0.31–0.41). ТЗ ожидало рост на 1–2 с, фактически ~2.3–4.6 с (теперь читаются и наборы, в
   том числе российские сети — десятки тысяч сетей); повторная проверка с кэшем осталась
   дешевле первой в ~20 раз.
5. **«Не по ожиданию» (шаги 3.1, 3.2): флаг «тестовое правило с uidrange (pref 101): нет»** при

   причём без пометки «с другими условиями» — ключа `uidrange` в выводе нет). Предположение:
   `ip -j rule show` этого iproute2 не включает ключ `uidrange` в JSON. На проверяемое
   поведение не влияет: правило пережило загрузку правил (шаг 3.2) и удалено только мной
   (шаг 3.4) — то и другое видно в том же выводе помощника.
