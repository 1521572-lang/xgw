# Следующая проверка XGW на ThinkCentre

**Действующее задание Flash** — [CDN-проба, mpv и проверка маршрута](HEADLESS-2026-11-20.md). База шлюза Ubuntu 24.04 LTS — `08d31ee`. Кандидат `3788dd2948c8d37478bc47cb49451d48a8ec2bff`. Испытание включает обратимую установку трёх модулей.

В последнем проходе mpv с прямым URL доиграл короткие замеры. Короткий job дал три fallback и один timeout, поэтому Selective не измерялся. Новый проход проверяет Range 64 КиБ и HTTP 206, показывает причины каждой строки и измеряет длинный поток тем же mpv после допуска. [Отчёт](../reports/2026-11-20T004500Z_playback-passive.md)

Flash сама выполняет техническую проверку и публикует один новый обезличенный отчёт при любом исходе. Codex отвечает за системный код, инструменты, тесты и разбор отчёта.
