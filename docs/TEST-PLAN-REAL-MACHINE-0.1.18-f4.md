# Проверка XGW: свой сервер устройства (Ф4)

**Для исполнителя.** Выполняй шаги строго по порядку. В каждом шаге — команда (копируй
целиком), «Ожидается» и «Если не так». Ничего не придумывай сверх написанного. Не уверен —
остановись и спроси заказчика. Выводы сохраняй в файлы, как написано (`$HOME/xgw-f4/…`).

Машина: ThinkCentre, Ubuntu 24.04.5 LTS, KDE Plasma (X11), браузер Chromium, XGW 0.1.18. Клон —
`~/zcod/xgw`. Код — ветка `split-f4` (от `netcheck-f3`; версия остаётся 0.1.18).

Что нового (ASSUMPTIONS п. 245). В карточке «Устройства» под адресом каждого устройства —
список «Сервер: авто / …»: устройство можно пустить через свой сервер (например, другой
страны), остальные идут через основной. Российские сайты у него по-прежнему напрямую; если
выбранный сервер недоступен — временно через основной. Здесь, у разработчика, Xray с такими
правилами и панель с устройствами не проверялись — это делает эта программа.

## 0. Запрещено

- `xgw net down`, `xgw disable`, `xgw uninstall`, `reboot`, сон машины, `install.sh --force` —
  **никогда**. Запуск, остановка и перезапуск служб `xgw*`, `tailscaled`, NetworkManager,
  `ssh`; ручные `nft` (кроме `nft list`), `ip`, `iptables`, `tc`, `sysctl -w`.
- Править `/etc/xgw` (в том числе `panel.json`), `/opt/xgw`, `/var/lib/xgw`, `/etc/systemd`,
  код XGW. Всё меняет заказчик в панели. Коммитить что-либо, кроме отчёта (§6).
- Писать в отчёт: адреса tailnet, имена `*.ts.net`, имена устройств и пользователей (имя
  пользователя → `<user>`), внешние IP, токены, адреса подписок, IP и домены серверов VPN.
  Можно: адреса устройств в домашней сети (`192.168.…`), MAC, теги и имена серверов из
  панели, отпечатки серверов (8 знаков), страны.

Шаг 1.2. Папка и помощник проверки (только читает: маршруты устройств из `panel.json` без
подписок, применённый конфиг Xray и метрики Xray):

```bash
mkdir -p "$HOME/xgw-f4" && chmod 700 "$HOME/xgw-f4" && cd "$HOME/xgw-f4" && cat > f4check.py <<'EOF'
"""Ф4: что шлюз собрал для устройств со своим сервером. Только читает: panel.json (маршруты
устройств, без подписок), применённый конфиг Xray и метрики Xray."""
import json
import sys

sys.path.insert(0, "/opt/xgw/lib")
from xgw import config, managed  # noqa: E402
from xgw.paths import Paths  # noqa: E402
from xgw.xraycore import metrics  # noqa: E402

paths = Paths.from_env()
cfg, _warnings = config.load(paths.config_file)
routes = managed.load(managed.path_for(paths.config_file))[0]["routes"]
print(f"в panel.json устройств со своим сервером: {len(routes)}")
for item in routes:
    print(f"  {item['ip']} {item['mac']} -> сервер {item['server']}")
xray = json.loads(paths.xray_config_file.read_text(encoding="utf-8"))
routing = xray.get("routing") or {}
devices = [item for item in routing.get("balancers") or [] if item.get("tag", "").startswith("dev-")]
try:
    vars_ = metrics.fetch_metrics(cfg.xray.metrics_port)
except Exception as exc:  # noqa: BLE001 — помощник: показать и идти дальше
    print(f"метрики Xray не прочитаны: {exc}")
    vars_ = {}
alive = metrics.parse_observatory(vars_)
stats = ((vars_.get("stats") or {}).get("outbound") or {}) if isinstance(vars_, dict) else {}
print(f"балансировщиков устройств в конфиге Xray: {len(devices)}")
for balancer in devices:
    tag, ip = balancer["selector"][0], balancer["tag"].removeprefix("dev-")
    rule = any(item.get("source") == [ip] and item.get("balancerTag") == balancer["tag"]
               for item in routing.get("rules") or [])
    state = alive.get(tag)
    word = "нет данных" if state is None else ("жив" if state["alive"] else "мёртв")
    mbytes = int((stats.get(tag) or {}).get("downlink") or 0) // 1048576
    print(f"  {balancer['tag']}: сервер {tag}, запасной выход {balancer.get('fallbackTag')}, "
          f"правило {'есть' if rule else 'НЕТ'}, ядро: {word}, принято {mbytes} МБ")
loop = any(item.get("tag") == "to-main" and item.get("protocol") == "loopback"
           for item in xray.get("outbounds") or [])
print(f"выход to-main (loopback): {'есть' if loop else 'нет'}; пробы ядра: "
      f"{(xray.get('burstObservatory') or {}).get('subjectSelector')}")
EOF
sha256sum f4check.py | cut -c1-16; sudo xgw status | grep -E '^Состояние|Перехват:' | tee before.txt
```

Ожидается: `035a18702014954a`; `Состояние: HEALTHY …`, `Перехват: включён …`. Записать как
есть.

Если не так: сумма другая — выполнить шаг заново, скопировав команду целиком; снова другая —
**стоп**, сообщить заказчику. Не `HEALTHY` — записать (это до установки) и продолжить.

Шаг 3.3. Через минуту — что собрал шлюз:

