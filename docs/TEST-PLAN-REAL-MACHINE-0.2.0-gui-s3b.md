## 2. Окно прежней версии и установка

До установки открыть окно текущей версии от владельца: `xgw gui &` — оно остаётся открытым.
Нужно согласие владельца на установку CODE и на условный возврат штатным установщиком BASE.
Нет согласия — INSTALL_NOT_RUN. Установка — блоком шага 2 ТЗ gui-s3 с каталогом
`/run/xgw-s3b` вместо `/run/xgw-s3` (тот же порядок: install, health до 9 попыток, возврат при
сбое), затем:

```sh
sudo cat /run/xgw-s3b/install.rc /run/xgw-s3b/health.rc
match_package "$TARGET"
```

Ожидаются 0 и 0 и совпадение пакета. При возврате снять health и закончить с PARTIAL.

## 3. Закрытие окна — два раза

Первый раз — окно, которое заменит открытое (как в отчёте gui-s3 зависло именно оно). От
владельца, в терминале:

```sh
xgw gui 2>"$HOME/xgw-gui-close-1.txt" & P=$!
sleep 5; pgrep -u "$USER" -fc 'xgw gui'
```

Ожидается: старое окно закрылось само, процессов `xgw gui` — 1. Владелец закрывает окно
крестиком мышью. Затем:

```sh
sleep 3; kill -0 "$P" 2>/dev/null && echo "через 3 с: работает" || echo "через 3 с: вышел"
sleep 15; kill -0 "$P" 2>/dev/null && echo "через 18 с: работает" || echo "через 18 с: вышел"
grep -c 'Timeout' "$HOME/xgw-gui-close-1.txt"
```

Не вышел и через 18 с — `kill -USR1 "$P"; sleep 1; kill "$P"`. В отчёт: два слова «вышел» /
«работает», число строк Timeout; если есть Timeout или USR1 — из файла только строки вида
`File ".../xgw/gui/….py", line N in имя` (до 15 строк, каталог → `~`).

Второй раз — после обхода: `xgw gui 2>"$HOME/xgw-gui-close-2.txt" & P=$!`; машина кликает
«Серверы», вкладку «Бесплатный пул», вкладку «Подписки», раздел «Подписки», раздел «Обзор»;
владелец мышью открывает меню «…» у любой карточки в «Серверах» и закрывает его Esc, наводит
курсор на точку строки сервера (шаг 4). Затем крестик и те же три команды проверки, что выше.
Файлы `xgw-gui-close-*.txt` в репозиторий не класть.
