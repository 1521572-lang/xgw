# Окно XGW: новый вид (как у VPN-клиентов) и строка «Перехват»

Выполнять после отчёта gui-s12 (PASS, cd55ed6): на машине установлен 9ed094f. Новый код
771cde3f2341a7f6ac440adcb02e9e296c2360b2.

Владелец не принял вид «Обзора» из этапов 1–2 («таблицы как в Word и Excel»): нужен вид
современного VPN-клиента. Окно переделано (ASSUMPTIONS п. 328, docs/GUI-NATIVE.md):
- узкая навигация со значками, внизу «Тема»;
- слева панель подключения: слово защиты («ЗАЩИЩЕНО» / «НЕ ЗАЩИЩЕНО»), большой щит с
  подсветкой цветом состояния, сервер в работе со значком страны, плитки «Скорость», «RTT»,
  «Проба», большая кнопка VPN, версии;
- справа серверы карточками: основной первым в рамке с меткой «В РАБОТЕ», дальше живые по
  скорости, запасные отдельно; сверху предупреждение с кнопками помощи, когда шлюзу плохо;
  внизу «Защита сети».

Исправлена косметика gui-s12: при выключенном VPN строки «Перехват: …» нет совсем, сразу после
включения она пишет «Перехват: включается…», через опрос — «Перехват: работает…». Действия и
запросы окна к панели не менялись.

Критерии:

- шаг 1: `generations` записан (дозапись new-batch, только чтение);
- тесты окна на машине (offscreen) — `26 passed`;
- установка, health rc0, совпадение пакета;
- новый вид: всё перечисленное выше видно, ничего не обрезано по краю окна при 1440×900 и при
  1024×720, тёмная и светлая темы читаемы;
- слово защиты, метка состояния и данные сервера совпадают с `xgw status`;
- строка «Перехват» не противоречит заголовку VPN (шаг 4, только с согласия владельца);
- демо-сцены work, trouble, empty открываются без root.

Разрешены терминал, чтение status/diag/logs, запуск окна и демо, снимки экрана для себя.
WAN, LAN, Tailscale, подписки, пул, pin и настройки не менять. Кнопку VPN в настоящем окне —
только с отдельного согласия владельца (шаг 4). В отчёте — только числа, слова состояний и
признаки, без имён серверов, стран, адресов, доменов, кода входа и cookie. Снимки экрана в
репозиторий не добавлять (на них имена серверов).

## 2. Обычная установка с локальным возвратом

Нужно согласие владельца на обычную установку CODE и на условный возврат штатным установщиком
BASE, если установка или on/HTTPS откажут. Нет согласия — INSTALL_NOT_RUN.

```sh
sudo sh -s -- "$TARGET" "$PREV" "$HELPER" <<'SH'
umask 077
d=/run/xgw-look
mkdir -m 700 "$d" || exit 3
sh "$1/packaging/install.sh" --yes >"$d/install.log" 2>&1
i=$?; echo "$i" >"$d/install.rc"
h=3; n=0
while [ "$n" -lt 9 ]; do
    if python3 -I "$3" health >"$d/health.json" 2>&1; then h=0; break; fi
    n=$((n + 1)); sleep 10
done
echo "$h" >"$d/health.rc"
if [ "$i" -ne 0 ] || [ "$h" -ne 0 ]; then
    sh "$2/packaging/install.sh" --yes >"$d/return.log" 2>&1
    echo "$?" >"$d/return.rc"
    python3 -I "$3" health >"$d/return-health.json" 2>&1
    echo "$?" >"$d/return-health.rc"
fi
printf '%s\n' 'Проверьте сохранённые rc'
SH
sudo cat /run/xgw-look/install.rc /run/xgw-look/health.rc
match_package "$TARGET"
```

Ожидаются 0 и 0 и совпадение пакета. При возврате снять health и закончить с PARTIAL.

## 3. Новый вид в окне владельца

В графическом сеансе владельца, от его имени (не sudo):

```sh
xgw gui &
sudo xgw status --json | python3 -c "import json,sys; s=json.load(sys.stdin); print(s.get('state'), (s.get('capture') or {}).get('mode'))"
```

Окно должно открыться сразу во «Обзор» без пароля (вход сохранён с gui-s12). Если просит
войти — войти, как в gui-s12, и записать это. Пройти и записать (да/нет, без имён):

1. Слева узкая панель: значки и подписи 7 разделов и «Тема», подписи не обрезаны.
2. Слово защиты вверху слева: при VPN включён и HEALTHY/DEGRADED — «ЗАЩИЩЕНО» зелёным; щит
   того же цвета с галочкой; под словом «VPN включён» и что идёт через VPN.
3. Строка «Перехват: работает…» есть и не противоречит заголовку.
4. Сервер в работе: значок страны (флаг или код), имя, «выбран …»; плитки «Скорость», «RTT»,
   «Проба» с числами, совпадают с карточкой браузерной панели (скорость и задержки).
5. Справа «Серверы» и «работают N из M»; N и M совпадают с `xgw status` (живые и все в
   работе); первая карточка в рамке с меткой «В РАБОТЕ» — это тот же сервер, что слева.
6. Метка состояния: при HEALTHY — плашка «✓ Серверы в порядке» справа вверху; при другом
   состоянии — вместо неё цветное предупреждение со словом состояния и кнопками помощи.
7. «Защита сети» внизу справа: что идёт через VPN, «при сбое Xray …», «Мимо VPN».
8. Тема: «Тема» → «Светлая», «Тёмная», «Как в системе» — всё читаемо, значки перекрашены.
9. Размер окна 1024×720 (минимальный) и 1440×900: ничего не уходит за край, длинные имена
   обрезаются многоточием, метка «В РАБОТЕ» в узком окне может скрыться (рамка остаётся).
10. Раздел «Серверы» слева — карточка «Открыть в браузерной панели», кнопка открывает панель.

Если менять размер окна или кликать будет исполнитель (машинное зрение, xdotool) — только по
прямому поручению владельца, как в gui-s12. Окно закрыть крестиком, затем:

```sh
systemctl is-active xgw
sudo python3 -I "$HELPER" health
```

Ожидаются active и health true.

## 4. Строка «Перехват» при переключении VPN (только с согласием владельца)

Если владелец согласен на кратковременное выключение VPN: открыть `xgw gui`, нажать
«Выключить VPN». Записать сразу и через 5 с: слово защиты («НЕ ЗАЩИЩЕНО»), заголовок «VPN
выключен» и есть ли строка «Перехват» (ожидается: её нет ни сразу, ни потом). Нажать «Включить
VPN»: сразу после — «ВКЛЮЧАЮ…» / «Включаю…», затем «ЗАЩИЩЕНО»; строка «Перехват: включается…»
может мелькнуть на один опрос, потом «Перехват: работает…». Сразу после —
`sudo python3 -I "$HELPER" health` (true). Нет согласия — NOT_RUN.
