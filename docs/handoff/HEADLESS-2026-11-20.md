# Приёмка CDN-пробы и воспроизведения через mpv

ThinkCentre, Ubuntu 24.04 LTS amd64. База шлюза `08d31ee`, кандидат
`3788dd2948c8d37478bc47cb49451d48a8ec2bff`. Flash сама запускает команды,
проверяет результат и автоматически публикует один обезличенный отчёт.
Доступ к терминалу, sudo и панели запрашивает сама при необходимости.
Исходники, инструменты и критерии готовит Codex.

В последнем проходе mpv с прямым URL доиграл 150 с. Короткий job дал три
fallback и один timeout. Окна curl в Standalone и пробы Selective различались.
Кандидат запрашивает 64 КиБ через Range на /videoplayback и засчитывает
успешный 206 с телом. Проверка страницы, бюджет и два HTTPS-раунда для pin
сохраняются. В сводку матрицы добавлены причина и стадии проб.

```bash
test "${#VIDEO}" -eq 11
resolve() {
  timeout 70 yt-dlp --no-playlist --socket-timeout 10 --retries 1 --extractor-retries 1 \
    -f 'bv[height=720][protocol=https]' --dump-single-json \
    "https://www.youtube.com/watch?v=$VIDEO" >"$1" 2>"$1.log"
}
FORMAT="$D/format.json"
resolve "$FORMAT"
headless() { "$PY" -m docs.helpers.headless_playback "$FORMAT" "$@"; }
probe() {
  headless probe --bytes 65536 >"$D/$1-range.json" || true
  headless probe --bytes 10485760 >"$D/$1-burst.json" || true
}
player() {
  local name=$1 seconds=$2
  shift 2
  headless play --seconds "$seconds" --samples "$D/$name-player.jsonl" "$@" >"$D/$name-verdict.json"
}
probe vpn-before
player vpn-before 120 --peers || echo VPN_PLAYER_PARTIAL
```

Сохрани метрики 64 КиБ и 10 МиБ, TLS, TTFB, HTTP и частичный результат mpv.
Ошибка извлечения оформляется отдельно. При рабочем медиазапросе сравнение
транспорта возможно и с частичным mpv. Продолжай на том же URL и формате.
Если подпись истекла, отметь начало нового окна и повтори контроль 64 КиБ.

Верни off/off. Настройки Selective с тем же URL из FORMAT вносятся

```bash
ready() {
  "$PY" - <<'PY'
import time
from xgw.desync.client import Client
client = Client()
deadline = time.monotonic() + 120
while time.monotonic() < deadline:
    s = client.request("/api/zapret2/overview")["zapret2"]
    if (s["fresh"] and s["policy_matched"] and s["mode"] == s["state"] == s["engine_mode"] == "off"
            and not s["blockers"].get("selective")):
        break
    time.sleep(2)
else:
    raise SystemExit("selective_not_ready")
PY
}
set_probe() {
  "$PY" - "$FORMAT" <<'PY'
import sys
from pathlib import Path
from docs.helpers.headless_playback import read_format
from xgw.desync.client import Client
from xgw.desync.schema import YOUTUBE_DOMAINS
url, _, _ = read_format(Path(sys.argv[1]))
client = Client()
view = client.request("/api/zapret2/overview")["zapret2"]
assert view["fresh"] and view["policy_matched"] and view["mode"] == view["engine_mode"] == "off"
reply = client.request("/api/zapret2/settings", {
    "expected": view["config_key"],
    "settings": {"youtube_transport_probe": True, "domains": list(YOUTUBE_DOMAINS),
                 "probe_urls": ["https://www.youtube.com/t/terms", url],
                 "check_seconds": 180, "retry_seconds": 120, "daily_probe_mb": 512},
})
if not reply.get("ok"):
    raise SystemExit(reply.get("code", "settings_failed"))
PY
}
run_matrix() {
  local label=$1
  live || return
  ready || return
  "$PY" -m xgw.desync.client start --candidates fake_md5 multidisorder --rounds 2 \
    --seconds 1100 >"$D/$label-start.json" || return
  "$PY" - "$D" "$label" <<'PY'
import json, sys, time
from pathlib import Path
from xgw.desync.client import Client
d, label = Path(sys.argv[1]), sys.argv[2]
job_id = json.loads((d / f"{label}-start.json").read_text())["id"]
client = Client()
deadline = time.monotonic() + 1300
while time.monotonic() < deadline:
    job = client.request("/api/zapret2/overview")["zapret2"]["job"]
    if job.get("id") == job_id and job["state"] not in ("queued", "running", "restoring"):
        (d / f"{label}-job.json").write_text(json.dumps(job))
        break
    time.sleep(5)
else:
    raise SystemExit("job_timeout")
PY
  "$PY" -m xgw.desync.client matrix "$D/$label-job.json" >"$D/$label-summary.json"
}
live
set_probe
run_matrix signed
```

В отчёт включи по каждой строке reason и доступные phase/kind/http/bytes.
Если проба не запускалась или данных нет, укажи конкретную причину и поле.
HTTP 206 с телом засчитывается для успешной CDN-пробы. Если все строки
показывают TLS, запуск воркера или таймаут, повтор того же задания пропусти.
При 403/410 или истёкшей подписи допускается **один** повтор после обновления

`run_matrix persistent`. Этот адрес проверяет доступность HTTPS на том же
хосте. Медиасеанс по-прежнему использует /videoplayback.

Выбирай профиль только из `two_https_pass` того же задания. Предпочтительный
fake_md5, запасной multidisorder. При пустом списке Selective=NOT_RUN и переход

Из отдельного терминала в обеих фазах открой контрольный внешний сайт вне
доменных правил YouTube. Для VPN используй прирост соответствующего аутбаунда
Xray или моста sing-box. При ротации IP проверь текущий VPN-аутбаунд. Для видео
сопоставь сокет mpv и помеченный сокет Xray. Следующая команда выводит только
счётчики и время, приватные IP остаются во входных файлах.
[Правила оценки коротких пар](T12-SELECTIVE-MEDIA-PAIRS.md)

```bash
"$PY" - "$D" <<'PY'
import json, sys
from itertools import pairwise
from pathlib import Path
root = Path(sys.argv[1])
def rows(path):
    return [json.loads(line) for line in path.read_text().splitlines()] if path.exists() else []
def peers(before, after):
    old = {row["socket"]: row for row in before}
    return {row["peer_ip"] for row in after
            if (prior := old.get(row["socket"])) and row["peer_ip"] == prior["peer_ip"]
            and type(row["bytes_received"]) is int and type(prior["bytes_received"]) is int
            and row["bytes_received"] > prior["bytes_received"]}
for stage in ("selective-long", "selective-seek"):
    player = rows(root / f"{stage}-player.jsonl")
    gateway = rows(root / f"{stage}-pairs.jsonl")
    matches = 0
    for left, right in pairwise(gateway):
        pair = right.get("media_pair") or {}
        if (pair.get("state") != "accepted" or pair["probe_before"] != pair["probe_after"]
                or not pair["nft_packets"] or not pair["queue_sequence_delta"]
                or not pair["groups"]["zapret2"]["downlink"]):
            continue
        marked = peers((left.get("tcp") or {}).get("sockets", []),
                       (right.get("tcp") or {}).get("sockets", []))
        for a, b in pairwise(player):
            if (a.get("socket_unix") and b.get("socket_unix")
                    and pair["start_unix"] <= a["socket_unix"] < b["socket_unix"] <= pair["end_unix"]
                    and marked & peers(a.get("sockets", []), b.get("sockets", []))):
                matches += 1
                print(stage, pair["start_unix"], pair["end_unix"],
                      pair["groups"]["zapret2"]["downlink"], pair["nft_packets"])
                break
    print(stage, "socket_matches", matches)
PY
```

Playback PASS требует 900/300 пригодных секунд, прогресс ≥98%, долю 720p
≥95%, остановки буфера ≤2%, пропуски ≤5 с и подтверждённую перемотку.
Это фиксированный поток TCP, отдельно запиши измерения буфера и скорости.
Для маршрута нужны совпадения сверх фона вне служебной пробы, прежняя
ревизия и параллельный VPN-контроль. При неполном наборе укажи PARTIAL
и конкретное недостающее поле. При полном успехе проверь отключение
отмеченного воркера. Сверь MainPID и принадлежность очереди, затем выполни
`sudo systemctl kill --kill-whom=main --signal=SIGKILL xgw-zapret2.service`.
Зафиксируй закрытие gate, снятие клиентского правила и новый медиазапрос
через VPN. При 403 после смены выхода сравни новый подписанный URL.

Сутки начинаются после подтверждения обеих фаз, медиамаршрута и возврата.
Сначала выбери off/off, затем вооружи отдельный таймер и включи прежнюю
проверенную политику. При прочих исходах переходи к §5.

## 5. Возврат и автоматическая публикация

Отмени своё активное задание, если оно осталось, и верни off/off. При
недоступности панели выполни независимый restore. По умолчанию rollback.
После PASS нового пакета можно выбрать accept, чтобы сохранить только
три новых файла и восстановить исходную политику.

```bash
RESULT_MODE=${RESULT_MODE:-rollback}
if [[ -n ${BACKUP:-} ]] && sudo test -f "$BACKUP/restore.sh"; then
  if ! sudo test -f "$BACKUP/restore-completed"; then
    sudo /bin/bash "$BACKUP/restore.sh" "$PY" "$HELPER" "$BACKUP" "$PANEL" "$RESULT_MODE" "$OVERLAY"
  fi
  sudo sha256sum -c "$BACKUP/config-before.sha256"
  sudo test -f "$BACKUP/restore-completed"
  systemctl is-active xgw.service
  systemctl show xgw-zapret2.service xgw-nfqws2.service -p ActiveState -p MainPID
  "$PY" -m xgw.desync.client status >"$D/final.json"
fi
```

Проверь новый VPN-сеанс, панель, off/off и хэш фактически оставленных файлов.
Погаси свой таймер и заверши свой монитор после проверки его PID. При
отрицательном исходе видео повтори `probe vpn-final` и `player vpn-final 120`.
Автоматически опубликуй один новый отчёт со всеми исходами и блокерами.
