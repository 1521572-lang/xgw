# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** запусти помощник `f141e88` для одного полного
300-секундного окна после перемотки за край буфера. Он загружает
инструмент снимков Xray из закреплённого коммита, проверяет его
перед запуском mpv и сопоставляет TCP-сокеты с журналом Xray.
[Готовое ТЗ r2](SELECTIVE-VPN-SEEK-300-2026-11-21.md)

В r1 установленный оверлей оказался без модуля `route_evidence`.
Прогон штатно остановился перед запуском плеера. Контроли off/off,
HTTPS 200 и совпадение SHA настроек прошли. Живая ротация Selective
ждёт успешного прямого допуска.
[Последний отчёт](../reports/2026-11-21T111107Z_selective-vpn-seek-300.md)

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
