# ThinkCentre. Страна по IP, анимация карты и карточки серверов

CODE `389f66b67c251ac397f92873d3b4e6f98bb39202`. Ветка freepool, версия 0.2.0. Предыдущий отчёт — 7f3872c.
Новый запуск из checkout — `vpn_ui/main_xgw.py`. Для страны по IP нужен обновлённый
серверный код панели. Проверяем настоящий каталог и движение карты при смене активного сервера.

## 1. Доступ и подготовка

Исполнитель сам запускает терминал и управляет окном через Vision. При отсутствии доступа
к терминалу, GUI или root запрашивает доступ и продолжает сам. При NoNewPrivileges запускать
GUI из пользовательского systemd-сеанса, административные команды — через согласованный
root-канал. Секрет в системном диалоге вводит владелец. Отчёт публикуется при любом исходе.

До изменения проверить рабочий VPN, режим zapret2 off, доступность панели и автоподбор
без ручного pin. Записать время UTC и PID демона/Xray. Открыть прежний отчёт и сверить
установленную версию. При деградации текущего маршрута ограничиться безопасным чтением.
Согласовать с владельцем машины загрузку GeoIP, обновление модулей и один перезапуск демона.
Сетевые настройки, ядра и подписки сохраняются.

```bash
set -euo pipefail
cd "${XGW_REPO:-$HOME/xgw}"
test -z "$(git status --porcelain)"

PYTHONPATH=src:. "$PY" -m pytest -o addopts= -q -p no:cacheprovider \
  tests/test_vpn_ui_xgw.py tests/test_vpn_ui_sidebar.py tests/test_geodat.py \
  tests/test_gui_model.py tests/test_gui_listing.py
PYTHONPATH=src:. "$PY" -m pytest -o addopts= -q -p no:cacheprovider \
  tests/test_panel.py -k server_country_uses_applied
```

Проверить итог тестов и отсутствие пропусков целевого набора. В отчёт записать количество.
Сохранить `D` и `REPO` между терминальными шагами. Снимки, конфиги, IP и имена серверов
оставлять в приватном каталоге. В публичном отчёте использовать N1, N2, S1, S2.

## 2. Подготовка панели

Проверить файлы действующей установки. По отчётам базовый серверный код — 38c08e7,
GUI на машине мог обновляться отдельно. При неизвестном расхождении остановить установку
и описать его. Штатная база маршрутизации может содержать только RU, CN и IR. Для GUI
нужна полная база стран. Источник — [V2Fly GeoIP 202610050438](https://github.com/v2fly/geoip/releases/tag/202610050438).
Загрузить файл обычным пользователем, сверить закреплённую SHA-256. Если GitHub недоступен
с машины, запросить перенос файла через доступный канал и сверить ту же сумму.

```bash
BASE=38c08e7
LIB=/opt/xgw/lib/xgw
BACKUP="/var/lib/xgw/backup/vpn-ui-map-$(date -u +%Y%m%dT%H%M%SZ)"
FILES=(geodat.py engine.py watch/panel.py freepool/pool.py)
for f in "${FILES[@]}"; do
  git show "$BASE:src/xgw/$f" >"$D/base.py"
  sudo cmp -s "$D/base.py" "$LIB/$f"
done
sudo test ! -e "$LIB/watch/server_geo.py"
UI_GEO=/opt/xgw/xray/geoip-ui.dat
sudo test ! -e "$UI_GEO"
curl --fail --location --max-time 180 -o "$D/geoip-ui.dat" \
  https://github.com/v2fly/geoip/releases/download/202610050438/geoip.dat
printf '%s  %s\n' 4ff4b2ec242a9e87b296ba27ddb85f8311e8d3e071eaebac5be9231c60e408dd \
  "$D/geoip-ui.dat" | sha256sum -c -
sudo install -d -m 0700 "$BACKUP"
for f in "${FILES[@]}"; do
  sudo install -D -m 0600 "$LIB/$f" "$BACKUP/$f"
done
sudo systemctl show -p MainPID xgw.service xgw-xray.service >"$D/pids-before"
for f in "${FILES[@]}" watch/server_geo.py; do
  sudo install -m 0644 "src/xgw/$f" "$LIB/$f"
  sudo cmp -s "src/xgw/$f" "$LIB/$f"
done
sudo install -m 0644 "$D/geoip-ui.dat" "$UI_GEO"
sudo cmp -s "$D/geoip-ui.dat" "$UI_GEO"
sudo systemctl restart xgw.service
```

Для возврата исходных модулей использовать сохранённые переменные и root-канал:

```bash
for f in "${FILES[@]}"; do
  sudo install -m 0644 "$BACKUP/$f" "$LIB/$f"
  sudo cmp -s "$BACKUP/$f" "$LIB/$f"
done
sudo rm -f -- "$LIB/watch/server_geo.py" "$UI_GEO"
sudo systemctl restart xgw.service
```

После установки дождаться свежего статуса и проверить VPN. Xray должен сохранить PID,
если демон не выполнял независимую штатную смену конфига. При ошибке установки или
недоступности панели либо VPN выполнить блок возврата и зафиксировать исход.
Обычный `xgw gui` и новое окно используют тот же сервер панели.
Первый разбор полной базы может занять несколько секунд. Отметить время первого
появления стран и проверить, что последующие обновления окна идут в обычном темпе.

## 3. Проверка каталога и карты через Vision

Открыть `"$PY" vpn_ui/main_xgw.py --native-titlebar` от пользователя графической сессии.
Можно использовать существующий сеанс или вход через кнопку. Закрыть другое окно XGW,
чтобы легче было сверять действия. Сначала проверить следующие пункты в тёмной теме,
затем повторить визуальную часть в светлой при 1024×720, в развёрнутом и узком окне.

1. Подписки сверху, серверы выбранной подписки ниже. Строка содержит страну по IP, скорость
   последнего замера и рейтинг XGW. Сверить несколько строк с данными панели. Неизвестная
   страна и отсутствующие замеры обозначены явно. Список подписок, поиск и автовыбор доступны.
2. Приватно сверить страну N1 с адресом его точки подключения в применённом конфиге
   и локальной GeoIP-базой. Для моста смотреть конечный адрес подключения в конфиге sing-box,
   а для имени — уже известное разрешение. По возможности найти случай, когда страна из
   имени подписки отличается от GeoIP. В отчёте указать число сверок и совпадения без IP.
3. Навести указатель на строку. Справа появляется карточка в теме окна с полным именем,
   состоянием, протоколом, ядром и доступными замерами. Проверить смену строки, уход
   указателя, Esc, клавиши стрелок и Enter. На узком экране карточка целиком видна.
   Смена подписки, наведение и просмотр сведений не меняют сервер и не создают pin.
4. Прокрутить длинный список, выделить строку, дождаться нескольких обновлений панели.
   Просматриваемое место и выбранный сервер должны сохраниться. Сверить полное имя
   по карточке до и после. Отдельно проверить сортировку по скорости.
5. Сравнить активную метку карты с N1 и локальной GeoIP. Открытие окна с рабочим VPN
   или поступление первого свежего снимка показывает метку активного сервера.
   Переключение подписки и наведение на другой сервер карту не двигают.
6. Проверить, что плашка ответа диагностики остаётся в окне инструментов. На узком экране
   правая панель сохраняет иконки и подсказки. Через закрытие окна проверить завершение процесса.

## 4. Движение карты при смене сервера

Проверять один раз при рабочем VPN, исходном автовыборе, отсутствии ручного pin, доступном
сервере N2 в другой известной стране и согласии владельца на временную смену сервера.
Иначе отметить MAP_SWITCH=NOT_RUN с причиной. Оставить действующий канал управления доступным.

Сначала открыть сведения N2 и сверить точное имя и страну, затем нажать отдельную кнопку
выбора. Сверить имя, подписку и страну в диалоге. Проверить, что отмена сохраняет N1,
затем подтвердить выбор N2. До смены маршрута отметка остаётся на N1. После подтверждения карта
плавно перемещается к стране N2. Два последующих опроса не перезапускают анимацию.
Нажать «Автовыбор XGW», подтвердить отсутствие ручного pin и доступность VPN. Если вернулся
N1, убедиться в движении карты обратно. При проблеме с окном снять созданный в этом пункте
pin штатным прежним GUI или `sudo xgw unpin`. При сетевом сбое остановить прогон и
восстановить прежний маршрут. Не выключать перехват и не включать zapret2 ради проверки вида.
