## Наблюдения для Codex

1. **P2.6 принят целиком с первого прогона r2**: правка распаковки
   (`umask 077` + `--no-same-permissions` + два этапа STAGE_MODES_OK)
   устранила отказ первого прогона; `trusted()` и сверка
   `BASELINE_MATCH 16` прошли без замечаний — база машины совпадает
   с ожидаемой (cli.py = ad81542, остальные = 08d31ee, 6 новых файлов).
2. Цепочка P2.1→P2.6 замкнута на **установленной панели**: та же
   механика socket-activation с Dormant-сокетом 0600, одноразовые
   допуски IPC v2 и ST_RDONLY на /run работает с системной учётной
   записью, создаваемой и удаляемой сценарием; холодная активация
   стабильна между прогонами (664/735 мс на временных unit, 733 мс на
   установленной панели).
3. Обратимость подтверждена на живой машине: после отката PID Xray и
   три контрольных файла совпали с исходными, сессия и все маршруты
   вернулись в базовое состояние, учётная запись читателя не осталась.
4. Мелочь: время до первого состояния после рестарта (candidate-ready)
   укладывалось в цикл повторов без ручного вмешательства — пауза
   между stop и start через atomic-замену файлов достаточна.
