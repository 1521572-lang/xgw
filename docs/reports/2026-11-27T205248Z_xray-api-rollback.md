## Откат на границе записи API (настоящий Xray)

Во всех опытах Xray сначала применял новое правило, после чего стенд имитировал потерю ответа приложения. Ошибки вводились только на границе клиента API — команды шли к отдельному настоящему Xray. В каждом опыте после отката проверялись конфиг на диске (равен прежнему), запуск Xray (сохранён), активный слот (`blue`), признак неопределённости и реальный список обработчиков Xray, а новый HTTP CONNECT получал байты через прежний `blue` с новым сокетом.

| Метка | Наблюдение |
| --- | --- |
| `ROLLBACK_REMOVED=PASS` | Потерян ответ после фактического удаления нового обработчика. Настоящий список Xray подтвердил отсутствие тега. XGW вернул `rejected`, очистил признак неопределённости, остановил `green` (его run снят, `pending` пуст); конфиг Xray и слот восстановлены, соединение через `blue` отвечает |
| `ROLLBACK_PRESENT=PASS` | Удаление не дошло до ядра — тег остался в настоящем списке. XGW вернул `failed`, сохранил признак неопределённости (`pending.phase=uncertain`) и оба процесса; вызов восстановления сохранил `green` и тег |
| `ROLLBACK_UNREADABLE=PASS` | Удаление не подтверждено, и запрос списка тоже вернул ошибку — XGW вернул `failed` и сохранил оба процесса; после снятия имитации ошибки стенд сверил наличие тега штатным чтением |

Смысл изменения: ошибка API больше не считается доказательством отсутствия обработчика. При откате клиент читает точные теги через настоящий API (`lsi`/`lso`): если тег действительно ушёл — откат принимается как `rejected`, если тег ещё в ядре или список недоступен — состояние помечается неопределённым и кандидат удерживается (`failed`) до согласованного восстановления.

## `HANDOFF_CONTROL` (нормальный переход без ошибок)

`HANDOFF_CONTROL=0`: `HANDOFF_BLUE_PATH=PASS`, `HANDOFF_MEASUREMENT_CONTEXT=PASS`, `HANDOFF_GREEN_PATH=PASS`, `HANDOFF_HELD=RETAINED`, `HANDOFF_CLEANUP=PASS`, `HANDOFF_OLD_AFTER_CLEANUP=CLOSED`. При коротком прогоне дедлайн сдвигался только в приватном файле стенда; путь нового соединения — через новый мост `green`, удержанное соединение жило до дедлайна и закрылось при штатной очистке.
