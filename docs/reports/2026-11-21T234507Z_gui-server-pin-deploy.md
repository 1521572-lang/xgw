## §2 Рабочее окно: перезапуск, инцидент, восстановление

- Штатный `xgw gui` заменил окно прежней версии кода (штампованный
  handover): процесс из пути установленного релиза, экземпляр один.
- **Инцидент (причина — моя автоматизация, не кандидат):** после
  выбора строки сервера подписки я нажал «Выбрать сервер» — диалог
  открылся как **отдельное X-окно, невидимое для снимка главного
  окна**; последующие слепые клики попали в него, один — по
  «На 10 минут» — отправил разрешённый диалогом pin с TTL 10 минут
  на выбранную строку (сервер домашней страны, Россия). Маркер
  «Выбран вручную до 02:36» подтвердился в статусе; перехват и
  трафик через VPN сохранялись всё время (HTTPS 200).
- **Исправление по решению владельца:** штатный `xgw unpin`
  (~02:29, раньше авто-истечения TTL в 02:36). Переход отметил
  кратким состоянием LEAK (прямой выход при включённом перехвате,
  правила nftables переприменялись) — к 02:40 шлюз вернулся к
  рабочему состоянию, автовыбор восстановлен (новый основной —
  Польша). Дальнейшие команды маршрутизации от меня не поступали.
- TTL-механика диалога показала встроенный предохранитель: даже
  без CLI пин снялся бы сам в 02:36.
