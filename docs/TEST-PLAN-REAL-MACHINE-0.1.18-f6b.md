# Проверка XGW: доработки после отчётов Ф4 и Ф6

**Для исполнителя.** Выполняй шаги строго по порядку. В каждом шаге — команда (копируй
целиком), «Ожидается» и «Если не так». Ничего не придумывай сверх написанного. Не уверен —
остановись и спроси заказчика. Выводы сохраняй в файлы, как написано (`$HOME/xgw-f6b/…`).

Машина: ThinkCentre, Ubuntu 24.04.5 LTS, KDE Plasma (X11), браузер Chromium, XGW 0.1.18. Клон —
`~/zcod/xgw`. Код — ветка `direct-f6` (версия остаётся 0.1.18). Программы Ф4 и Ф6 уже пройдены
(отчёты `docs/TEST-REPORT-REAL-MACHINE-0.1.18-f4-2026-10-25.md` и `…-f6-2026-10-25.md`).
Проверяемый телефон — S25 Ultra, адрес в домашней сети 192.168.60.135.

Что нового (ASSUMPTIONS п. 247):
1. **Свой сервер устройства применяется сразу** (дефект «правило не собрано» из отчёта Ф4:
   выбор записывался, а конфиг Xray ждал ночного окна перезапуска). Если для выбора нужен
   перезапуск Xray, соединения всех устройств прерываются на пару секунд.
2. **«Российские адреса — мимо Xray» — по устройствам** (пожелание заказчика из отчёта Ф6). В
   строке каждого устройства — список «Российские: через Xray / мимо Xray»; переключатель вверху
   карточки теперь только для «Этот компьютер и контейнеры». Включённый общий переключатель при
   установке переходит на этот компьютер и на устройства, что в этот момент в сети.
3. **Пинг запасных серверов.** В строке запасного — задержка в мс по его последней проверке
   (у серверов в работе она была и раньше); кнопка замера скорости у запасного заодно его
   проверяет.

Здесь, у разработчика, проверены только юнит-тесты и текст правил (`nft -c`); перезапуск Xray,
телефон, сайты и панель проверяет эта программа.

## 0. Запрещено

- `xgw net down`, `xgw disable`, `xgw uninstall`, `reboot`, сон машины, `install.sh --force` —
  **никогда**. Запуск, остановка и перезапуск служб `xgw*`, `tailscaled`, NetworkManager,
  `ssh`; ручные `nft` (кроме `nft list`), `ip`, `iptables`, `tc`, `sysctl -w`.
- Править `/etc/xgw` (в том числе `panel.json`), `/opt/xgw`, `/var/lib/xgw`, `/etc/systemd`,
  код XGW. Серверы и переключатели в панели меняет только заказчик. Коммитить что-либо, кроме
  отчёта (§8).
- Писать в отчёт: адреса tailnet, имена `*.ts.net`, имена устройств и пользователей (имя
  пользователя → `<user>`), внешние IP, токены, адреса подписок, IP и домены серверов VPN.
  Можно: адреса устройств в домашней сети (`192.168.…`), отпечатки серверов (8 знаков), страны,
  число сетей, счётчики правил, задержки и скорости.

Шаг 1.2. Папка и помощник проверки (только читает: настройки без подписок, конфиг Xray,
`status.json` демона, таблицу nftables `ip xgw`):

```bash
mkdir -p "$HOME/xgw-f6b" && chmod 700 "$HOME/xgw-f6b" && cd "$HOME/xgw-f6b" && cat > f6bcheck.py <<'EOF'
"""Доработки Ф4/Ф6: свой сервер устройства, российские адреса по устройствам, пинг запасных.
Только читает: config.toml и panel.json (без подписок), конфиг Xray, status.json демона,
таблицу nftables ip xgw. Режимы: before, route, direct, ping."""
import json
import subprocess
import sys
import time

sys.path.insert(0, "/opt/xgw/lib")
from xgw.paths import Paths  # noqa: E402

paths = Paths.from_env()
mode = sys.argv[1] if len(sys.argv) > 1 else ""
panel_file = paths.config_file.with_name("panel.json")
if mode == "before":
    try:
        raw = json.loads(panel_file.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        raw = {}
    print(f"до установки: kernel_direct в panel.json: {raw.get('kernel_direct')}; "
          f"kernel_devices: {'есть' if 'kernel_devices' in raw else 'нет'}")
    sys.exit(0)

from xgw import config, managed  # noqa: E402
from xgw.net import nft  # noqa: E402

cfg, _warnings = config.load(paths.config_file)
if mode == "route":
    routes = cfg.managed.routes
    print(f"устройств со своим сервером: {len(routes)}")
    for ip, server in sorted(routes.items()):
        print(f"  {ip} -> сервер {server}")
    xray = json.loads(paths.xray_config_file.read_text(encoding="utf-8"))
    tags = [item["tag"] for item in xray["routing"]["balancers"] if item["tag"].startswith("dev-")]
    print(f"балансировщики устройств в конфиге Xray: {len(tags)} {tags}")
    outbound = any(item.get("tag") == "to-main" for item in xray["outbounds"])
    print(f"выход to-main: {'есть' if outbound else 'нет'}")
    print(f"конфиг ждёт окна перезапуска: {'да' if paths.pending_config_file.exists() else 'нет'}")
    started = subprocess.run(
        ["systemctl", "show", "-p", "ActiveEnterTimestamp", "--value", "xgw-xray.service"],
        capture_output=True, text=True).stdout.strip()
    print(f"Xray запущен: {started}")
elif mode == "direct":
    data = managed.load(managed.path_for(paths.config_file))[0]
    print(f"этот компьютер и контейнеры: {'вкл' if cfg.routing.kernel_direct else 'выкл'} "
          f"(в panel.json: {data['kernel_direct']})")
    print(f"устройства с российскими мимо Xray: {[item['ip'] for item in data['kernel_devices']]}")
    print(f"мешает: {nft.kernel_direct_blocker(cfg) or '—'}")
    listed = subprocess.run(["nft", "list", "table", "ip", "xgw"], capture_output=True,
                            text=True).stdout
    devices = (sorted(nft.set_elements(listed, nft.DIRECT_LAN_SET))
               if nft.has_set(listed, nft.DIRECT_LAN_SET) else "нет")
    print(f"набор direct4 в ядре: {'есть' if nft.has_set(listed, nft.DIRECT_SET) else 'нет'}; "
          f"набор устройств direct_lan4: {devices}")
    for line in listed.splitlines():
        if "@direct4" in line:
            print("  правило: " + line.strip())
elif mode == "ping":
    status = json.loads(paths.status_file.read_text(encoding="utf-8"))
    spares = status.get("spares") or []
    pinged = [item for item in spares if item.get("delay_ms") is not None]
    print(f"запасных: {len(spares)}, с задержкой в мс: {len(pinged)}")
    now = time.time()
    measured = [item for item in spares if item.get("speed_ts")]
    if not measured:
        print("замеренных запасных нет")
        sys.exit(0)
    last = max(measured, key=lambda item: item["speed_ts"])
    scanned = f"{now - last['scanned']:.0f} с назад" if last.get("scanned") else "никогда"
    print(f"последний замеренный запасной: замер {now - last['speed_ts']:.0f} с назад, "
          f"скорость {last.get('speed_mbps')} Мбит/с; проверка {scanned}, вердикт "
          f"{last.get('verdict')}, задержка {last.get('delay_ms')} мс")
else:
    print("режим: before | route | direct | ping")
EOF
sha256sum f6bcheck.py | cut -c1-16; sudo xgw status | grep -E '^Состояние|Перехват:' | tee before.txt; sudo python3 -I f6bcheck.py before | tee -a before.txt
```

Ожидается: `194e6d15b38525a1`; `Состояние: HEALTHY …`, `Перехват: включён …`; «до установки:
kernel_direct в panel.json: True; kernel_devices: нет» (в отчёте Ф6 заказчик оставил разгрузку
включённой). Записать как есть.

Если не так: сумма другая — выполнить шаг заново, скопировав команду целиком; снова другая —
**стоп**, сообщить заказчику. Не `HEALTHY` — записать (это до установки) и продолжить.
`kernel_direct` не `True` — записать: переноса в 2.3 тогда не будет, это не дефект.

## 5. Пинг запасного сервера (при согласии на пункт 4)

Шаг 5.1. **Попроси заказчика** (дословно):

«В панели, карточка „Серверы": найдите сервер с подписью „запасной" (они ниже серверов „в
работе"). Справа в его строке — маленькая круглая стрелка у скорости. Нажмите её и подождите,
пока стрелка перестанет крутиться (до минуты). Что теперь написано справа в этой строке? Есть ли
там задержка в мс? Если навести мышь на мс — что во всплывающей подсказке?»

Затем:

```bash
cd "$HOME/xgw-f6b" && sudo python3 -I f6bcheck.py ping | tee ping.txt
```

Ожидается: в строке — скорость и «N мс» (цветом: зелёный, жёлтый или красный), подсказка
«В порядке — по проверке …» или «Медленный — по проверке …»; в выводе — «последний замеренный
запасной: замер T с назад …; проверка S с назад, вердикт OK (или SLOW), задержка D мс», T и S
меньше 120, D — то же число, что видит заказчик (может отличаться, если панель успела
обновиться). Записать ответ заказчика, «запасных: …, с задержкой в мс: …», T, S, D.

Если не так: стрелки у этого сервера нет — попросить выбрать другой запасной (у серверов x100
замера нет). Вердикт не OK и не SLOW (сервер не ответил) — в строке вместо мс слово
(«недоступен», «тайм-аут») — это не дефект: попросить нажать стрелку у другого запасного, один
раз. Вердикт OK или SLOW, а «задержка None» или заказчик не видит мс — **дефект «нет пинга у
запасного»**: записать ответ и `ping.txt`. «замеренных запасных нет» или T больше 120 —
подождать минуту, повторить помощник; снова так — **дефект «замер по кнопке не идёт»**.

## 7. Если что-то пошло не так

- Установка не прошла (код не 0) — ничего не откатывать, сообщить заказчику.
- После выбора сервера у телефона пропал интернет — попросить заказчика выбрать «Сервер: авто».
- Не открываются российские сайты — попросить выбрать в строке телефона «Российские: через
  Xray».
- Шлюз не `HEALTHY` — записать и продолжить; сеть руками не трогать.
