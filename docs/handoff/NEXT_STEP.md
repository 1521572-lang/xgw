# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** выполни два read-only измерения. Сначала
пересчитай архивные потоки и проверь оба ранее подтверждённых контроля.
Затем сравни один HTTP Range с четырьмя короткими запросами на тот же
диапазон через действующий Xray VPN. Инструменты закреплены на
`feea23c`. [Готовое ТЗ](SELECTIVE-REPLAY-VPN-RANGE-2026-11-21.md)

В последнем прогоне первый и повторный прямые допуски дали TLS-таймаут.
Настройки восстановлены, обычный VPN подтверждён. Строка `flow-r2b`
содержит несходящиеся счётчики. Для отчёта берём агрегаты повторного
разбора сырых данных. Живая ротация ждёт пригодного прямого окна.
[Последний отчёт](../reports/2026-11-21T082230Z_selective-recovery-replay.md)

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует обезличенный отчёт
при любом исходе в `integration/zapret2-batch1`.
