# Окно XGW, этап 3: разделы «Серверы» (подписки и пул) и «Подписки»

Выполнять после отчёта diag-limit: тогда на машине стоит f57eb5b (волна 1б и правка окна
6f49129). Если diag-limit ещё не выполнен или стоит другая версия — остановиться и сообщить
владельцу: эта поставка ставится только поверх принятой. Новый код
7f09f774afd3dd908ab43313533cf7744d7377a0 (ASSUMPTIONS п. 333).

Пакет меняет только окно (src/xgw/gui): разделы «Серверы» и «Подписки» теперь в окне, а не
«Открыть в браузерной панели». Демон, Xray, sing-box и правила сети не меняются. Подробно:
- «Серверы» → «Подписки»: «Основной сервер» (переключатель), «Автовыбор», «Замерить скорость
  всех», «Проверить запасные», «Обновить подписки»; серверы карточками по подпискам — страна,
  имя, метки, скорость, задержка, точка; у карточки: замер одного, «Выбрать», меню «…» (ядро,
  приоритет, отключить, «Убрать из списка…»); «Включить все»/«Отключить все»; «Убранные из
  списка» с «Вернуть»; поиск по имени и стране;
- «Серверы» → «Бесплатный пул»: сводка, режим, серверы по источникам, «Показать остальные»,
  «Выбрать»/«Автовыбор»;
- «Подписки»: «Добавить», карточки подписок с квотой, «Изменить»/«Убрать» у добавленных из
  панели, отдельные ссылки.

Заодно проверяются: замена открытого окна прежней версии (6f49129), тёмная тема, подсказка у
точки состояния.

Критерии: тесты окна `32 passed`; установка, health rc0, пакет совпадает; открытое окно
f57eb5b закрывается само, новое открывается с разделами; цифры разделов совпадают с браузерной
панелью; действия на демо проходят; на настоящем шлюзе ничего не изменено, кроме разрешённого.

Разрешены терминал, браузерная панель (только смотреть), `xgw status`, `xgw diag --no-net`,
журнал, окно и демо. На настоящем шлюзе нельзя: «Выбрать», «Автовыбор», приоритет, ядро,
отключить, убрать, «Включить все»/«Отключить все», переключатель основного сервера, режим пула,
добавлять, менять и убирать подписки и ссылки, «Проверить запасные», «Обновить», «Замерить
скорость всех». Можно только с отдельного согласия владельца — замер скорости одного сервера
кнопкой у его карточки (шаг 4.3). WAN, LAN, Tailscale, пул, ручной выбор и настройки не менять.
В отчёте — только числа, слова состояний и признаки: без имён серверов, подписок, стран,
адресов, доменов, кода входа и cookie; снимки экрана в репозиторий не добавлять.

## 2. Окно прежней версии и установка

До установки открыть окно текущей версии от владельца: `xgw gui &` — оно остаётся открытым.
Нужно согласие владельца на установку CODE и на условный возврат штатным установщиком BASE.
Нет согласия — INSTALL_NOT_RUN.

```sh
sudo sh -s -- "$TARGET" "$PREV" "$HELPER" <<'SH'
umask 077
d=/run/xgw-s3
mkdir -m 700 "$d" || exit 3
sh "$1/packaging/install.sh" --yes >"$d/install.log" 2>&1
i=$?; echo "$i" >"$d/install.rc"
h=3; n=0
while [ "$n" -lt 9 ]; do
    if python3 -I "$3" health >"$d/health.json" 2>&1; then h=0; break; fi
    n=$((n + 1)); sleep 10
done
echo "$h" >"$d/health.rc"
if [ "$i" -ne 0 ] || [ "$h" -ne 0 ]; then
    sh "$2/packaging/install.sh" --yes >"$d/return.log" 2>&1
    echo "$?" >"$d/return.rc"
    python3 -I "$3" health >"$d/return-health.json" 2>&1
    echo "$?" >"$d/return-health.rc"
fi
SH
sudo cat /run/xgw-s3/install.rc /run/xgw-s3/health.rc
match_package "$TARGET"
```

Ожидаются 0 и 0 и совпадение пакета. При возврате снять health и закончить с PARTIAL.

## 4. «Серверы» на настоящем шлюзе (только смотреть)

Открыть рядом браузерную панель (вкладка серверов). Записать да/нет и числа без имён:

1. «Подписки»: число групп подписок и «включено N из M» у каждой совпадают с панелью; у
   основного или выбранного вручную сервера — рамка и метка («основной» / «выбран вручную»),
   тот же сервер, что в «Обзоре» слева; у ручного выбора видна строка «Выбран вручную … —
   «Автовыбор» вернёт выбор шлюзу» и кнопка «Автовыбор» (не нажимать).
2. Скорость, RTT и проба у 3 любых карточек совпадают с панелью; у неживых — «нет ответа»;
   меню «…» открывается (пункты: Ядро — если сервер умеет оба, Приоритет, Отключить/Включить,
   Убрать из списка…) — закрыть Esc, ничего не выбирать.
3. Только с согласия владельца: кнопка замера у одной живой карточки → кнопка неактивна, пока
   идёт замер, затем у карточки новое время замера. Нет согласия — NOT_RUN.
4. Поиск: ввести часть имени — остаются подходящие; очистить — все вернулись.
5. «Бесплатный пул»: сводка («найдено … проверено … пригодно …») совпадает с вкладкой пула в
   панели; источники и «допущено X · проверено Y из Z» совпадают; «Показать остальные (N)»
   раскрывает и сворачивает список; окно не подвисает (записать на глаз: да/нет).
6. «Подписки»: число карточек и у каждой «серверов: N», квота («Израсходовано … из …») и
   ошибка совпадают с панелью; «Изменить»/«Убрать» есть только у добавленных из панели
   (не нажимать); отдельные ссылки — то же число.
7. Тема: владелец сам мышью «Тема» → «Тёмная», «Светлая», «Как в системе» на «Обзоре» и
   «Серверах» — читаемо (нет времени — NOT_RUN). Подсказка при наведении на точку у узкой
   строки сервера в «Обзоре» при окне 1024×720 — слово состояния.

Машинное зрение и xdotool — только по прямому поручению владельца. Закрыть окно, затем
`systemctl is-active xgw` и `sudo python3 -I "$HELPER" health` (active, true).

## 5. Действия на демо (без root, сеть не трогается)

```sh
cd "$TARGET"
python3 tests/panel_demo.py --gui --port 8798 --scene work
```

В окне демо: «Серверы» → у любой карточки «Выбрать» — у неё метка «выбран вручную», появился
«Автовыбор»; «Автовыбор» — метка ушла. Меню «…» → Приоритет → Высокий (в строке состояния —
«Приоритет сервера …»). «…» → «Отключить» → карточка «отключён»; «Включить» — вернулась. «…» →
«Убрать из списка…» → вопрос → «Убрать» → сервер в «Убранные из списка — 1» → «Вернуть».
«Бесплатный пул» → «Включить наблюдение» (в демо). «Подписки»: вставить `trojan://pass@example.org:443#Тест` →
«Добавить» → в строке состояния «Добавлено серверов: 1», поле пусто; вставить «не ссылка» →
отказ, текст в поле остался. У «запасная» — «Изменить» (окно User-Agent и заголовков; Отмена)
и «Убрать» (вопрос; Отмена). Остановить Ctrl+C.
