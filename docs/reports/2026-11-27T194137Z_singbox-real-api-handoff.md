## `HANDOFF` (два sing-box и Xray — отдельные реальные процессы, loopback)

`HANDOFF=0`. Использовались настоящие исполняемые файлы: Xray держал настоящий API, оба слота sing-box были дочерними процессами, данные шли через реальный HTTP CONNECT, идентичность сокетов снималась из procfs по PID процесса.

| Метка | Наблюдение |
| --- | --- |
| `HANDOFF_BLUE_PATH=PASS` | Реальный запрос через прокси Xray (старый мост) дошёл до локального источника и обменялся байтами; в процессе `blue` найден ровно один установленный сокет к прежнему порту; при подготовке `green` файл конфигурации Xray по-прежнему указывал на прежний порт |
| `HANDOFF_MEASUREMENT_CONTEXT=PASS` | Коммит выполнен через настоящий API Xray: процесс Xray сохранил свой запуск, активным стал `green`, `blue` — завершающим. Из контекстов замера исчез прежний порт, для того же идентификатора моста появился новый порт, а ключ поколения сменился (цель/бакет тот же, ключ другой) |
| `HANDOFF_GREEN_PATH=PASS` | Новое соединение получило байты через новый мост; у процесса `green` есть установленный сокет этого моста; в конфиге Xray сохранён тег выхода и изменён порт |
| `HANDOFF_HELD=RETAINED` | До срока старая сессия обменялась байтами, и в процессе `blue` сохранялся тот же сокет — поток удержан до дедлайна, без EOF и reset |
| `HANDOFF_CLEANUP=PASS` | Дедлайн сдвинут в приватном файле состояния стенда под общей блокировкой и выполнен штатный `reap`: `blue` остановлен, `green` и Xray сохранили запуск, соединение `green` отвечает |
| `HANDOFF_OLD_AFTER_CLEANUP=CLOSED` | После очистки старая сессия фактически закрыта — сохранение потока после срока не заявляется |

Состояние в приватном префиксе после перехода: активно `green`, `blue` в `draining`, затем его run снят штатным reap; процесс Xray всё время оставался тем же.
