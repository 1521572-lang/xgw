# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** проверь профиль systemd из `95aeaa4`.
Временный HTTP-процесс должен читать пять полей по IPC, а попытка
открыть рабочий снимок, настройки, токен и базу должна завершиться
отказом. Сценарий повторяет HTTP-контроль и проверяет очистку unit.
[Готовое ТЗ](PANEL-READ-SANDBOX-2026-11-21.md)

В P2.2 на ThinkCentre прошли 95 тестов. Пять полей совпали со
штатной панелью, при отказе IPC получен 503, после восстановления
200. Замер показал, что UID может читать `status.json` напрямую.
Живая ротация Selective ждёт успешного прямого допуска.
[Последний отчёт](../reports/2026-11-21T143147Z_panel-read-http.md)

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
