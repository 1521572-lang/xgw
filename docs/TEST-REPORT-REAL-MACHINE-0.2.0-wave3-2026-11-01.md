## Подтверждённые дефекты

1. **(шаг 2.3, FAIL миграции) Установка с кодом 0 оставила дом без VPN: перехват снят, барьер
   не загружен.** Загрузка правил была убита SIGTERM: «правила перехвата не загружены: nft -f -:
   код -15» (23:06:45, момент `Stopping xgw.service` установщика — гонка перезапуска службы с
   загрузкой правил; ядро правила не отвергало). Установщик по fail-safe оставил перехват
   снятым; автоматического возврата перехвата не произошло (владелец оставался без VPN 23:06 —
   23:25 до ручного enable, затем снова без VPN с ~23:27). Ожидание ТЗ: HEALTHY + guard + правила
   с битом барьера + skuid sing-box после установки. Востановление — действием владельца
   (`sudo xgw enable` в 23:25:25, барьер загрузился). Воспроизводимость не проверялась
   (повторная установка вне плана этого прогона). Предположение: одноразовая гонка
   установка/перезапуск службы; проверяется разработчиком.
2. **(эксплуатация, слова владельца дословно) «блокируется и входящий ethernet адаптер. такого
   быть не должно либо должно быть автоматическое переподключение чтобы машина не теряла связь
   с интернетом полность болше чем 30 секунд»** — при включении перехвата барьер обрывает
   установленные соединения (в том числе владельца, 2284 пакета за один переход), и связь
   владельца с машиной/интернетом пропадает дольше 30 секунд без автоматического
   переподключения; владелец дважды снимал перехват из-за этого. Атрибуция потоков не
   проводилась; счётчик барьера — локальное свидетельство. Требует решения разработчика
   (переходный режим включения перехвата для установленных соединений и/или быстрый
   автопереподъём).
