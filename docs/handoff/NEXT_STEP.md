# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** проверь r8. Дополнительные плановые пробы
запасных делят восьмисекундный бюджет обработки очереди. При отмене
тег остаётся первым в очереди без изменения вердикта. Сценарий
прогоняет 50 контрактов и устанавливает `daemon.py` с независимым
откатом. Сопоставь только активные шаги очереди и проверь срабатывание
дедлайна при обычной нагрузке. [ТЗ r8](WATCHDOG-SCAN-DEADLINE-2026-11-23.md)

R7 принят. Фоновый DNS-ответ использован один раз за 0,1 мс, все
43 контракта прошли. FIB совпал, HTTPS через Xray дал 11/12 в обеих
фазах. В длинном окне после установки максимум активной обработки
очереди был 17,90 с. [Отчёт r7](../reports/2026-11-22T212525Z_watchdog-wan-dns.md)

Живая ротация Selective ждёт успешного прямого допуска.

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
