## Наблюдения для Codex

1. **Линия деградировала за ночь**: узел из вчерашнего accept
   (`77.37.x.x`, rr8-c35d) не отвечает TLS на прямом пути; резолвер
   продолжает отдавать только его. Для будущих допусков нужна процедура
   «узел недоступен → искать альтернативу» (например, выборка нескольких
   `rrN`-узлов из Network разных клиентов или persistent-проба как
   fallback-URL пары).
2. Кандидат `93d87f1` (route_reconcile) не проверен вживую — гейт и
   установка чистые; повтор возможен без изменений ТЗ сразу после
   восстановления линии (вся подготовка уже описана в ТЗ).
3. Диагностический бонус: прямой путь умирает «в ноль» (TLS не отвечает)
   при живом VPN-пути к тому же сервису — полезный маркер для
   автодиагностики линии в панели (сейчас панель покажет fallback без
   причины).
