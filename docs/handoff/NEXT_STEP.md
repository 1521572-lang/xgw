# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** запусти обновление установленной карты
из `012b859`. Сценарий сверяет три файла, вооружает таймер
и проверяет живое окно из установленного релиза. После приёмки
проверь обычный запуск `xgw gui`.
[ТЗ обновления карты](GUI-MAP-DEPLOY-2026-11-22.md)

UI06 r3 прошёл целиком. Панорама дала шесть позиций, два кадра
показали новый маркер и разные фазы пульса. Исходный IP вернулся,
PID и настройки совпали. Испытание использовало частную копию GUI.
[Последний отчёт](../reports/2026-11-21T221346Z_gui-map-switch-r3.md)

Живая ротация Selective ждёт успешного прямого допуска.

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
