# Следующая проверка XGW на ThinkCentre

**Действующее задание Flash** — [Медиамаршрут Selective и возврат на VPN](MEDIA-PROOF-2026-11-20.md). На Ubuntu 24.04 LTS установлены пять файлов `3a00777` поверх `08d31ee`. Инструменты `1e0c29099eb1c8186c7c7ffb2f4931adfc988596` запускаются из отдельного дерева.

Допуск и обе длинные фазы прошли. Для long привязка маршрута осталась частичной. После SIGKILL наблюдались fallback и повторный active. Теперь Flash проверит путь и новый сеанс через VPN в коротких окнах. Суточный замер в этот проход не входит. [Отчёт](../reports/2026-11-20T060738Z_selective-cdn-peer.md)

Flash сама выполняет техническую проверку и публикует один новый обезличенный отчёт при любом исходе. Codex отвечает за системный код, инструменты, тесты и разбор отчёта.
