# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** выполни один цикл Standalone → VPN с
временным точечным патчем. Подтверди возврат `blue`/`green`, событие
целевого применения через API и откат рабочих файлов.
[ТЗ](STANDALONE-MANAGED-LIVE-2026-11-23.md)

Перед циклом проверяются два варианта ранней отмены на копии пакета.
Остановку, которая уже началась, XGW завершает перед сборкой VPN.

Контракты исходников и патч на пяти установленных файлах проверены.
Штатная пересборка уже вернула `blue` на рабочем шлюзе. Целевой возврат
нового кода проверяется отдельным циклом.
[Контракты](../reports/2026-11-23T115805Z_standalone-managed-return.md) · [Проверка копии](../reports/2026-11-23T124447Z_standalone-managed-return.md)

Живую матрицу и проверки Selective продолжить после проверки
возврата к управляемому поколению и успешного прямого допуска.

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
