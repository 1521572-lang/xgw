## §2 Деградация гейта блока на этой машине (классификация)

- Блок запускает pytest из корня рабочей копии (репозитория). pytest
  без ini-файла выбирает rootdir как общий предок каталога тестов и
  текущего каталога — на этой машине это /home/xxx. Относительные
  node id начинают включать имя временного каталога прогона, а шаблон
  каталога содержит слово «incident» — подстроку из выражения -k.
  В результате **-k легитимно матчит все 163 теста** (каждый node id
  содержит «incident»), фильтр перестаёт ограничивать набор, и за
  таймаут 60 с успевает выполниться 27 тестов с посторонними
  отказами (тесты вне контрактного набора на файлах чужого
  рабочего каталога). Повторная проверка: из нейтрального каталога
  тот же вызов даёт «7 passed, 156 deselected».
- Классификация: контекст запуска сценария, не кандидат и не машина.
  Достаточная правка для r2: запускать pytest с текущим каталогом
  прогона (rootdir=каталог), либо сменить шаблон mktemp без слова
  «incident», либо передать rootdir явно.

## §4 Уровень доказательства и вывод

- Путь предупреждения — **pinned** (02:29:16, прямое указание
  закреплённого сервера), затем **own_exit** (02:35:06, тот же сервер
  под автоматическим выбором, заменён запасным). Обе записи —
  прямые указания сервера с домашним выходом через штатную пробу;
  ни одной записи «мимо Xray» (legacy_ambiguous) в интервале нет.
- Это подтверждает исходную посылку кандидата: состояние LEAK в этом
  инциденте не было обходом VPN — трафик шёл через выбранный сервер,
  который сам находился в домашней стране. Переименование
  пользовательских текстов LEAK («Выход в домашнюю страну» вместо
  «Трафик идёт мимо VPN») и явная сверка с пробой через Xray в
  кандидате соответствуют данным машины.
- Записи пакетного пути того же интервала отсутствуют (каталог
  bridge-установки на машине не сохранился) — нечего агрегировать.
- Для будущих GUI-проверок принято: клиент с блокировкой записи для
  просмотра и отмены; модальный диалог ищется и снимается как
  отдельное X-окно, затем закрывается Esc; без снимка GUI-действия
  останавливаются.
