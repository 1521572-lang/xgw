1. **Ожидание ТЗ «одна вкладка в панели: 1» неточно.** `grep -c BroadcastChannel` в новом
   app.js даёт 2 — слово встречается в двух строках (проверка поддержки `if ("BroadcastChannel"
   in window)` и конструктор `new BroadcastChannel("xgw-panel")`). Установленный файл
   побайтово совпадает с исходником ветки — панель обновлена; для будущих программ точнее
   считать `grep -c 'new BroadcastChannel'` (1).
2. Рисование роутера в Qt (PyQt5 на этой машине) отработало: заказчик видит роутер, не круг
   с X — то, что разработчик не мог проверить у себя без PyQt.
3. **Пожелание заказчика:** при каждом открытии панели мигает вторая вкладка, которая
   закрывается сама через секунду — можно ли сделать открытие незаметным (без видимой
   второй вкладки)? Рабочее поведение правильное (вкладка всегда одна), вопрос только о
   визуальном шуме.
4. Сторож значка за всю программу не менялся (PID 1701170 с 13:19:08) — значок не падал и
   не перезапускался.
