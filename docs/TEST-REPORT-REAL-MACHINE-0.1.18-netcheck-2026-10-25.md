1. Проверки по кнопке (5.8 с) заметно быстрее полного `diag --netcheck` (25 с) — видимо, за

   напрямую, и через VPN (важно для future QUIC-обходов).
3. Проверка утечки DNS подтверждена контрольным экспериментом с меткой мимо VPN (0x2) —
   метод честный, не «сам себя проверял».

   она фильтруется выборкой ТЗ (NAMES), не дефект.
