# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** проверь журнал закрепления и диагностику
домашнего выхода из `4a6636f2a7b2302b714436584c393731233cc6a0`.
Сценарий читает сохранённые события и запускает 13 контрактов
по именам тестов. [ТЗ r2](HOME-EXIT-INCIDENT-2026-11-22.md)

В первом проходе диагностика указала сервер с домашним выходом
сначала при ручном закреплении, затем при автовыборе. Сведения о
пакетном пути за этот интервал отсутствуют. Семь контрактов прошли
при повторе с исправленным каталогом запуска. R2 фиксирует
выборку и различает источники новых событий закрепления.
[Последний отчёт](../reports/2026-11-22T115700Z_home-exit-incident.md)

Живая ротация Selective ждёт успешного прямого допуска.

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
