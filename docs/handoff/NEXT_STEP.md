# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** запусти временную проверку установленной
панели T11 из `52d57a5`. Скрипт запускает контракты, сверяет пять
файлов с базой, проверяет вход на установленной панели и возвращает
исходный пакет под защитой независимого таймера.
[Готовое ТЗ](PANEL-LOGIN-INSTALLED-TRIAL-2026-11-21.md)

Предыдущий отчёт подтвердил одноразовый вход в браузере и Qt,
переадресацию со старой закладки и сохранение сессии. Исправлены два
ожидания в группе cli-install. Живая ротация Selective ждёт успешного
прямого допуска. [Последний отчёт](../reports/2026-11-21T122428Z_panel-one-time-login.md)

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
