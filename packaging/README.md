# Linux-поставка XGW с zapret2

Готовый архив включает Python-код XGW, nfqws2 1.0.7, две Lua-библиотеки, исходники
third_party/zapret2 и лицензии. На шлюзе компилятор не нужен. nfqws2 запускается отдельно,
режим по умолчанию off. Сборка и включение режима — разные действия.

Собирать на Ubuntu той же версии и архитектуры, что и целевая машина. Сейчас целевая
платформа — Ubuntu 26.04, amd64. Сборка для других платформ требует отдельной проверки.
На сборочной машине нужны make, gcc, pkg-config, liblua5.4-dev, libnetfilter-queue-dev,
libnfnetlink-dev, libmnl-dev, libcap-dev и zlib1g-dev. Их устанавливают с согласия владельца.
Сам сценарий не скачивает пакеты или исходники и не меняет службы/сетевые настройки.

```bash
python3 packaging/build_release.py --output dist
```

Сценарий проверяет хеши upstream, собирает nfqws2 с системной Lua 5.4, выполняет
dry-run без очереди, упаковывает `xgw-0.2.0-linux-x86_64-zapret2.tar.gz` и SHA-256.
Сборка не требует root. Исполнение Lua проверяется отдельно помощником из TEST-PLAN
через intercept=0: для этой проверки nfqws2 нужны права на raw-сокеты, пакеты не отправляются.
Состав берётся из Git и неигнорируемых новых файлов рабочего дерева: перед публикацией
проверить чистоту дерева и не помещать в него приватные данные. Версия XGW не меняется.
bundle.json фиксирует архитектуру, компилятор, версии пакетов и хеши файлов. Это проверка
целостности, не цифровая подпись издателя. Архив передавать доверенным каналом.

После проверки SHA-256 распаковать архив и выполнить `sudo sh packaging/install.sh`
из его каталога xgw. Обычный установщик покажет общий план и зависимости, поставит nfqws2
в `/opt/xgw/zapret2/1.0.7`, не запуская его и не включая режим. Для настоящего рабочего
шлюза следовать отдельному TEST-PLAN, а не запускать полную установку ради приёмки комплекта.
Исходный репозиторий без сборки по-прежнему позволяет установить Python-часть XGW;
установщик явно сообщает об отсутствии комплекта. Для полной поставки использовать архив.

Явные binary/lua_dir существующего config.toml сохраняются, в том числе /opt/zapret2.
Новые настройки по умолчанию указывают на встроенный выпуск. Старые внешние файлы не удаляются.
Комплект устанавливается атомарно. Повторная установка того же комплекта допустима;
другой бинарник под тем же номером версии требует отдельного решения, не перезаписывается.
Удаление XGW удаляет встроенный комплект вместе с /opt/xgw, внешний /opt/zapret2 сохраняется.
Обновление выпуска zapret2 — отдельное изменение с хешами, сборкой и живой приёмкой.
