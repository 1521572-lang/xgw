# ThinkCentre. standalone r6: таблица стратегий без браузера и проба двух роликов

CODE `6114494127dbcef6a804b9140fbec9fab559b214`. Версия 0.2.0, freepool, GLM-5.3-Flash с root и Vision.
Отчёт r5 (e709082): расширенный список доменов помог, `fake_seq` впервые сыграла ролик без
VPN, но второй современный ролик не стартовал, а пять стратегий не опробованы. Критерий r5
«не больше двух пустых отрезков за 40 с» был ошибкой ТЗ: плеер качает буфер куском и молчит.
Код шлюза в r6 **не меняется и не устанавливается**: на машине остаётся 38c08e7 (три файла
окна могут быть от a73c790 — это допустимо). Новое только в помощнике: команда `nodes`
проверяет видеоузлы Google, назначенные этой линии (ASSUMPTIONS п. 388). Цель: стратегия, с
которой играют **оба** ролика, либо честная таблица, где какая стратегия ломается.

## 1. Исполнитель и подготовка

Исполнитель сам выполняет команды и управляет окнами через Vision; нет доступа — запросить и
продолжить самому, владельца запускать команды не просить. Отчёт публикуется автоматически при
любом исходе. Прочитать отчёт r5. Разрешены смена режима и стратегии, таймер возврата. Не
менять чужие службы, WAN/LAN/Tailscale, sysctl, подписки, настройки рабочего стола; не
скачивать пакеты; не перезагружать ПК. Адреса роликов, имена видеоузлов, настройки и журналы —
приватно. Git и окна — от пользователя графической сессии `U` (определить, не угадывать).

Нужны работающий VPN, zapret2 off, capture on; selfcheck — восемь `lua_check=ok` (FAIL —
стратегию пропускать). Приватные файлы пользователя `U` (его домашний каталог `UH`):

В `W` — две ссылки, по одной в строке: **А** — ролик из приватного файла прежних прогонов

## 2. Включение режима

Создать `return-vpn.sh` и таймер блоком §4 ТЗ r3 со сроком **240 с**; только `active`
разрешает продолжить. В окне XGW открыть раздел zapret2 и нажать «zapret2 без VPN»,

snapshot "$D/ready.json"` — ready=true, vpn_bridges=0, queue=true, lease=true. Нет готовности
— §6. Есть — остановить этот таймер и сразу поставить новый тем же скриптом на **3600 с**.

## 3. Таблица стратегий без браузера (около 8 минут)

```bash
sudo install -m 644 "$S" /tmp/xgw-strategy-check.py   # пользователю каталог D закрыт
sudo python3 -I "$S" listed /tmp/xgw-listed.json
C="sudo -u $U python3 -I /tmp/xgw-strategy-check.py"
sudo python3 -I "$S" use fake_seq
$C nodes --watch "$W" --store "$NS" --fresh | grep nodes_ok || true
for s in fake_seq fake_ts hostfakesplit_md5 fakedsplit_md5 seqovl multisplit multidisorder fake_md5; do
  echo "== $s" | tee -a "$D/table.txt"
  sudo python3 -I "$S" use "$s" | tee -a "$D/table.txt" || continue
  $C hosts --listed /tmp/xgw-listed.json | { grep -E '"ok": false|_ok=' || true; } | tee -a "$D/table.txt"
  $C nodes --watch "$W" --store "$NS" | { grep nodes_ok || true; } | tee -a "$D/table.txt"
done
```

Первая `nodes --fresh` читает страницы роликов А и Б (под `fake_seq` страница открывается) и
запоминает до четырёх видеоузлов на ролик в приватный файл; печатает только
`videoN_nodes_ok=X of M page=СТАТУС`. Имён узлов и ссылок в выводе нет — так и должно быть.
M=0 у обоих роликов — повторить `--fresh` один раз; снова 0 — записать значение `page=` и
вести §4 по порядку из цикла без отбора. Дальше для каждой стратегии: ready, какие
общеизвестные адреса не ответили, `zapret2_ok`, `direct_ok` и ответы тех же узлов.

В отчёт — таблица из восьми строк: стратегия, ready, zapret2_ok, список неответивших адресов
(имена из вывода `hosts` — это общеизвестные служебные имена), video1_nodes_ok,
video2_nodes_ok. **Отбор для §4:** сортировать по сумме nodes_ok обоих роликов, при равенстве
— по zapret2_ok, при равенстве — по порядку цикла. Взять четыре верхние; стратегии с нулём
ответивших узлов (при M>0) не брать. `fake_seq` пробуется всегда, первой.

## 4. Браузер: два ролика на стратегию

Перед §4 заменить таймер новым на **3600 с**. Профиль Firefox — новый, обычного пользователя,
без расширений и прокси. Одна проба стратегии:

1. `sudo python3 -I "$S" use ИМЯ` (ready=false — записать reason, следующая);
2. разблокировать экран, закрыть **все** окна Firefox этого профиля;
3. открыть ролик А, при необходимости Play, сразу `sudo python3 -I "$S" measure 90 | tee -a
   "$D/measure.txt"`; по Vision: позиция плеера в начале и в конце замера, качество, сколько
   секунд суммарно был спиннер;
4. в том же окне открыть ролик Б и повторить шаг 3.

Ролик **играет**, если за 90 с позиция ушла вперёд не меньше чем на 60 с, спиннер после старта
суммарно не дольше 10 с, down_mib ≥ 5 и worker_stable=true. `stalled_steps` записать, но в
критерий не включать. Стратегия **годна** — играют оба; **частично** — один. Остановиться на
первой годной; одна проба на стратегию. В отчёт — по строке на каждый ролик каждой пробы:
стратегия, ролик А/Б, down_mib, mbit_s, stalled_steps, позиция начало→конец, качество, итог.

## 5. Годная стратегия: подтверждение и выключатель в окне

Заменить таймер новым на 1800 с. Блоком §5 первого ТЗ (`…-zapret2-standalone.md`) с D/H:
snapshot до, ролик Б 60 с с перемоткой вперёд, snapshot после, delta. PASS VIDEO: ролик видимо
играет, direct_data_confirmed=true, download ≥ 2 МиБ, vpn_delta=0, PID и конфиг прежние.

Выключатель (в r4 и r5 — NOT_RUN): в окне XGW на «Обзоре» большая кнопка с надписью
**«Выключить перехват»** (в новом виде окна — в белой карточке слева, в прежнем — по центру
под заголовком). Нажать → `systemctl is-active xgw-zapret2.service` не active, обычный сайт
открывается напрямую. Кнопка стала **«Включить zapret2»** — нажать → снова ready по snapshot.
Отказы обработчика и рестарт демона проверены в r5, здесь не повторять.

Всё PASS — остановить таймер, оставить режим без VPN с найденной стратегией включённым по
поручению владельца; записать её имя.

## 6. Годной нет, возврат и первый отказ

VIDEO=PARTIAL, если хоть один ролик играл, иначе FAIL. Оставить в настройках лучшую из
частичных (`sudo python3 -I "$S" use ИМЯ`; нет частичных — `fake_seq`). Возврат — как §6 ТЗ
r3: связь есть — `sudo /bin/bash "$D/backup/return-vpn.sh"` и остановить свой таймер; связи
нет — команд не слать, таймер вернёт VPN. Проверить режим off и работающий VPN. В любом
исходе в конце: `sudo -u "$U" rm -f "$NS"` (имена узлов не хранить) и остановить запрет
простоя, если запускали. Указать конечный режим, стратегию, активные таймеры.
