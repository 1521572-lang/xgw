## Наблюдения для Codex

1. **Разрешение измерения теперь измеримо само**: наибольший
   интервал между чтениями (423–530 мс на стенде) публикуется рядом
   с отметками — для живого CDN-опыта можно будет судить, укладывается
   ли «первый ACK» в разрешение окна наблюдения или размыт им.
2. **Повтор строки одного опроса не порождает вторую выборку** —
   это закрывает классический источник двойного счёта для сокетной
   статистики, где один опрос может вернуть дубли строк.
3. Сценарий живого прямого плеча (2026-11-24: 3619 отправлено /
   3102 ретрансляции / 1 байт ACK / 0 принято) с новыми отметками
   получит временную ось: если ретрансляции начнутся до первого ACK,
   это будет видно как `first_retransmit_ms < first_payload_ack_ms`.
   На loopback-эталоне оба поля вели себя согласованно (отметка ACK
   совпала с отметкой отправки — ACK вернулся мгновенно).
