# ThinkCentre · HTTPS с физического LAN-клиента, повторная приёмка T12

**Ubuntu 24.04 LTS. Кандидат — `9e38fb2be264adf6780c3929cd7738ed09ea130e`.** Системный стенд подтвердил путь Xray → sing-box → Hysteria2. Эта проверка обращается к живому рабочему пути с отдельного устройства LAN. Предыдущее ТЗ остановилось на отсутствии доверенного SSH-клиента. Доступный авторизованный терминал этого устройства теперь тоже подходит. [Отчёт системного стенда](https://github.com/1521572-lang/xgw/blob/2bdedd2426a132e03385a05545883ee57bb0116a/docs/reports/2026-11-26T100637Z_release-system-singbox-lan.md) · [Предыдущий отчёт LAN](https://github.com/1521572-lang/xgw/blob/9e4c025efb5404086ae601f3dc535a9e881521dd/docs/reports/2026-11-24T220450Z_t12-lan-https.md)

## Подготовка клиента

Flash сама выполняет команды. При отсутствии доступа запросить авторизованный терминал или доверенный SSH-алиас устройства. Для SSH задать `XGW_T12_LAN_SSH`. Для работы через два терминала задать `XGW_T12_LAN_TERMINAL=1` на шлюзе и заранее перенести `lan_https_sample.py` на LAN-клиент. Клиенту нужны python3, curl и ip. При нескольких IPv4 на LAN-интерфейсе шлюза задать `XGW_T12_LAN_GATEWAY` равным адресу из настроек клиента. Штатный перехват должен быть включён. [Скрипт клиента из базовой ревизии](https://github.com/1521572-lang/xgw/blob/9e4c025efb5404086ae601f3dc535a9e881521dd/docs/helpers/lan_https_sample.py)

Для двух терминалов подготовить команду на клиенте заранее. Запустить **один раз** после `LAN_WINDOW_READY` на шлюзе. Передачу JSON выполнять после закрытия окна, по доступному приватному каналу.

```bash
umask 077
sample=$(mktemp)
python3 -B ./lan_https_sample.py >"$sample"
printf 'Private sample: %s\n' "$sample"
```

После завершения 20-секундного окна шлюз покажет путь назначения. Перенести в него результат с правами 0600. Исходные адреса, порты и журнал остаются в приватных файлах. Указание на шлюз через localhost за физический LAN не засчитывается.

## Запуск на шлюзе

Запустить из клона XGW с доступом через sudo к чтению состояния и журнала. Для терминального режима нужен доступ к двум терминалам и к файлу результата. Для SSH требуется действующая авторизация с уже доверенным ключом хоста. Тест использует рабочий маршрут клиента, штатный журнал Xray и один ограниченный HTTPS GET. Смена выхода, сетевых правил и настроек SSH в эту проверку не входит. [Git bundle](https://github.com/1521572-lang/xgw/blob/docs/flash-proton-ui-manifest/docs/handoff/artifacts/xgw-t12-lan-https-r2.bundle)

```bash
bash <<'BASH'
set -euo pipefail
umask 077
. /etc/os-release
[[ $ID == ubuntu && $VERSION_ID == 24.04 && $EUID != 0 ]]
BR=docs/flash-proton-ui-manifest
CODE=9e38fb2be264adf6780c3929cd7738ed09ea130e
REPO=$(git rev-parse --show-toplevel)
PY=/usr/bin/python3
TEST_PY=${XGW_TEST_PYTHON:-$PY}
D=$(mktemp -d "$HOME/xgw-t12-lan-r2.XXXXXXXX")
git -C "$REPO" fetch --no-tags origin "refs/heads/$BR"
git -C "$REPO" show FETCH_HEAD:docs/handoff/artifacts/xgw-t12-lan-https-r2.bundle >"$D/lan.bundle"
printf '%s  %s\n' '16859eb4c0d7bd7076422cb49b3251a097e2be07a7b2f64f4321b12e616742b8' "$D/lan.bundle" | sha256sum --check -
git -C "$REPO" bundle verify "$D/lan.bundle"
git -C "$REPO" fetch "$D/lan.bundle" refs/heads/feat/reproducible-proton-ui-and-manifest
test "$(git -C "$REPO" rev-parse FETCH_HEAD)" = "$CODE"
mkdir "$D/tree"
git -C "$REPO" archive "$CODE" src tests docs/helpers vpn_ui pyproject.toml | tar -x -C "$D/tree"
printf 'OS %s\nPINNED %s\nPRIVATE_ARTIFACTS %s\n' "$PRETTY_NAME" "$CODE" "$D"
uname -r
export PYTHONPATH="$D/tree:$D/tree/src:$D/tree/tests"
export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTEST_ADDOPTS=
cd "$D/tree"

snapshot() {
  sudo -n timeout -k 3 60 "$PY" -I -B - snapshot <docs/helpers/audit_host_observe.py &&
    sudo -n sha256sum /etc/xgw/config.toml /etc/xgw/panel.json
}

xray_snapshot() {
  sudo -n timeout -k 2 8 /usr/bin/env -i PATH=/usr/sbin:/usr/bin:/sbin:/bin \
    "PYTHONPATH=$D/tree/src" "$PY" -B -P -m xgw.desync.route_evidence snapshot
}

run_phase() {
  local label=$1 code=0
  shift
  "$@" >"$D/$label.log" 2>&1 || code=$?
  tail -n 16 "$D/$label.log"
  printf '%s_EXIT %s\n' "$label" "$code"
  return "$code"
}

client_window() {
  local host=${XGW_T12_LAN_SSH:-} terminal=${XGW_T12_LAN_TERMINAL:-0} gateway start end
  if [[ $terminal == 1 ]]; then
    [[ -z $host ]] || { printf 'LAN_CHOOSE_ONE_CLIENT_METHOD\n'; return 3; }
    exec 3<>/dev/tty || { printf 'LAN_TERMINAL_UNAVAILABLE\n'; return 3; }
  elif [[ -z $host ]]; then
    printf 'LAN_NOT_RUN_NO_AUTHORIZED_CLIENT\n'
    return 3
  fi
  [[ $host != -* && $host != *[[:space:]]* ]] || return 3
  sudo -n timeout -k 2 15 xgw status --json >"$D/status.private.json" \
    2>"$D/status.private.err" || { printf 'LAN_STATUS_UNAVAILABLE\n'; return 3; }
  gateway=$("$PY" -B -P - "$D/status.private.json" "${XGW_T12_LAN_GATEWAY:-}" <<'PYTHON'
import json
import subprocess
import sys
from pathlib import Path

from xgw.desync.lan_control import _lan_address


def gateway():
    capture = json.loads(Path(sys.argv[1]).read_bytes())["capture"]
    interface = capture.get("lan_if")
    if (capture.get("mode") != "on" or capture.get("lan") is not True
            or capture.get("loaded") is not True or capture.get("blocked") or not interface):
        return None
    data = subprocess.check_output(["ip", "-j", "-4", "address", "show", "dev", interface],
                                   stderr=subprocess.DEVNULL, timeout=3)
    addresses = set()
    for link in json.loads(data):
        for row in link.get("addr_info", []):
            try:
                addresses.add(str(_lan_address(row.get("local"))))
            except ValueError:
                continue
    selected = sys.argv[2]
    if selected:
        return selected if selected in addresses else None
    return next(iter(addresses)) if len(addresses) == 1 else None


try:
    address = gateway()
except (OSError, ValueError, KeyError, subprocess.SubprocessError):
    address = None
if not address:
    raise SystemExit(3)
print(address)
PYTHON
  ) || { printf 'LAN_GATEWAY_UNCONFIRMED\n'; return 3; }

  if [[ $terminal == 1 ]]; then
    printf 'Prepare the LAN terminal. Press Enter on this terminal when ready.\n' >&3
    read -r -t 60 -u 3 || { printf 'LAN_NOT_RUN_TERMINAL_NOT_READY\n'; return 3; }
  fi
  start=$(date +%s) || return
  xray_snapshot >"$D/xray.before.json" || { printf 'LAN_XRAY_BEFORE_UNAVAILABLE\n'; return 3; }
  if [[ $terminal == 1 ]]; then
    printf 'LAN_WINDOW_READY · Run one LAN sample now. Window: 20 seconds.\n' >&3
    sleep 20
  else
    timeout -k 2 20 ssh -T -o BatchMode=yes -o StrictHostKeyChecking=yes -o ConnectTimeout=4 \
      -- "$host" 'python3 -B -' <docs/helpers/lan_https_sample.py \
      >"$D/client.json" 2>"$D/client.private.err" \
      || { printf 'LAN_CLIENT_SAMPLE_UNAVAILABLE\n'; return 3; }
  fi
  xray_snapshot >"$D/xray.after.json" || { printf 'LAN_XRAY_AFTER_UNAVAILABLE\n'; return 3; }
  end=$(date +%s) || return
  end=$((end + 1))
  sudo -n timeout -k 2 8 journalctl -q --no-pager -b -u xgw-xray.service \
    --since "@$start" --until "@$end" -n 512 -o json --output-fields=MESSAGE,_PID,_BOOT_ID,_SYSTEMD_UNIT \
    >"$D/xray.private.jsonl" 2>"$D/xray.private.err" \
    || { printf 'LAN_JOURNAL_UNAVAILABLE\n'; return 3; }
  if [[ $terminal == 1 ]]; then
    printf 'Save the private JSON as %s/client.json, chmod 600, then press Enter.\n' "$D" >&3
    read -r -t 120 -u 3 || { printf 'LAN_CLIENT_SAMPLE_UNAVAILABLE\n'; return 3; }
    [[ -f $D/client.json && ! -L $D/client.json ]] || return 3
  fi
  "$PY" -B -P -m xgw.desync.lan_control --require-vpn --gateway "$gateway" "$D/client.json" \
    "$D/xray.before.json" "$D/xray.after.json" "$D/xray.private.jsonl"
}

before=0
snapshot >"$D/state.before" 2>"$D/snapshot.before.err" || before=$?
run_phase CONTRACTS timeout -k 3 120 "$TEST_PY" -B -P -m pytest \
  -o addopts= -p no:cacheprovider --color=no -v -rs --tb=short --portable \
  --basetemp "$D/pytest" tests/test_desync_lan_control.py tests/test_desync_vpn_control.py \
  tests/test_desync_route_evidence.py tests/test_selective_probe_watch.py || true
run_phase LAN client_window || true
after=0
snapshot >"$D/state.after" 2>"$D/snapshot.after.err" || after=$?
if [[ $before == 0 && $after == 0 ]]; then
  if cmp -s "$D/state.before" "$D/state.after"; then
    printf 'T12_GATEWAY_UNCHANGED\n'
  else
    printf 'T12_GATEWAY_SNAPSHOT_DIFF\n'
  fi
else
  printf 'T12_GATEWAY_SNAPSHOT_NOT_AVAILABLE %s %s\n' "$before" "$after"
fi
BASH
```

## Критерии и публикация

LAN считается пройденным при `LAN_EXIT 0`, завершённом HTTPS и `accepted_route.state=observed`. Группа `xray` подтверждает обычный VPN с физического клиента. Для закрытия живого моста нужен результат `group=sing-box` для самого запроса. Если в рабочем составе нет пригодного участника моста или запрос шёл через Xray, указать этот пункт как `NOT_RUN`. При неполном HTTPS или неустановленном маршруте сохранить точную причину. При недоступном клиенте выполнить контракты и зафиксировать `NOT_RUN`.

Сверить хеши и состояние шлюза до и после. При любом исходе опубликовать один обезличенный `docs/reports/<UTC>_t12-lan-https-r2.md` в ветке `docs/flash-proton-ui-manifest`. Указать SHA кандидата, версии, SSH или терминал, код HTTPS, байты, категорию маршрута и итог сравнения шлюза. Адреса, порты, исходный JSON и журнал не публиковать.
