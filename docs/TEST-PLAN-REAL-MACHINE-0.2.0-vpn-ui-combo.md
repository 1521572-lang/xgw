# ThinkCentre. Стрелки выпадающих списков XGW

CODE `4141854b061b5af70c0f027d014afa01ae83064f`, ветка freepool. Предыдущий отчёт
8e25fd8 подтвердил карту и карточки серверов. Здесь проверяем оформление списков
и управление ими в рабочем окне. Для проверки подходит установленная после этого
отчёта панель. Окно запускается из исходников от пользователя графической сессии.

Исполнитель сам запускает команды и управляет окном через Vision. При отсутствии
терминала или графического доступа запрашивает доступ и продолжает сам. Для входа
использует сохранённый сеанс или polkit. При NoNewPrivileges окно запускать через
пользовательский systemd. Установку модулей и перезапуск служб этот прогон не требует.

```bash
set -euo pipefail
cd "${XGW_REPO:-$HOME/xgw}"
REPO=$PWD
git fetch origin freepool
CODE=4141854b061b5af70c0f027d014afa01ae83064f
git merge-base --is-ancestor "$CODE" origin/freepool
umask 077
D=$(mktemp -d "$HOME/xgw-vpn-ui-combo.XXXXXXXX")
git worktree add --detach "$D/new" "$CODE"
cd "$D/new"
python3 -c 'from PyQt6 import QtWidgets, QtSvg'
date -u +%FT%TZ
python3 vpn_ui/main_xgw.py --theme light --native-titlebar
```

Сначала закрыть предыдущий экземпляр нового окна, если он открыт. Проверить
при 1024×720 и в развёрнутом окне:

1. У фильтра, сортировки и выбора темы справа тонкий шеврон на общем фоне поля.
   Нет отдельной рамки или серого прямоугольника под стрелкой. Текст и шеврон
   не накладываются. После Tab рамка фокуса видна вокруг всего поля.
2. Щелчок по стрелке и по тексту открывает список. Изменить фильтр и сортировку,
   проверить результат, затем повторить с клавиатуры. Escape закрывает список.
   Вернуть исходные значения. Эти действия меняют только представление каталога.
3. Через настройки сменить светлую тему на тёмную и обратно. Шевроны остаются
   читаемыми. В разделе «Устройства» осмотреть список маршрута, в настройках zapret2
   — список стратегий, если доступны. Отменить открытые диалоги без сохранения.
4. Закрыть окно и сверить состояние VPN, zapret2 и ручного выбора сервера с исходным.
   В отчёте записать PASS/FAIL/NOT_RUN по пунктам, время UTC, CODE и первое расхождение.
   При недоступном списке указать причину. Имена, адреса и снимки сохранить приватно.

При любом исходе исполнитель публикует
`docs/TEST-REPORT-REAL-MACHINE-0.2.0-vpn-ui-combo-ДАТА.md` автоматически.
В исходном REPO обновить чистую ветку freepool через fetch и merge --ff-only.
Закоммитить только отчёт, выполнить обычный push, сверить файл на GitHub
и сообщить ссылку и хеш. При гонке перенести свой коммит на свежую origin/freepool
без force. При отсутствии доступа к публикации сохранить файл и указать причину.
