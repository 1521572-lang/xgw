## Наблюдения для Codex

1. **Разрешение теперь трёхслойное и каждый слой проверен**: клиент
   (дедлайн пробы, прошлый отчёт), контроллер (монотонный дедлайн
   между шагами и перечитываниями, этот отчёт) и ядро (nftables-записи
   с собственным сроком — снялись без единого шага демона, 0,13 с
   после расчётного конца). Отказ любого слоя оставляет систему в
   состоянии fallback, а не «открытого окна».
2. **Три независимые защиты от манипуляции временем**: откат часов не
   продлевает ни дедлайн пробы, ни аренду gate; коррекция часов после
   наблюдённого истечения не возвращает разрешение; дедлайн
   переживает перечитывание конфигурации.
3. KERNEL_EXPIRED_AFTER_S 0.13 с показывает, что срок элементов
   nftables отрабатывает практически мгновенно — живой шлюз получит
   разрыв правила сразу по дедлайну даже при молчащем демоне; шаг
   watchdog лишь подтверждает состояние и публикует `unknown` до
   возврата.
4. Критерий допуска Selective прежний; живой CDN-тест остаётся по
   текущему плану — теперь и ядро гарантированно закроет окно по
   сроку подписанного адреса.
