## Наблюдения

1. Основное исправление подтверждено объективно: с живой вкладкой команда открытия НЕ
   создаёт новую вкладку (ни скрытия, ни закрытия старой, окно Chromium одно), а выводит
   окно с панелью вперёд через KWin — именно то, чего хотел заказчик («можно сделать
   незаметным открытие второй вкладки?» из отчёта tray-icon).
2. Новая вкладка открывается только когда вкладки нет (после Ctrl+W панель открылась сразу).
3. Телеметрия вкладки (page.py) — точный инструмент: события «скрылась/закрылась» совпадают
   со сворачиванием окна и закрытием вкладки до долей секунды. Мелочь: в 3.6 «скрылась»
   (3,2 с назад) зафиксировалась на 0,2 с позже «закрылась» (3,4 с назад) — порядок событий
   при закрытии, на работу не влияет.
4. Заказчик не отвечал на запросы §3 — сценарии выполнены исполнителем; визуальную оценку
   («не мигает») стоит собрать у заказчика попутно при следующей программе (одним вопросом).
