## Наблюдения

- Обе доработки по отчёту А3.2 подтверждены на реальной машине: строка сервера видна
  сразу после выключателя (прокрутка к новому месту строки работает в обе стороны), и
  на каждое действие с телефона — одно событие.
- Третья доработка (имена без пробелов) сработала сама при получении подписок после
  установки — шаг 3.2 («Обновить подписки» с телефона) не понадобился.
- В начале шага 4.1 телефон был с потухшим экраном и открытой шторкой — приложение
  уходило с экрана, первый поиск запасного не удался; после разблокировки всё прошло.
  Для будущих прогонов полезно держать экран включённым (скрипт ставит «не гасить на
  USB» только в `devices`, который в этом ТЗ не вызывался до шага 2.3).
- У скрипта a33check.py нет команды показа текущего экрана (в А3.2 была `texts`, тут
  только `tab`) — при разборе «неудач» пришлось пользоваться `tab`/`tap`; мелкое
  неудобство исполнителя, не дефект.
- DEGRADED держится по причине Р1 весь день (отдельный разбор); на это испытание не
  повлиял: выключатель, события и имена работают.
