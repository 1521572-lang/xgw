## Наблюдения для Codex

1. **Форматный дрейф Xray 26.11.9**: префикс схемы в строке «accepted»
   изменился с `tcp:` на `//`. Стоит принимать обе формы в helper
   (однострочная правка) — иначе вся XRAY-фаза невоспроизводима на
   актуальной сборке; наблюдение на loglevel warning работает, уровень
   менять не нужно.
2. **Сценарий смены CDN закрыт на реальном ядре**: даже при отказе API
   при уходе watchdog старая привязка снимается до остановки воркера, а
   если снять не удалось — gate остаётся закрытым и пробы не
   начинаются (кейс `withdrawal_rejected`). Клиент в это время
   обслуживается VPN — окно «двойного маршрута» отсутствует.
3. Неудачная новая проба оставляет клиента на VPN без колебаний
   посторонних маршрутов — поведение согласуется с требованием
   «переключение только по подтверждённому результату».
