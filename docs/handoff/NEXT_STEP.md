# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** установи принятый журнал закрепления и
диагностику домашнего выхода по сценарию из `844984a1a217d0b117dc44600baa7090f8db301e`.
Установщик проверяет совместимость с фактическими файлами,
прогоняет 13 контрактов и ставит независимый таймер отката.
[ТЗ установки](PIN-AUDIT-INSTALL-2026-11-22.md)

В r2 все 13 контрактов прошли за один запуск, две фазы дали
код 0, совпали 41 событие, PID и SHA настроек. Имена источников
проверены на фикстурах. Для штатной записи событий требуется
установка. [Последний отчёт](../reports/2026-11-22T121135Z_home-exit-incident-r2.md)

Живая ротация Selective ждёт успешного прямого допуска.

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
