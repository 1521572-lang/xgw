  Срок жизни пригодной подписи не измерен (пригодной подписи нет); статусы сохранены
  приватно (probes.json 0600: страница + SABR-URL, не передавались в argv, в Git не

## 3. Selective, fallback и второе ядро

- **Selective не открылся** (см. п. 1) — клиентское прямое правило не появлялось,
  видео во время попытки продолжалось через VPN. Повторные циклы gate (check 300,
  retry 300) удерживали состояние fallback; безопасный отказ подтверждён счётчиками.
- **Fallback по SIGKILL воркера** в явном виде не выполнялся: в момент проверки
  воркер уже был released (gate закрыт из-за probe_failed), состояние эквивалентно
  пост-отказному: прямое правило отсутствует, YouTube через VPN (+510 МБ), VPN-выход
  жив. Отдельную эмуляцию отказа активного воркера не проводил — прямого активного
  воркера в Selective получить не удалось (тот же блокер проб).
- **evidence.vpn_control = fail / request_failed**: служебная проверка первого URL
  через штатный VPN-probe-inbound не прошла (точный код зафиксирован; страница через
  обычный VPN-socks при этом 200 за ~2 c — расхождение указывает на служебный
  probe-inbound/порт 19999, не на VPN). Служебная проба не должна использоваться как
  признак доступности видео — предупреждение ТЗ соблюдено.
- **Второе ядро**: подписка содержит только xray-профили; sing-box-мост поднят
  штатным pin ядра на запасном сервере (`xgw core <server> sing-box` → bridged=1,
  сервер жив, статус [sb]). Короткие замеры второго ядра — в таблице выше. После
  замеров pin снят (`unpin`, `core auto`) — балансировщик вернул автосостав; в момент
  медиа-интервала первого захода конфиг пересобрался (прибор отклонил интервал) —
  честная особенность «автопрофилирование меняет конфиг» задокументирована.
- **Длинный 15+5 в Selective** — NOT_RUN: короткая фаза не открылась (блокер проб).
  Отдельно не компенсировался: по ТЗ длинная фаза только после подтверждения короткой.
