## Наблюдения для Codex

1. **Локальный транспорт закрыл обе живые загадки 24.11 управляемыми
   эквивалентами**: «302 повторно» на контрольном плече — это кейс
   `full_range` с одним переходом по дедлайнам, а зависание
   TLS-рукопожатия с CDN — кейсы `page_tls_stalled` /
   `redirect_tls_stalled` с остановкой по сроку цели. Теперь обе
   стороны имеют воспроизводимый эталон без WAN.
2. **Защита от перевода часов назад** — поздний успех отклоняется и
   не обновляет `last_transport_ok_at`; срок подписанного адреса
   является настоящим дедлайном, а не «рекомендацией».
3. Приватность выдержана: подписанный адрес не попадает в статус
   (`expire=` отсутствует в JSON), ключи и тестовый сертификат
   остались на машине.
4. Критерий допуска Selective прежний — 206/65536 на обоих плечах;
   цепочка пробы теперь ограничена сроком адреса, поэтому живой
   CDN-тест по текущему плану получит предсказуемый бюджет даже при
   зависании рукопожатия.
