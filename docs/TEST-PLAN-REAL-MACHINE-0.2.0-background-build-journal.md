# Пересчёт долгих шагов по журналу уже завершённого прогона

В отчёте 261808d запись статуса ≤25 с, сборки и on/HTTPS прошли десятиминутный прогон.
Остался счётчик шагов от 60 с: прежний parser не учитывал префикс даты/логгера.
Это только чтение прежнего периода, не новый тест шлюза. Установленный код не обновляется.
Все доступные инструменты для чтения разрешены, включая терминал, браузер и машинное зрение.
Сырые журналы и приватное состояние в Git/чат не отправлять. Итог — одна страница с числами.
Не выполнять prepare/start/refresh, не повторять наблюдение, не менять сеть/службы/настройки.
Не трогать /run/xgw-status-acceptance: в нём уже завершённый запуск и его точные границы времени.

Это обновление клона, не установленного XGW.

## 3. Один раз прочитать прежний журнал и сохранить безопасный результат

```bash
cd "$HOME/zcod/xgw" && test ! -e "docs/TEST-REPORT-REAL-MACHINE-0.2.0-background-build-journal-$(date +%F).md" && sudo -n python3 -I -B "$HOME/zcod/xgw/docs/helpers/background_build.py" recount > "docs/TEST-REPORT-REAL-MACHINE-0.2.0-background-build-journal-$(date +%F).md"
```
Ожидается rc0. Помощник проверяет старый SHA, завершённый успешный state и точные границы окна.
Читается только journalctl -u xgw.service от начала обновления двух файлов до сохранения итога.
В вывод попадают длительность окна, число записей/запусков и число шагов от 60 с, без текста логов.
Для проверки наличия начала журнала обязателен хотя бы один запуск демона в этом окне.
Нет начала окна, пропали /run/журнал или данные не читаются — rc3, не выдумывать ноль.
Rc3 означает STOP: сообщить безопасный этап. Не устанавливать ничего ради восстановления данных.
При тайм-ауте инструмента дождаться уже выполняющейся команды; не начинать новый прогон.
Команда не меняет runtime, не выполняет сеть/API, не перезапускает службы и не пишет в /run.

Ожидается заголовок `Пересчёт долгих шагов завершённого прогона` и `Сбор данных: завершён`.

Не переписывать исходный отчёт 261808d и не выдавать пересчёт за повтор 102 наблюдений или сборок.
