# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** запусти задание для `06cad10`. Оно
пересчитывает две сохранённые записи mpv, отдельно показывает
состояние буфера и вердикт воспроизведения, затем проверяет
контракты меток T03–T05 и разбор правил nftables ядром.
[Готовое ТЗ](PLAYBACK-METRICS-AND-MARKS-2026-11-21.md)

В r2 после перемотки прошло 300 с в 720p с прогрессом 99,77% и без
остановок. Один сокет подтверждён в группе Xray, контроль шлюза
прошёл. Живая ротация Selective ждёт успешного прямого допуска.
[Последний отчёт](../reports/2026-11-21T112442Z_selective-vpn-seek-300.md)

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
