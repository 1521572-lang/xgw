## Дефекты
1. (отклонение, на решение разработчика) **Перепроверка молчащего не прошла по пути «вне
   очереди»**: журнал — «перепроверка молчащего вне очереди: 0», дневник — «молчащих
   перепроверено вне очереди: 0»; при этом перепроверка (TIMEOUT) прошла через ~2 мин после
   блокировки — штатной ранней очередью («серверы в работе перепроверяются первыми»), до порога
   5 минут тишины, и журнальной строки «сервер пула pool-… молчит у проб ядра N мин —
   перепроверка вне очереди» не было. Суть правки подтверждена другой частью: молчащий выбыл из
   состава ровно на ~5-й минуте тишины (304 с), «выбыло из состава: 1» в дневнике. Предположение:
   ранняя очередь опережает 5-минутный порог при обычном числе живых серверов; путь «вне очереди»
   достижим только при перегруженной очереди проверок (как в сценарии плана М3) — в проверенном
   сценарии он не задействуется.
2. (мелкий, не по ожиданию) Холодный старт: перепроверены 7 из 8 — добавленный на место
   выбывшего сервер (без «состаренной» проверки) не перепроверен за 7 минут; и до перепроверок
   серверов в работе прошла 1 проверка сервера списков. Главный критерий не нарушен (состав
   8 из 8 сохранён, «закрыто»: 0, дом не прерывался).

## Наблюдения
1. Сценарий «сервер замолчал» отработал: смена на другой сервер за 93 с (дом подвисаний не
   почувствовал — заказчик не сообщал), перепроверка TIMEOUT, выбытие из состава на ~5-й минуте
   тишины, место занял следующий допущенный; «ЗАКРЫТО» не было ни в одном замере.
2. Причина смены — «выбранный вручную не отвечает»: сервер оставался под сохранённым ручным
   выбором заказчика из прошлой вехи (в diary заказчик выбирал серверы вручную и «Автовыбор» не
   нажимал). Формулировка причины отличается от заявленной «„X“ не отвечает» — категория та же
   (сервер не отвечает), учтена помощником отдельно.
3. Ручной выбор пережил возврат режима подписок и включение «весь дом»: первый выбор в 4.3 сразу
   пошёл через сохранённый pin (событие «— выбран вручную» ещё на первом выборе). Возможно, стоит
   снимать ручной выбор при возврате режима подписок (сейчас снимается только «Автовыбором» или
   `pin auto`) — чтобы долгие сессии не начинались с несвежего выбора.
4. Холодный старт прошёл без последствий: Xray продолжал вести дом, демон вернулся за ~5 с,
   состав 8 из 8 сохранён (строка KEEP = сутки работает), «закрыто»: 0; первые перепроверки —
   именно серверов в работе (последняя — через 151 с), и только одна посторонняя проверка списка
   вклинилась.
5. status-файл при включении «весь дом» отстал более чем на 3 минуты (watch не увидел переход;
   события показывают применение на +30 с и первый выбор на +48 с) — то же наблюдение было в
   diary-вехе; предположение: демон обновляет сводку после полного шага, который при включении
