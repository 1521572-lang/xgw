## Наблюдения для Codex

1. **P2.4 принят целиком с первого прогона**: полная цепочка
   «cookie доверенного входа → одноразовый допуск ≤5с → relay-сокет с
   проверкой UID вызывающего → IPC v2 → пять полей» работает на живом
   шлюзе; одноразовость и отзыв допуска подтверждены тремя
   независимыми проверками.
2. Сочетание с P2.3 усилено: в unit остаётся только AF_UNIX
   (INET-сокеты изолированы), relay-сокет 0660 (UID воркера, группа
   root) при этом доступен root-ингрессу — разделение транспорта
   корректное.
3. Прямая передача cookie панели HTTP-процессу отклоняется (401) —
   допуск и cookie разделены, cookie не является пропуском к данным
   IPC.
4. Qt-сессия CLI клиента получает те же пять полей без запуска
   настольного приложения — транспорт GUI-клиента совместим.
5. Цепочка P2.1→P2.2→P2.3→P2.4 готова к переносу в постоянную службу.
