# Проверка XGW 0.1.18: один значок в трее и теги серверов в событиях обхода

**Для исполнителя.** Выполняй шаги строго по порядку. В каждом шаге — команда (копируй
целиком), «Ожидается» и «Если не так». Ничего не придумывай сверх написанного. Не уверен —
остановись и спроси заказчика. Выводы сохраняй в файлы, как написано (`$HOME/xgw-018-tray/…`).

Машина: ThinkCentre, Ubuntu 24.04.5 LTS, рабочий стол KDE Plasma, XGW 0.1.18 с кодом ветки
`tspu-speed-tray` (23757ee), заказчик вошёл в рабочий стол. Клон — `~/zcod/xgw`.

Что исправлено (ASSUMPTIONS пп. 240 (е) и 241):

1. **В трее было три значка XGW.** Каждая установка запускала новый значок, не закрывая
   прежний. Теперь значок один: второй запуск сразу выходит, а установка закрывает прежние
   значки (и запущенные до исправления) и встаёт на их место.
2. **Теги в событиях обхода.** После имени сервера в событиях profile и fragment стоит его
   тег: «🇪🇺 🚀Авто | Лучший сервер ⚡⚡ …» (spare-eu-13c2) — двенадцать серверов с одним
   именем больше не выглядят как один.

## 0. Запрещено

- `xgw net down`, `xgw disable`, `xgw uninstall`, `reboot`, сон машины, `install.sh --force` —
  **никогда**. Запуск, остановка и перезапуск служб `xgw*`, `tailscaled`, NetworkManager,
  `ssh`; ручные `nft` (кроме `nft list`), `ip`, `iptables`, `tc`, `sysctl -w`.
- Править `/etc/xgw`, `/opt/xgw`, `/var/lib/xgw`, `/etc/systemd`, код XGW. Коммитить что-либо,
  кроме отчёта (§6).
- Закрывать процессы значка можно только командами шагов 2.4 и 2.5.
- Писать в отчёт: адреса tailnet, имена `*.ts.net`, имена устройств и пользователей (имя
  пользователя → `<user>`), внешние IP, токены, адреса подписок, IP и домены серверов VPN.
  Теги серверов (`spare-eu-13c2`) и номера процессов — можно, не заменять.

## 2. Установка и один значок

Шаг 2.1. Код:

```bash
cd ~/zcod/xgw && git fetch && git checkout tspu-speed-tray && git pull --ff-only && git log -1 --format='%h %s' && grep -q LOCK_NAME src/xgw/tray.py && grep -q _server_text src/xgw/daemon.py && echo "исправления в коде: есть"; cd "$HOME/xgw-018-tray"
```

Ожидается: «исправления в коде: есть». Записать хеш. Нет строки — **стоп**, сообщить заказчику.

Шаг 2.2. Установка:

```bash
cd ~/zcod/xgw && date '+%F %T' | tee "$HOME/xgw-018-tray/install-time.txt" && sudo sh packaging/install.sh --yes 2>&1 | tee "$HOME/xgw-018-tray/install.txt" | tail -8; echo "код ${PIPESTATUS[0]}"; grep -E 'значок в трее' "$HOME/xgw-018-tray/install.txt" | sed -E 's/для [^:]+:/для <user>:/'; cd "$HOME/xgw-018-tray"
```

Ожидается: «код 0», «демон xgw запущен», «значок в трее для <user>: автозапуск при входе,
запущен». Код не 0 — **стоп**, сохранить вывод, сообщить заказчику (сеть не тронута).

Шаг 2.3. Через 10 секунд — значок один:

```bash
sleep 10; pgrep -fa 'xgw tray' | sed -E 's/^[0-9]+ //' | tee "$HOME/xgw-018-tray/after.txt"; echo "значков (--run): $(pgrep -fc 'xgw tray --run')" | tee -a "$HOME/xgw-018-tray/after.txt"; echo "блокировка: $(cat "/run/user/$(id -u)/xgw-tray.lock" 2>&1), сторож: $(pgrep -f 'xgw tray --replace')" | tee -a "$HOME/xgw-018-tray/after.txt"
```

Ожидается: ровно две строки процессов — `/usr/bin/python3 -I /usr/local/bin/xgw tray
--replace` (сторож) и `… xgw tray --run` (значок); «значков (--run): 1»; в строке
«блокировка: N, сторож: N» — одно и то же число. **Спроси заказчика**: «Сколько значков XGW
сейчас рядом с часами?» — ожидается «один».

Если не так: значков больше одного — **дефект «значки не заменены»**: записать вывод целиком.
Ни одного — запустить его так же, как установка (`sudo systemd-run --user --machine="$USER@"
--quiet --collect -- /usr/local/bin/xgw tray --replace`), записать «не запустился при установке»
и выполнить шаг 2.3 снова.

Шаг 2.4. Второй запуск не добавляет значок:

```bash
/usr/local/bin/xgw tray; echo "код $?"; sleep 2; echo "значков (--run): $(pgrep -fc 'xgw tray --run')" | tee "$HOME/xgw-018-tray/second.txt"
```

Ожидается: «значок XGW уже запущен», «код 0», «значков (--run): 1». Если команда не вернулась
за 10 секунд (значит, встал второй значок) — нажать Ctrl+C, **дефект «второй значок
встаёт»**, записать.

Шаг 2.5. Замена, как при следующей установке:

```bash
before=$(pgrep -f 'xgw tray --run'); sudo systemd-run --user --machine="$USER@" --quiet --collect --description="XGW: значок в трее" -- /usr/local/bin/xgw tray --replace; sleep 8; after=$(pgrep -f 'xgw tray --run'); echo "значок был: $before, стал: $after; значков (--run): $(pgrep -fc 'xgw tray --run')" | tee "$HOME/xgw-018-tray/replace.txt"
```

Ожидается: «значок был: N, стал: M» — разные числа; «значков (--run): 1». **Спроси

Шаг 2.6 (при согласии на пункт 3). **Попроси заказчика**: «Выйдите из сеанса рабочего стола
