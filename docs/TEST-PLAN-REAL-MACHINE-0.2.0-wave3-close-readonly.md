# Однократное уточнение исходной проверки волны 3

Исполнитель — GLM-5.3-Flash на ThinkCentre. Это единственная уточняющая волна после STOP шага 4.
Рабочий on сохраняется. Никаких правок сети, установки, восстановления и переключений ядер.
WAN/LAN/Tailscale, пул и ручной выбор не трогать. Старые шаги 4–9 пока не продолжать.
Не удалять /run/xgw-wave3-close и не заменять лежащий там helper.py. Prepare не повторять.
Помощник остаётся одним файлом: docs/helpers/wave3_close.py.
Новая SHA-256: `65af212bf4c4501876842b165d708abfca075ee8b4242766cb79caaf0d0a22f3`.

## 1. Обновить только чистый клон freepool

```bash
cd "$HOME/zcod/xgw" && test "$(git branch --show-current)" = freepool && test -z "$(git status --porcelain)" && git fetch --quiet origin freepool && git merge --quiet --ff-only origin/freepool && printf 'Уточняющее задание получено
'
```
Ожидается `Уточняющее задание получено`, код 0. Если не так: STOP, без reset/rebase/force.
Установленный XGW не обновляется. Результат прежнего STOP остаётся прежним.

## 2. Проверить новую сумму файла в клоне

```bash
printf '%s  %s
' '65af212bf4c4501876842b165d708abfca075ee8b4242766cb79caaf0d0a22f3' "$HOME/zcod/xgw/docs/helpers/wave3_close.py" | sha256sum --check --status && printf 'Сумма нового помощника верна
'
```
Ожидается `Сумма нового помощника верна`, код 0. Иначе STOP, файл на машине не исправлять.

## 3. Один раз выполнить только чтение

```bash
sudo -n python3 -I -B "$HOME/zcod/xgw/docs/helpers/wave3_close.py" clarify
```
Команда запускается из нового файла в клоне; старый файл в /run не выполняется и не заменяется.
Она читает состояние, правила, счётчики и права, делает одну прежнюю HTTPS-пробу.
Loaded запускается отдельно, предел остаётся 8 с. Он не увеличивается ради зелёного результата.
Все независимые проверки выполняются, даже если одна не прошла. Результат каждой сохраняется сразу.
Нет фонового worker, таймера, xgw net up, runuser, временных ip rule или файлов в состоянии XGW.
Пишется только запись уточнения в существующие приватные заметки помощника в /run.

Ожидается заголовок `# Уточнение исходной проверки волны 3` и шесть подписанных результатов:
- Состояние HEALTHY;
- Перехват on;
- Соответствие правил (loaded): true, false, неизвестный ответ или тайм-аут различаются;
- Барьер POSTROUTING и счётчики;
- HTTPS: код HTTP, ошибка TLS/сертификата, тайм-аут или ошибка соединения;
- Права sing-box и конфигов: при несовпадении называется конкретная граница.

Код 0 — все шесть прошли. Код 3 — есть отказ или неизвестный результат; это допустимый
результат уточнения, а не повод повторять команду. Ни один из кодов не разрешает правки.
При ошибке sudo нужен рабочий терминал владельца, без перенастройки sudoers/служб.
При тайм-ауте инструмента дождаться окончания уже запущенной команды, не запускать её заново.
Если факт окончания неизвестен, STOP и сообщение в чат без публикации вымышленного результата.

## 4. Прочитать завершённый отчёт

```bash
sudo -n python3 -I -B "$HOME/zcod/xgw/docs/helpers/wave3_close.py" report --clarified
```
Ожидается тот же короткий отчёт и `Сбор данных: завершён`, код 0, даже если шаг 3 вернул 3.
Если завершённой записи нет, будет код 3. Тогда STOP: не повторять clarify/prepare,
не читать raw state.json, конфиги или журналы вручную. Сообщить только фактический код/этап.
Старые «0 из 6» не означают шесть выполненных попыток: изоляция тогда не запускалась.
Новые наблюдения не устанавливают задним числом причину прежнего отказа.

```bash
cd "$HOME/zcod/xgw" && sudo -n python3 -I -B "$HOME/zcod/xgw/docs/helpers/wave3_close.py" report --clarified > "docs/TEST-REPORT-REAL-MACHINE-0.2.0-wave3-close-readonly-$(date +%F).md"
```
Ожидается код 0. Прочитать весь файл: одна страница, без секретов, внешних IP, доменов,
имён серверов/устройств/подписок, полных MAC и текстов исключений.
Отрицательные результаты сохранить буквально. Для этого не требуется общий успех baseline.
Одностраничная [форма отчёта](TEST-REPORT-REAL-MACHINE-0.2.0-wave3-close-readonly-TEMPLATE.md) рядом;
экспортированный вывод не переписывать и не заменять неизвестные значения предположениями.

## Где остановиться

На этом уточнение заканчивается, даже если все проверки прошли. Старые cut/isolation/watch
не запускать: запись уточнения намеренно не выдаёт им допуск и не меняет baseline на true.
Не подменять URL, не увеличивать тайм-аут, не перепроверять другими командами и не чинить сеть.
Разработчик разберёт конкретную строку. Если причина останется неясной, следующий шаг —
короткий вопрос владельцу с вариантами, а не новая серия диагностических волн.
