# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** проверь отдельный HTTP-процесс из
`b686169`. Он читает пять полей zapret2 через принятый Unix-сокет.
Скрипт проверяет UID, нулевые capabilities, авторизацию, ответ
при отказе IPC и совпадение результата с действующей панелью.
После прогона удаляются временные процесс и сокет.
[Готовое ТЗ](PANEL-READ-HTTP-2026-11-21.md)

подтверждены на живом снимке.
Живая ротация Selective ждёт успешного прямого допуска.
[Последний отчёт](../reports/2026-11-21T141753Z_panel-read-ipc.md)
