# ThinkCentre. Окно XGW: новый «Обзор» и навигация по образцу Proton VPN

CODE `a73c790863be2f16978ba3bc90b835bc3d84bc93`. Версия 0.2.0, freepool, GLM-5.3-Flash с root и Vision.
Меняются три файла окна: `theme.py`, `widgets.py`, `window.py` (ASSUMPTIONS п. 387). Демон,
панель, Xray, sing-box, правила сети и настройки не трогаются и не перезапускаются. Здесь
проверены снимки в контейнере Ubuntu 24.04 и узкие тесты; настоящий экран, флаги стран, тени
и нагрузка — только этот прогон. Цель: подтвердить вид словами и найти видимые дефекты.

## 1. Исполнитель и подготовка

Исполнитель сам выполняет команды и смотрит окно через Vision; нет доступа — запросить и
продолжить самому, владельца запускать команды не просить. Отчёт публикуется автоматически
при любом исходе. Не нажимать «Выключить VPN», «Включить VPN», «Выключить перехват», «Выбрать»,
замеры, обновления, переключатели и кнопки режимов zapret2. Git и окно — от пользователя
графической сессии. Снимки экрана, имена серверов и устройств, адреса — в Git не отправлять.

```bash
set -euo pipefail
cd "${XGW_REPO:-$HOME/xgw}"
test -z "$(git status --porcelain)"
sudo -v
git fetch origin freepool
CODE=a73c790863be2f16978ba3bc90b835bc3d84bc93
BASE=38c08e7e7e6c372281491f0006c142a2f8c5dffb
git merge-base --is-ancestor "$CODE" origin/freepool
umask 077
D=$(mktemp -d "$HOME/xgw-gui-proton.XXXXXXXX")
git worktree add --detach "$D/new" "$CODE"
git worktree add --detach "$D/base" "$BASE"
git -C "$D/new" diff --name-only "$BASE" "$CODE" -- src
G=/opt/xgw/lib/xgw/gui
sudo test -d "$G" && sudo test ! -L "$G"
for f in "$D"/base/src/xgw/gui/*.py; do sudo cmp -s "$f" "$G/${f##*/}" || { echo "STOP gui_base ${f##*/}"; exit 2; }; done
echo OK gui_base
systemctl is-active xgw.service; systemctl show xgw.service -p MainPID
sudo xgw diag --no-net | grep Итог
date -u +%FT%TZ
```

В diff — ровно три файла окна. `STOP gui_base` — на машине другой состав окна: не ставить,
в отчёт — имя файла. Записать PID демона и Xray (`systemctl show xgw.service -p MainPID`) и
строку diag: в конце они должны совпасть.

## 2. Замена трёх файлов

Закрыть окно XGW обычной кнопкой закрытия и дождаться выхода его процесса (значок в трее и
службы не трогать; массовые pkill/killall не применять).

```bash
sudo bash -s -- "$G" "$D" <<'SH'
set -Eeuo pipefail
G=$1 D=$2 N=$2/new/src/xgw/gui
files=(theme.py widgets.py window.py)
for f in "${files[@]}"; do python3 -c 'import sys; compile(open(sys.argv[1],"rb").read(), sys.argv[1], "exec")' "$N/$f"; done
mkdir -m 700 "$D/saved"
for f in "${files[@]}"; do cp -a -- "$G/$f" "$D/saved/$f"; done
restore() { for f in "${files[@]}"; do cp -a -- "$D/saved/$f" "$G/$f"; done; echo RESULT gui_files_restored; }
trap 'restore; exit 2' ERR
for f in "${files[@]}"; do
    install -o "$(stat -c %u "$D/saved/$f")" -g "$(stat -c %g "$D/saved/$f")" -m "$(stat -c %a "$D/saved/$f")" "$N/$f" "$G/.xgw-gui-new"
    mv -f -- "$G/.xgw-gui-new" "$G/$f"
done
for f in "${files[@]}"; do cmp -s "$G/$f" "$N/$f"; done
trap - ERR
echo OK gui_files=3
SH
```

Ожидается `OK gui_files=3`. Запустить `xgw gui` от пользователя графической сессии. Окно не
открылось или упало — записать последнюю строку ошибки без путей с именем пользователя,
вернуть файлы (§5) и закончить отчётом FAIL.

## 4. Просмотр: окно 1024×720 и нагрузка

11. Уменьшить окно до наименьшего размера: навигация стала узкой — одни значки; наведение
    на значок показывает подсказку с названием. Ctrl+1…8 переключают разделы.
12. «Обзор» в наименьшем окне: карточка, отметка страны и три плитки помещаются, ничего не
    наложено и не обрезано; у списка серверов работает прокрутка.
13. Нагрузка покоя: окно открыто на «Обзоре», мышь не трогать 40 с:

```bash
P=$(pgrep -f 'xgw gui' | head -1 || true); test -n "$P"
a=$(awk '{print $14+$15}' "/proc/$P/stat"); sleep 30; b=$(awk '{print $14+$15}' "/proc/$P/stat")
echo "gui_cpu_ticks_30s=$((b-a)) hz=$(getconf CLK_TCK)"
```

    Ожидается меньше 5 % одного ядра (при hz=100 — меньше 150 тиков за 30 с). Больше —
    записать число: это дефект кэша карты, не повод для отката.
14. Закрыть окно кнопкой закрытия: процесс окна завершился за 15 с (`pgrep` пусто). Запустить
    снова — открылось одно окно. Это заодно закрывает проверку из ТЗ gui-s3b.
15. Свободным текстом, до десяти строк: что в новом виде выглядит плохо или непонятно
    (наложения, слишком мелкий или бледный текст, пустые места, неудачные цвета, отличие от
    описания выше). Без имён серверов и устройств. Этот пункт обязателен и при всех PASS.
