# Проверка XGW 0.2.0: бесплатные серверы — своя вкладка в панели

**Для исполнителя.** Выполняй шаги строго по порядку. В каждом шаге — команда (копируй
целиком в терминал), «Ожидается» и «Если не так». Ничего не придумывай сверх написанного. Не
уверен — остановись и спроси заказчика. Выводы сохраняй в файлы, как написано
(`$HOME/xgw-fptab/…`). Файл помощника создавай только командой шага 1.2, выполненной в
терминале. Блок команды копируй целиком, ничего в нём не меняя.

Машина: ThinkCentre, Ubuntu 24.04.5 LTS (systemd 255), KDE Plasma (X11), браузер Chromium.
Клон — `~/zcod/xgw`. Код — ветка `freepool`, версия 0.2.0. Телефон — S25 Ultra в домашней сети.
Команды — в терминале сеанса заказчика (`sudo` от его имени).

Если на этой машине ещё не пройдено ТЗ `docs/TEST-PLAN-REAL-MACHINE-0.2.0-freepool-m2v2.md` —
сначала оно, потом это (то ТЗ бережёт суточный предел подключений SSTP; здесь подключений за
час наблюдения — не больше двух).

Что нового (ASSUMPTIONS п. 265). Пожелание заказчика: бесплатные серверы были маленькой карточкой
со сводкой в левой колонке, без сведений о самих серверах, — нужен такой же режим, как у
подписок. Теперь:
1. **Две вкладки** над карточкой «Серверы»: «Подписки» (всё как раньше) и «Бесплатные серверы».
   Выбранную вкладку браузер помнит после обновления страницы.
2. **Вкладка «Бесплатные серверы»** — карточка во всю правую колонку: в шапке — число найденных
   и кнопки «Опросить источники» и «Выключить» (без наблюдения — «Включить наблюдение»), под
   ней — прежняя сводка, затем **блоки источников**, как блоки подписок: название, метка итога
   опроса («ок», «частично», «недоступен»…), «допущено N · проверено M из K», «Список от …».
   В блоке — **строка на каждый проверенный сервер**, как у серверов подписок: имя, метки
   («сейчас через», «в работе» или «допущен»; протокол; страна выхода), справа — задержка
   (время пробы целиком, у сервера в работе у устройств — по пробам ядра Xray) или итог
   проверки словом; серым — почему сервер не допущен к трафику устройств, когда проверен, когда
   перепроверка. Непроверенные — в свёрнутом списке «Ещё не проверялись — N».
3. Строки приходят **отдельным запросом** панели `/api/pool` (их сотни) — только пока вкладка
   открыта и когда демон пересчитал сводку пула (раз в минуту); в `/api/state`, который страница
   спрашивает каждые 3 с, их нет. Причину «не допущен» считает тот же код, что выбирает серверы
   для трафика устройств.
4. События о бесплатных серверах в карточке «События» — с меткой «бесплатные серверы» (было
   «freepool»).

Карточки «Бесплатные серверы» в левой колонке больше нет. Трафик, проверки серверов и выбор
серверов для устройств не менялись.

Здесь, у разработчика, — только юнит-тесты затронутых модулей и ruff; панель в браузере не
открывалась. Всё остальное — на этой машине.

## 0. Запрещено

- `xgw net down`, `xgw disable`, `xgw uninstall`, `reboot`, сон машины, `install.sh --force` —
  **никогда**. Запуск, остановка и перезапуск служб `xgw*` (и `xgw-fp@*`), `tailscaled`,
  NetworkManager, `ssh`; ручные `nft` (кроме `nft list`), `ip`, `ip netns`, `iptables`, `tc`,
  `sysctl -w`, `systemd-run`, `modprobe`, `apt` (пакеты ставит только установщик XGW); команды
  `tailscale`, `xray`, `sing-box`, `sstpc`, `pppd`. `sudo xgw pool mode …` — только в шаге 3.1
  (`observe`) и по правилу «Наблюдение не оставлять включённым» (`off`).
- Самому открывать сайты источников (vpngate, vpnbook), серверы `*.opengw.net` и файлы списков
  на GitHub. Их открывает только сам шлюз. Самому открывать `/api/pool` в браузере или
  `curl` — тоже нет: это делает только помощник.
- Править `/etc/xgw` (в том числе `config.toml` и `panel.json`), `/opt/xgw`, `/var/lib/xgw`,
  `/run/xgw`, `/etc/systemd`, код XGW. Печатать `config.toml`, `panel.json`, `panel-token`, файлы
  в `/var/lib/xgw/freepool` (`cat`, `less`, `grep` по ним) — в них ключи подписок, токен панели,
  пароли и ссылки серверов. Серверы, вкладки, переключатели и кнопки в панели меняет и нажимает
  только заказчик. Коммитить что-либо, кроме отчёта (§8).
- Писать в отчёт: **имена бесплатных серверов** (заказчик видит их на вкладке — в отчёт они не
  идут), адреса tailnet, имена `*.ts.net`, имена устройств и пользователей (имя пользователя →
  `<user>`), внешние IP, токены, адреса и домены подписок, IP, домены и ссылки серверов VPN,
  логины и пароли, строки журнала. Можно: адреса устройств в домашней сети (`192.168.…`), коды
  стран, названия источников, метки и надписи панели без имён серверов, счётчики, итоги
  проверок, причины недопуска, размеры, времена.

Шаг 1.2. Папка, помощник проверки и состояние до установки:

```bash
mkdir -p "$HOME/xgw-fptab" && chmod 700 "$HOME/xgw-fptab" && cd "$HOME/xgw-fptab" && cat > fptabcheck.py <<'EOF'
"""XGW 0.2.0, бесплатный пул: вкладка «Бесплатные серверы» в панели — помощник проверки.
Только читает: строки вкладки кодом установленного XGW (freepool.pool.server_rows), ответ
панели /api/pool (вход — токеном панели, как у ярлыка «XGW»; кнопок не нажимает), сводку пула
в /run/xgw/status.json и журнал со стандартного ввода — счётчики, коды стран, итоги проверок и
да/нет, без имён и адресов серверов, ссылок и ключей. Режимы: rows, api, live, log."""
import http.client
import json
import os
import re
import sys
import time

mode = sys.argv[1] if len(sys.argv) > 1 else ""
LIB = os.environ.get("FPTAB_LIB", "/opt/xgw/lib")
KEYS = {"id", "source", "name", "protocol", "backend", "country", "egress", "verdict",
        "checked_at", "next_at", "delay_ms", "tunnel_up", "connect_s", "error", "why"}
NAMES = {"vpngate": "VPN Gate", "vpnbook": "VPNBook", "igareck": "GitHub igareck",
         "mahdibland": "GitHub mahdibland"}
SECRET = re.compile(r"://|\b[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}\b"
                    r"|password|passwd", re.I)


def xgw():
    sys.path.insert(0, LIB)
    from xgw import config
    from xgw.paths import Paths

    paths = Paths.from_env()
    return config.load(paths.config_file)[0], paths


def counted(items):
    found = {}
    for item in items:
        found[item] = found.get(item, 0) + 1
    return ", ".join(f"{name} {count}" for name, count in sorted(found.items())) or "—"


def rows_now(cfg, paths):
    from xgw.freepool import pool

    return pool.server_rows(cfg, paths, time.time())


def status(paths):
    try:
        data = json.loads((paths.run / "status.json").read_text(encoding="utf-8"))
    except (OSError, ValueError) as exc:
        print(f"status.json не читается: {type(exc).__name__}")
        return {}
    return data if isinstance(data, dict) else {}


if mode == "rows":
    cfg, paths = xgw()
    from xgw.freepool import traffic

    rows = rows_now(cfg, paths)
    print(f"режим пула: {cfg.free_pool.mode}; регион {cfg.free_pool.region}; строк: {len(rows)}")
    for source in cfg.free_pool.providers:
        mine = [row for row in rows if row["source"] == source]
        checked = [row for row in mine if row["checked_at"]]
        works = [row for row in checked if row["verdict"] in ("OK", "SLOW")]
        print(f"{NAMES.get(source, source)}: всего {len(mine)}; проверено {len(checked)}; "
              f"допущено {len([row for row in mine if not row['why']])}; не проверялись "
              f"{len(mine) - len(checked)}")
        print(f"  итоги: {counted(row['verdict'] for row in checked)}")
        print(f"  рабочих (OK/SLOW): {len(works)}; страна выхода есть у "
              f"{len([row for row in works if row['egress']])}; задержка есть у "
              f"{len([row for row in works if row['delay_ms']])}; протоколы: "
              f"{counted(row['protocol'] for row in mine)}")
    admitted = {item.node.fingerprint for item in traffic.admitted(cfg, paths, time.time())}
    shown = {row["id"] for row in rows if not row["why"]}
    print(f"допущено всего: {len(shown)}; совпадает с допуском трафика: "
          f"{'да' if shown == admitted else 'НЕТ'} ({len(admitted)})")
    print(f"причины недопуска: {counted(row['why'] for row in rows if row['why'])}")
    extra = sorted({key for row in rows for key in row} - KEYS)
    leaked = [row for row in rows
              if any(SECRET.search(str(row.get(key) or "")) for key in ("name", "error", "why"))]
    print(f"лишних полей в строках: {', '.join(extra) or 'нет'}; "
          f"ссылок, ключей и паролей в строках: {len(leaked)}")
elif mode == "api":
    cfg, paths = xgw()
    from xgw.watch import panel

    token = panel.read_token(paths)
    port = cfg.panel.port

    def get(path, cookie=""):
        conn = http.client.HTTPConnection("127.0.0.1", port, timeout=30)
        headers = {"Host": f"127.0.0.1:{port}"}
        if cookie:
            headers["Cookie"] = cookie
        try:
            conn.request("GET", path, headers=headers)
            response = conn.getresponse()
            return response.status, response.getheader("Set-Cookie") or "", response.read()
        except OSError as exc:
            return type(exc).__name__, "", b""
        finally:
            conn.close()

    code, _cookie, _body = get("/api/pool")
    print(f"/api/pool без входа: {code}")
    code, cookie, _body = get(f"/?token={token}" if token else "/")
    cookie = cookie.split(";")[0]
    print(f"вход токеном панели: {code}; cookie: {'есть' if cookie else 'нет'}")
    code, _cookie, body = get("/api/pool", cookie)
    try:
        data = json.loads(body.decode("utf-8")) if code == 200 else {}
    except ValueError:
        data = {}
    served = data.get("servers") or []
    rows = rows_now(cfg, paths)
    print(f"/api/pool после входа: {code}; строк {len(served)} (по коду помощника {len(rows)}); "
          f"размер ответа {len(body) // 1024} КБ; режим {data.get('mode')}")
    same = {row.get("id") for row in served} == {row["id"] for row in rows}
    print(f"строки ответа совпадают с кодом: {'да' if same else 'НЕТ'}")
    summary = status(paths).get("free_pool") or {}
    at = summary.get("computed_at")
    print(f"сводка пула в status.json: {'есть' if summary else 'нет'}; посчитана: "
          + (f"{int(time.time() - float(at))} с назад" if at else "нет времени"))
    print(f"строк серверов в status.json: {'ЕСТЬ' if 'servers' in summary else 'нет'}")
elif mode == "live":
    cfg, paths = xgw()
    flow = (status(paths).get("free_pool") or {}).get("traffic") or {}
    members = flow.get("servers") or []
    rows = rows_now(cfg, paths)

    def row_of(item):
        key = str(item.get("id") or "-")
        return next((row for row in rows if row["id"].startswith(key)), None)

    current = [item for item in members if flow.get("tag") and item.get("tag") == flow["tag"]]
    print(f"устройств через пул: {len(flow.get('devices') or [])}; закрыто: "
          f"{'да' if flow.get('closed') else 'нет'}; в составе pool: {len(members)}; живых: "
          f"{len([item for item in members if item.get('alive')])}")
    if current:
        row = row_of(current[0])
        print(f"сейчас через: есть; страна {flow.get('country') or '?'}; задержка "
              f"{flow.get('delay_ms', 0)} мс; его строка во вкладке: "
              + (f"есть, страна {row['country']}, допущен: {'да' if not row['why'] else 'нет'}"
                 if row else "НЕТ"))
    else:
        print("сейчас через: нет")
    print(f"серверы состава найдены среди строк вкладки: "
          f"{len([item for item in members if row_of(item)])} из {len(members)}")
elif mode == "log":
    text = sys.stdin.read()
    print(f"строк журнала: {text.count(chr(10))}; Traceback: {text.count('Traceback')}; "
          f"«серверы бесплатного пула не прочитаны»: "
          f"{text.count('серверы бесплатного пула не прочитаны')}; «шаг не выполнен»: "
          f"{text.count('бесплатный пул: шаг не выполнен')}; проверок серверов пула: "
          f"{text.count('бесплатный пул: проверка ')}")
else:
    print("режим: rows | api | live | log")
EOF
python3 -c "import hashlib;d=open('fptabcheck.py','rb').read().rstrip(b'\n')+b'\n';print(hashlib.sha256(d).hexdigest()[:16])"; sudo xgw status 2>&1 | grep -E '^Состояние|Перехват:|^Xray|^sing-box' | tee before.txt; sudo xgw pool 2>&1 | head -1 | tee -a before.txt; sudo journalctl -u xgw --since "60 min ago" --no-pager | sudo python3 -I fptabcheck.py log | tee log-before.txt
```

Ожидается:
- `1982d7d8758f64b1`;
- `Состояние: …`, `Перехват: включён …`, строки `Xray …` и `sing-box …` — записать как есть;
- первая строка `xgw pool` — «Бесплатный пул: выключен; …» или «Бесплатный пул: наблюдение
  (трафик через подписку); …» — **записать, какая**: от неё зависят шаги 3.1 и 6.1;
- счётчики журнала — записать.

Если не так: сумма другая — выполнить шаг заново, скопировав команду целиком; снова другая —
