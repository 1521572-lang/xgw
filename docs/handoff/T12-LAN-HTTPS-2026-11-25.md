# ThinkCentre · новый HTTPS-сеанс с LAN-клиента

**Ubuntu 24.04 LTS.** Flash сама запускает команды и публикует
обезличенный отчёт при любом исходе. При недоступности терминала,
sudo, pytest, клиента LAN или GitHub запроси доступ. Проведи остальные
фазы независимо. Код и проверки подготовлены Codex.

[Предыдущий отчёт](../reports/2026-11-24T215502Z_t12-vpn-route.md)
подтвердил оба HTTPS-маршрута через Xray по штатному журналу. Оба запроса
использовали локальные входы ThinkCentre. Здесь проверяется обычный
HTTPS через прозрачный перехват с отдельного устройства LAN, которое
уже пользуется этим шлюзом.

## Доступ и запуск

Из рабочей копии укажи в `XGW_T12_LAN_SSH` согласованный SSH-адрес или
алиас уже доступного Linux-клиента с `python3`, `curl` и `ip`. Нужна
заранее доверенная запись SSH и действующая аутентификация. Допускается
подключение через предоставленный терминал этого клиента, если он
поддерживает выполнение того же скрипта и безопасную передачу JSON.
Запускай команды сама. Перехват включён в рабочей конфигурации. Если
у LAN-интерфейса несколько IPv4, укажи адрес шлюза клиента в
`XGW_T12_LAN_GATEWAY`; скрипт сверит его с интерфейсом ThinkCentre.
Не меняй маршрут, SSH-настройки, прокси клиента или правила шлюза.

При необходимости активируй `sudo -v` и укажи существующий pytest через
`XGW_TEST_PYTHON`. В одном проходе выполняется один HTTPS GET по IPv4 к
публичному trace-адресу Cloudflare без явного прокси. Рабочий VPN и
маршруты остаются как есть. Проверка выделяет один сокет из уже доступного
журнала Xray. Тела ответа, пакеты и браузерные данные не сохраняются.

~~~bash
bash <<'BASH'
set -euo pipefail
umask 077
. /etc/os-release
[[ $ID == ubuntu && $VERSION_ID == 24.04 && $EUID != 0 ]]
BR=integration/zapret2-batch1
CODE=f092a47c91af1a9b5729e05f69237cdfab3756d5
REPO=$(git rev-parse --show-toplevel)
PY=/usr/bin/python3
TEST_PY=${XGW_TEST_PYTHON:-$PY}
git -C "$REPO" fetch origin "$BR"
git -C "$REPO" merge-base --is-ancestor "$CODE" FETCH_HEAD
D=$(mktemp -d "$HOME/xgw-t12-lan.XXXXXXXX")
mkdir "$D/tree"
git -C "$REPO" archive "$CODE" src tests docs/helpers vpn_ui pyproject.toml | tar -x -C "$D/tree"
printf 'OS %s\nPINNED %s\nPRIVATE_ARTIFACTS %s\n' "$PRETTY_NAME" "$CODE" "$D"
uname -r
export PYTHONPATH="$D/tree:$D/tree/src:$D/tree/tests"
export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTEST_ADDOPTS=
cd "$D/tree"

snapshot() {
  sudo -n timeout -k 3 60 "$PY" -I -B - snapshot <docs/helpers/audit_host_observe.py &&
    sudo -n sha256sum /etc/xgw/config.toml /etc/xgw/panel.json
}

xray_snapshot() {
  sudo -n timeout -k 2 8 /usr/bin/env -i PATH=/usr/sbin:/usr/bin:/sbin:/bin \
    "PYTHONPATH=$D/tree/src" "$PY" -B -P -m xgw.desync.route_evidence snapshot
}

run_phase() {
  local label=$1 code=0
  shift
  "$@" >"$D/$label.log" 2>&1 || code=$?
  tail -n 16 "$D/$label.log"
  printf '%s_EXIT %s\n' "$label" "$code"
  return "$code"
}

client_window() {
  local host=${XGW_T12_LAN_SSH:-} gateway start
  if [[ -z $host ]]; then
    printf 'LAN_NOT_RUN_NO_AUTHORIZED_CLIENT\n'
    return 3
  fi
  [[ $host != -* && $host != *[[:space:]]* ]] || return 3
  sudo -n timeout -k 2 15 xgw status --json >"$D/status.private.json" \
    2>"$D/status.private.err" || { printf 'LAN_STATUS_UNAVAILABLE\n'; return 3; }
  gateway=$("$PY" -B -P - "$D/status.private.json" "${XGW_T12_LAN_GATEWAY:-}" <<'PYTHON'
import json
import subprocess
import sys
from pathlib import Path

from xgw.desync.lan_control import _lan_address


def gateway():
    capture = json.loads(Path(sys.argv[1]).read_bytes())["capture"]
    interface = capture.get("lan_if")
    if (capture.get("mode") != "on" or capture.get("lan") is not True
            or capture.get("loaded") is not True or capture.get("blocked") or not interface):
        return None
    data = subprocess.check_output(["ip", "-j", "-4", "address", "show", "dev", interface],
                                   stderr=subprocess.DEVNULL, timeout=3)
    addresses = set()
    for link in json.loads(data):
        for row in link.get("addr_info", []):
            try:
                addresses.add(str(_lan_address(row.get("local"))))
            except ValueError:
                continue
    selected = sys.argv[2]
    if selected:
        return selected if selected in addresses else None
    return next(iter(addresses)) if len(addresses) == 1 else None


try:
    address = gateway()
except (OSError, ValueError, KeyError, subprocess.SubprocessError):
    address = None
if not address:
    raise SystemExit(3)
print(address)
PYTHON
  ) || { printf 'LAN_GATEWAY_UNCONFIRMED\n'; return 3; }

  start=$(date +%s) || return
  xray_snapshot >"$D/xray.before.json" || { printf 'LAN_XRAY_BEFORE_UNAVAILABLE\n'; return 3; }
  timeout -k 2 20 ssh -T -o BatchMode=yes -o StrictHostKeyChecking=yes -o ConnectTimeout=4 \
    -- "$host" 'python3 -B -' <docs/helpers/lan_https_sample.py \
    >"$D/client.json" 2>"$D/client.private.err" \
    || { printf 'LAN_CLIENT_SAMPLE_UNAVAILABLE\n'; return 3; }
  xray_snapshot >"$D/xray.after.json" || { printf 'LAN_XRAY_AFTER_UNAVAILABLE\n'; return 3; }
  sudo -n timeout -k 2 8 journalctl -q --no-pager -b -u xgw-xray.service \
    --since "@$start" -n 512 -o json --output-fields=MESSAGE,_PID,_BOOT_ID,_SYSTEMD_UNIT \
    >"$D/xray.private.jsonl" 2>"$D/xray.private.err" \
    || { printf 'LAN_JOURNAL_UNAVAILABLE\n'; return 3; }
  "$PY" -B -P -m xgw.desync.lan_control --gateway "$gateway" "$D/client.json" \
    "$D/xray.before.json" "$D/xray.after.json" "$D/xray.private.jsonl"
}

before=0
snapshot >"$D/state.before" 2>"$D/snapshot.before.err" || before=$?
run_phase CONTRACTS timeout -k 3 120 "$TEST_PY" -B -P -m pytest \
  -o addopts= -p no:cacheprovider --color=no -v -rs --tb=short --portable \
  --basetemp "$D/pytest" tests/test_desync_lan_control.py tests/test_desync_vpn_control.py \
  tests/test_desync_route_evidence.py tests/test_selective_probe_watch.py || true
run_phase LAN client_window || true
after=0
snapshot >"$D/state.after" 2>"$D/snapshot.after.err" || after=$?
if [[ $before == 0 && $after == 0 ]]; then
  if cmp -s "$D/state.before" "$D/state.after"; then
    printf 'T12_GATEWAY_UNCHANGED\n'
  else
    printf 'T12_GATEWAY_SNAPSHOT_DIFF\n'
  fi
else
  printf 'T12_GATEWAY_SNAPSHOT_NOT_AVAILABLE %s %s\n' "$before" "$after"
fi
BASH
~~~

## Итоги фаз

- **CONTRACTS** — число `passed`, `failed`, `skipped` и длительность.
  Отдельно укажи, что проверены исходный IP назначения и имя после
  sniffing, посторонние записи, отсутствие совпадения и чужой шлюз.
- **LAN** — `PASS` для VPN, если `https_complete=true` и
  `accepted_route.state=observed` с группой `xray` или `sing-box`.
  Опубликуй HTTP-код, количество байтов, код curl и категорию. При
  `direct`, `blocked` или `other` укажи выбранную категорию и исход HTTPS.
  При `no_access_record`, `ambiguous`, `window_unconfirmed` или
  `journal_limit` сохрани точную метку и итог HTTPS. Один HTTP 200
  подтверждает доступность сайта. Путь подтверждает запись `tproxy-in`.
- **Доступ** — при отсутствии отдельного клиента запроси доступ и отметь
  `NOT_RUN`, если он недоступен. Проба со шлюза через localhost уже
  принята и за LAN не засчитывается. Повтор запросов в этом ТЗ не нужен.
- **Шлюз** — сравнение снимков и хэшей, изменившиеся категории при наличии.
  Путь sing-box учитывается только при наблюдении `group=sing-box`.
  Приёмка YouTube, Selective и суточные измерения остаются отдельными.

## Автоматическая публикация

Публикуй только версии, SHA, итоги фаз, агрегаты и категории. Оставь на
машине настройки, журналы, адреса, порты, имена клиента и пути. Подставь
абсолютный путь к обезличенному Markdown в `REPORT_SRC`. Выполни блок
из рабочей копии при любом исходе и верни ссылку на коммит.

~~~bash
bash -s -- "$REPORT_SRC" <<'BASH'
set -euo pipefail
umask 077
REPORT_SRC=$1
BR=integration/zapret2-batch1
[[ $REPORT_SRC == /* && -s $REPORT_SRC ]]
REPO=$(git rev-parse --show-toplevel)
PUB=$(mktemp -d "$HOME/xgw-t12-lan-report.XXXXXXXX")
git -C "$REPO" fetch origin "$BR"
git -C "$REPO" worktree add --detach "$PUB/repo" FETCH_HEAD
trap 'git -C "$REPO" worktree remove "$PUB/repo" && rmdir -- "$PUB"' EXIT
cd "$PUB/repo"
REPORT="docs/reports/$(date -u +%Y-%m-%dT%H%M%SZ)_t12-lan-https.md"
test ! -e "$REPORT"
install -m 0644 -- "$REPORT_SRC" "$REPORT"
git add -- "$REPORT"
git diff --cached --check
git commit -m 'Report ThinkCentre LAN HTTPS through transparent capture'
if ! git push origin "HEAD:refs/heads/$BR"; then
  git fetch origin "$BR"
  git rebase FETCH_HEAD
  git push origin "HEAD:refs/heads/$BR"
fi
git fetch origin "$BR"
git merge-base --is-ancestor HEAD FETCH_HEAD
printf 'PUBLISHED %s %s\n' "$(git rev-parse HEAD)" "$REPORT"
BASH
~~~
