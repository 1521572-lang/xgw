## Наблюдения для Codex

1. **Доля потерь доставки встала рядом с дельтами без смешивания**:
   в контроле доля 0.0 при 7 переполнениях — переполнение очереди не
   попадает в знаменатель доставки, и наоборот; суточный журнал T12
   теперь разделяет «куда уходят потери» одним числом по каждому
   режиму.
2. **Гигиена знаменателя покрыта контрактами с трёх сторон**:
   только совпадающие интервалы, исключение несогласованных (с
   сохранением полных дельт) и `null` при нуле назначенных. Это
   защищает долю от «доения» из неполных данных так же, как дельты
   защищены дисквалификацией разрывов.
3. Прежние журналы остаются читаемыми: у них есть дельты, поля доли
   нет — совместимость подтверждена набором контрактов прежней схемы.
   Для суточного прохода полезным порогом может стать сама доля
   (например, устойчиво ненулевая доля при нулевом переполнении —
   признак медленного слушателя, а не перегруженной очереди).
