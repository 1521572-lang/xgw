## 1. Исполнитель и подготовка

Исполнитель сам выполняет команды и смотрит окно через Vision; нет доступа — запросить и
продолжить самому, владельца запускать команды не просить. Отчёт публикуется автоматически.
Не нажимать «Выключить VPN», «Включить VPN», «Выключить перехват», «Выбрать», замеры,
обновления, переключатели и кнопки режимов zapret2. Git и окно — от пользователя графической
сессии. Снимки экрана, имена серверов и устройств, адреса — в Git не отправлять.

```bash
set -euo pipefail
cd "${XGW_REPO:-$HOME/xgw}"
test -z "$(git status --porcelain)"
sudo -v
git fetch origin freepool
CODE=de81cdc07c2132946fa851203c000b7bfc0825ec
BASE=a73c790863be2f16978ba3bc90b835bc3d84bc93
git merge-base --is-ancestor "$CODE" origin/freepool
umask 077
D=$(mktemp -d "$HOME/xgw-gui-look3.XXXXXXXX")
git worktree add --detach "$D/new" "$CODE"
git worktree add --detach "$D/base" "$BASE"
git -C "$D/new" diff --name-only "$BASE" "$CODE" -- src
G=/opt/xgw/lib/xgw/gui
sudo test -d "$G" && sudo test ! -L "$G"
for f in "$D"/base/src/xgw/gui/*.py; do sudo cmp -s "$f" "$G/${f##*/}" || { echo "STOP gui_base ${f##*/}"; exit 2; }; done
echo OK gui_base
systemctl is-active xgw.service; systemctl show xgw.service -p MainPID
sudo xgw diag --no-net | grep Итог
date -u +%FT%TZ
```

В diff — ровно пять файлов окна. `STOP gui_base` — на машине другой состав окна: не ставить,
в отчёт — имя файла. Записать PID демона и строку diag: в конце они должны совпасть.

## 2. Замена пяти файлов

Закрыть окно XGW кнопкой закрытия и дождаться выхода его процесса (службы и значок в трее не
трогать; массовые pkill/killall не применять).

```bash
sudo bash -s -- "$G" "$D" <<'SH'
set -Eeuo pipefail
G=$1 D=$2 N=$2/new/src/xgw/gui
files=(theme.py widgets.py window.py devices.py listing.py)
for f in "${files[@]}"; do python3 -c 'import sys; compile(open(sys.argv[1],"rb").read(), sys.argv[1], "exec")' "$N/$f"; done
mkdir -m 700 "$D/saved"
for f in "${files[@]}"; do cp -a -- "$G/$f" "$D/saved/$f"; done
restore() { for f in "${files[@]}"; do cp -a -- "$D/saved/$f" "$G/$f"; done; echo RESULT gui_files_restored; }
trap 'restore; exit 2' ERR
for f in "${files[@]}"; do
    install -o "$(stat -c %u "$D/saved/$f")" -g "$(stat -c %g "$D/saved/$f")" -m "$(stat -c %a "$D/saved/$f")" "$N/$f" "$G/.xgw-gui-new"
    mv -f -- "$G/.xgw-gui-new" "$G/$f"
done
for f in "${files[@]}"; do cmp -s "$G/$f" "$N/$f"; done
trap - ERR
echo OK gui_files=5
SH
```

Ожидается `OK gui_files=5`. Запустить `xgw gui` от пользователя графической сессии. Окно не
открылось — последняя строка ошибки без путей с именем пользователя, возврат (§4), отчёт FAIL.

## 3. Просмотр

По каждому пункту — PASS/FAIL и одно предложение о том, что видно.

1. Разделы: десять раз подряд щёлкнуть «Трафик», затем «Диагностика» (после каждого щелчка
   подождать секунду и сверить заголовок страницы с подсвеченным разделом). Все двадцать
   раз страница совпала с разделом — PASS; записать число несовпадений.
2. Фокус: на «Обзоре» щёлкнуть строку «zapret2 · …», вернуться Ctrl+1 — сиреневой рамки на
   строке нет. Щёлкнуть строку сервера, закрыть сведения Escape — рамки на строке сервера
   нет. Клавишей Tab рамка по-прежнему появляется на кнопках и строках (доступность).
3. Окно 1024×720, «Обзор»: свечение сверху карты не уходит под белую карточку, границы
   («шва») у верхнего края карточки не видно.
4. Строка «zapret2 · …» той же ширины, что карточка над ней, в широком и в узком окне.
5. Заголовки плиток «ПЕРЕХВАТ», «ПРИ СБОЕ XRAY», «МИМО VPN» читаются без усилия.
6. «Подписки»: у полосы расхода видна серая дорожка на белой карточке.
7. «Трафик»: таблица — белая карточка со скруглением и строкой заголовков; строки с именем
   «?» нет (вместо неё, если такой расход есть, — «Серверы, которых уже нет в списке»).
8. «Устройства»: между кнопками карточки и её правым краем есть поле; у правого края
   списка карточки не упираются в полосу прокрутки.
9. Навести на строку сервера в «Обзоре»: подсказка «Щелчок или Enter — сведения о сервере».
10. **Обрезка имён (уточнение замечания).** В «Обзоре», окно шире 1200: найти строку сервера,
    где имя кончается «…». Записать: а) какая строка обрезана — верхняя (имя) или нижняя
    (ядро и подписка); б) сколько примерно точек пустого места между «…» и правым краем
    строки (до точки состояния); в) есть ли в этой строке справа скорость и на какой она
    линии; г) есть ли в имени значки-эмодзи или иероглифы; д) показывает ли подсказка при
    наведении имя целиком. Само имя не записывать. Нет таких строк — так и написать.
11. Свободным текстом, до десяти строк: что ещё выглядит плохо или изменилось к худшему.
