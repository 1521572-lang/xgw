## Изменения

Единая read-only карточка `/api/state.zapret2`; отдельные состояния error/absent/stale,
проверка ревизии снимка, отсутствие ложного возврата на VPN. GUI-накладки на принятый
freepool frontend показывают ошибки и настроенную/подтверждённую стратегию раздельно.

Версионированная политика v1, чистая идемпотентная миграция, явный порядок TOML/panel.json,
сохранение приватных probes вне API. Неподдержанные возможности сохраняются в документе,
но отклоняются при проекции на несовместимый runtime. Повреждённый panel.json и попытка
валидатора молча сменить режим теперь дают ConfigError вместо неявного другого маршрута.

Явный LF для заданных типов файлов. Изменений vendor zapret2 нет. Созданы NEXT_STEP,
контракт, шаблон отчёта и узкий Ubuntu-helper установки/восстановления файлов.

```text
python -m pytest --portable tests/test_desync_schema.py tests/test_zapret2_panel.py

ruff check по всем изменённым Python-файлам: All checks passed!
```

Проверены миграция и roundtrip, конфликт/неподдержанная версия, сохранение настроек,
отказ от неявного включения engine, реальная сборка ответа Panel.state с моками зависимостей,
статусы/свежесть/приватность, логика overview, откат частичной записи при установке.
Subprocess и сеть в portable-тестах запрещены. Linux-импорты — fail-fast заглушки.
Файловая блокировка, права и systemd не симулируются как успешная проверка Linux:
для тестов сохранения/установки замоканы, проверяется только логика файловой транзакции.
