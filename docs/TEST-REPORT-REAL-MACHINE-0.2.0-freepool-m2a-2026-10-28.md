## Дефекты

1. **Бэкенд OpenVPN: NETWORK_UNREACHABLE — 2 случая** (коды причин из ТЗ). Поколения к серверам
   VPN Gate с нестандартными портами: `TCP: connect to [AF_INET]<ip>:1535 failed: No route to
   host` (18:36) и `<ip>:1603 … No route to host` (19:37). При этом адресная проверка этих же
   серверов проходила (адрес открыт), т.е. снаружи адрес достижим, а внутри пространства имён
   «нет маршрута к хосту» — предположительно маршрут к одному адресу (peer) не установился или
   установился не для этого адреса/порта. По ТЗ — код дефекта бэкенда с продолжением проверки;
   на остальные подключения и наблюдение не влияет (остальные отказы — CONNECT_TIMEOUT/UNKNOWN,
   это серверы/сеть). Для разработчика: воспроизводится на серверах VPN Gate с портами 1535 и
   1603.
