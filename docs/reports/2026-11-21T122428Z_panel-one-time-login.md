## Наблюдения для Codex

1. **Старая закладка очищается адресом в обеих сессиях** — UX-цель ТЗ
   достигнута: пользователь с протухшей закладкой видит инструкцию, а не
   ошибку; действующая сессия продолжает открывать панель.
2. Два предсуществующих отказа cli-install живут в среде без root
   (`bypass_mark` без SO_MARK уводит установку в не-ноль; busy-port).
   Стоит либо пометить их root-only (skip без root), либо изолировать
   путь `_singbox` в тесте — иначе каждый прогон даёт шум.
3. Лабораторный стенд (panel_demo + случайный порт + ensure_token)
   позволил пройти весь сценарий без касания установленной панели —
   пригоден как шаблон для будущих UX-ТЗ панели.
