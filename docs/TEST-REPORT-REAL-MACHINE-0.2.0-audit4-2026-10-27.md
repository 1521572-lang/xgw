   пробой).** 4 трейсбека в двух эпизодах (21:41:12, 21:41:23) — ровно во время пробы шага
   4.2. Механизм: «медленный» запрос (полная строка запроса, заголовки не дописаны) после
   20-секундного таймута чтения уходит в маршрутизацию; заголовка Host нет → ожидаемый
   `_Reply` 421 «не тот адрес»; при отправке ответа клиент (проба) уже отключился, и
   исключение в `appapi._send` (строка 369) не перехвачено — в журнал пишет ERROR «API
   приложения: запрос не обработан» с полным трейсбеком. Обычные клиенты так не отключаются;
   пределы соединений и таймаут при этом работают (обрыв в 20 с подтверждён). Рекомендация:
   в `_send` гасить `BrokenPipeError`/`ConnectionResetError` молча или одной строкой без
