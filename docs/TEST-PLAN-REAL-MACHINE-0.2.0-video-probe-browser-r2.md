# ThinkCentre. Повтор видеопробы Firefox при ротации пула

CODE `a79e54e09fd827d6c97105555f09ff373ac797a4`, база `3feda6c`. Исполнитель GLM-5.3-Flash.
Первый прогон завершился STOP после штатной смены участника. Новый помощник сохраняет
результат каждого этапа и отдельно проверяет конфигурацию выбранного VPN-выхода.
Цель — установить, можно ли повторить GET видеоссылки из Firefox на этом выходе.
Запуск из исходников. Шлюз, маршруты, подписки, VPN, настройки и службы сохраняются.
Использовать установленный Firefox, временный профиль и публичную страницу владельца.
В отчёт только числа и признаки. URL, токены, теги, имена, пути и сырые журналы оставить приватно.

## 2. Один живой прогон

Исполнитель сам запускает согласованный прогон через живого безлимитного участника.
Браузеру отведено до 120 секунд и 16 МиБ переданных прокси данных. Для отдельного GET
запрашивается до 64 КиБ с таймаутом 8 секунд. Повтор по той же квитанции запрещён.
Берётся youtube_sign_url или подходящий watch-адрес из zapret2.probe_urls. Если адреса нет,
владелец задаёт одну строку в приватном `$D/page.txt` (0600). Настройки шлюза не править.

```bash
rc=0
if test -f "$D/page.txt"; then
  sudo python3 -I "$H" --state "$D/result.json" --page-file "$D/page.txt" || rc=$?
else
  sudo python3 -I "$H" --state "$D/result.json" || rc=$?
fi
printf 'helper_rc=%s\n' "$rc"
sudo xgw diag --no-net >"$D/diag-after"
```

Исполнитель читает BROWSER, VIDEO, CHECK, OK, RESULT/STOP и сравнивает диагностику.
Firefox запускается без окна, после запуска закрывается, временный профиль удаляется.
Если открыт интерфейс XGW, исполнитель сам сверяет конечные статусы с Vision.
При штатной ротации посмотреть события пула за время прогона и записать только факт смены.
Не провоцировать ротацию и не ждать специально, пока она произойдёт. Если её не было,
отметить `NOT_RUN` для живого сценария ротации. Тест с подставной ротацией выполняется в §1.

## 3. Исход

- `CHECK xray_config_changed=1` вместе с `OK settings_processes_and_selected_path_same` — общий
  конфиг изменился, настройки, процессы и конфиг выбранного входа и его цепочки совпали.
  Ротацию указывать по журналу, если она там видна.
- `STOP selected_path_changed` — выбранный путь на контрольной точке изменился. При STOP
  сразу после Firefox повторный GET не выполняется. Если VIDEO уже есть, это неподтверждённое
  наблюдение. В обоих случаях BROWSER и собранные признаки остаются в квитанции.
- `STOP gateway_settings_or_processes_changed` или `gateway_snapshot_unavailable` — сравнение
  не подтверждено. Сохранить уже полученные строки и проверить конечное состояние шлюза.
- `RESULT browser_video_verified` — повторный GET через VPN получил HTTP 200/206, video/*
  и минимум 16 КиБ. Следующий отдельный эксперимент относится к прямому пути zapret2.
- `browser_url_missing`, `replay_failed` или `replay_not_video` — источник пробы не подтверждён.
  Сохранить playback, HTTP, объём и video_mime. При playback=1 полезно разобрать сетевой
  запрос браузера отдельно. При отказе плеера или браузера записать точный результат.

Отметить конечные capture, zapret2 и диагностику. Без запуска direct или selective.
Сверка конфигурации выбранного пути делается на контрольных точках. Публичный IP не измеряется.

## 4. Автоматическая публикация отчёта

После завершения, включая FAIL, STOP и NOT_RUN, исполнитель сам оформляет одну страницу
`docs/TEST-REPORT-REAL-MACHINE-0.2.0-video-probe-browser-r2-ДАТА.md` и публикует в `freepool`.
В отчёте указать CODE, суммы, выполненные тесты, согласованный объём прогона, BROWSER/VIDEO/CHECK,
RESULT/STOP, живую ротацию или NOT_RUN, конечные режимы и диагностику до и после.
Проверить текст на секреты. Использовать отдельное рабочее дерево от свежей `origin/freepool`,
добавить в коммит только отчёт, проверить `git diff --cached --check`, сделать обычный push
в `freepool` и сверить файл на GitHub. При гонке перенести свой коммит отчёта на свежую
ветку и повторить push без force. Отдельное подтверждение публикации отчёта не требуется.
В ответе указать хеш и ссылку. При невозможности push сохранить отчёт и сообщить причину.
