## Дефекты

1. **Пульт по Wi-Fi с включённым VPN телефона не работает (шаг 4.2).** На экране «Нет
   связи со шлюзом (Failed to connect to /127.0.0.1:17821). Если на телефоне включён
   другой VPN, выключите его: через VPN шлюз недоступен», «Состояние на …» не
   обновляется; повтор через 30 с — тот же результат. При этом сам VPN работает (страна
   PL), по мобильной сети пульт работает (шаг 4.4). Судя по тексту, не поднялся запасной
   путь пульта через VPN телефона (локальный прокси 127.0.0.1:17821), а прямой путь к
   *.ts.net из домашней Wi-Fi — не дошёл; подсказка про «другой VPN» в этой ситуации
   вводит в заблуждение (другого VPN нет). Дефект 1 отчёта А3 исправлен частично.

- Кнопка включения VPN на короткое время показывала «Подождите…» (приложение получало
  данные со шлюза) — нажатие в это время не срабатывает, через несколько секунд —
  нормально.
- Страна выхода через узел (PL) совпала со страной выхода самой машины через тот же

  предыдущем испытании): телефон через выходной узел выглядит в интернете как устройства
  дома, «не RU» — требование шага выполнено.
- DNS-проба edns.ip-api.com с телефона дважды дала «НЕТ ОТВЕТА» — записано как есть;
  сделать вывод о стране DNS-сервера не удалось.
- Консоль Tailscale при первом заходе выдавала ошибку «unable to load user on response»
  (телефон и инкогнито), одобрение «Use as exit node» получилось после повторного входа
  с компьютера — к коду XGW отношения не имеет, записано для полноты.

  настройки нет; передать авторам.
