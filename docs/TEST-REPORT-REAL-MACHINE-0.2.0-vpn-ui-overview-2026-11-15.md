## Записанные несовместимости с установленным backend (gui-light)

1. **Карточка zapret2 отсутствует в /api/state** — окно показывает «Нет данных», страница zapret2
   сообщает «нужны данные новой панели». По ТЗ §3.3 это корректное поведение; подмена backend
   не выполнялась. Таблица §4 подтверждает: когда контракт появится, подписи точны.
2. **endpoint_country в строке сервера отсутствует** — карта не может определить страну
   действующего сервера и честно остаётся в виде по умолчанию без выдуманной отметки
   (`map_country()` возвращает пусто). Пульс карты — только в состоянии CONNECTING
   (наблюдался при запуске окна, останавливается в CONNECTED — по коду карты так и задумано).
   Для полной проверки «пульс на стране действующего сервера» нужен backend с этим полем.
