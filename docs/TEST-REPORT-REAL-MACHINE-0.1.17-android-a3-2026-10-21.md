# Отчёт А3: VPN телефона в приложении (ветка android-a3)

Код: 79134a1. APK: android/apk/XGW-0.1.17-a3.apk, sha256 9b965011 — совпал. Телефон:
SM-S938B (Galaxy S25 Ultra), Android 17. Согласие заказчика: пункты 1–7 (1–3 — да;
4, 5, 6 — выбраны все; 7 — «оставить VPN телефона включённым»).

## Итог

Приложение обновилось поверх А2 с сохранением привязки (Success, 0.1.17-a3), список
серверов пришёл со шлюза (4 сервера). VPN телефона включается, Xray в приложении работает,
интерфейс tun0, страна выхода меняется AE → PL (сервер VPN телефона), сайты открываются
со скоростью «нормальной» по отзыву заказчика. Три дефекта: пульт шлюза не работает при
включённом VPN телефона («Нет связи со шлюзом (connection closed)», состояние не
обновляется — и по Wi-Fi, и по мобильной сети); VPN умер при первом переходе Wi-Fi →
мобильная сеть (Xray остановился, страна RU), повторные переходы пережил; уведомления
«VPN XGW» в шторке нет — выключить из уведомления невозможно, кнопкой в приложении
выключается. «Постоянная VPN» включилась сама и подняла VPN после перезагрузки телефона.
Падений приложения — 0, шлюз всё испытание HEALTHY и не менялся.

## Дефекты

1. **Пульт шлюза не работает при включённом VPN телефона.** На экране «Нет связи со
   шлюзом (connection closed)», «Состояние на ЧЧ:ММ:СС» не обновляется (по Wi-Fi зависло
   на 21:42:44, по мобильной сети — на 21:51:33). Воспроизводится и по Wi-Fi (5.5), и по
   мобильной сети (6.3). При этом сам VPN работает (страна PL), интернет на телефоне есть,
   приложение по uid-правилам «мимо своего VPN: да». После выключения VPN телефона
   признак не проверялся программой шагов (в 8.1 экран пульта не смотрели), пульт
   восстанавливался при следующем включении VPN (одно обновление состояния), затем снова
   терялся.
2. **VPN телефона не пережил первое выключение Wi-Fi (6.1).** При переходе Wi-Fi →
   мобильная сеть Xray в приложении остановился, интерфейс исчез, страна выхода RU
   (ожидалось PL). Приложение показало «VPN телефона выключен». Повторные переходы того
   же направления (7.2) и обратный (7.1) VPN пережил — сбой разовый, но воспроизвёлся.
3. **Уведомления «VPN XGW: Включён: серверов N» в шторке нет (8.1).** Выключить VPN из
   уведомления невозможно. Кнопкой в приложении VPN выключается корректно (Xray
   останавливается, интерфейс исчезает).

## Наблюдения

- Окно разрешения на уведомления (5.2) не показывалось вовсе — возможная причина дефекта 3:
  разрешение могло не быть выдано.
- До VPN по домашнему Wi-Fi страна выхода телефона AE — сервер шлюза (основной ОАЭ);
  с VPN телефона — PL: VPN телефона выбирает другой сервер из списка шлюза.
- Без VPN по мобильной сети страна ZZ=RU — страна заказчика; ZZ ≠ YY, сервер VPN в другой
  стране.
- Повторное включение VPN (6.3, после остановки) — без окна разрешения Android, как
  задумано.
- В 5.1 до включения VPN проверка «приложение XGW мимо своего VPN» показала «НЕТ» —
  артефакт эвристики uid-правил при выключенном VPN (записано как есть).
- «Постоянная VPN»: Android включил VPN без открытия приложения (9.2) и поднял его сам
  после перезагрузки (9.3, страна PL) — работает как задумано.

## Что не проверено и почему

- Ничего из согласованных пунктов не пропущено. Шаг 6.2 («минута без VPN», отдельное
  выключение кнопкой) выполнен данными шага 6.1: VPN уже был выключен дефектом 2, страна
  без VPN (RU) измерена дважды; нажимать кнопку выключения не было чего.
- Проверка «пульт восстанавливается после выключения VPN телефона» не предусмотрена
  шагами — не проверялось.
