# ThinkCentre. vpn_ui: окно VPN-клиента по дизайн-бандлу Proton — проверка на экране

CODE `5551ad708804c229339e067f497654d23bddb882`. Версия 0.2.0, freepool, GLM-5.3-Flash с root и Vision.
Пакет `vpn_ui/` — отдельный прототип окна (ASSUMPTIONS п. 390, описание — `vpn_ui/README.md`).
Он запускается из рабочей копии, в систему не ставится и ничего не меняет: демон, панель,
Xray, sing-box, правила сети и настройки не трогаются. Окно работает с имитацией бэкенда;
адреса в нём учебные (203.0.113.24 и 198.51.100.17) — в отчёт их писать можно.
Здесь проверено только в контейнере под PyQt6 без экрана; настоящий экран, шрифты, оконный
менеджер и PySide6 — этим ТЗ.

## 1. Исполнитель и подготовка

Исполнитель сам выполняет команды и смотрит окно через Vision; нет доступа — запросить и
продолжить самому, владельца запускать команды не просить. Отчёт публикуется автоматически.
Git и окно — от пользователя графической сессии, root не нужен. Окно XGW (`xgw gui`), значок
в трее и службы не трогать. Снимки экрана в Git не отправлять.

```bash
set -euo pipefail
cd "${XGW_REPO:-$HOME/xgw}"
test -z "$(git status --porcelain)"
git fetch origin freepool
CODE=5551ad708804c229339e067f497654d23bddb882
git merge-base --is-ancestor "$CODE" origin/freepool
umask 077
D=$(mktemp -d "$HOME/xgw-vpn-ui.XXXXXXXX")
git worktree add --detach "$D/new" "$CODE"
cd "$D/new"
test "$(find vpn_ui -name '*.py' | wc -l)" = 23 && echo OK files
python3 -V
for b in PySide6 PyQt6; do
    python3 -c "import $b.QtSvg, $b.QtWidgets" 2>/dev/null && echo "OK binding $b" || echo "NO $b"
done
echo "session=${XDG_SESSION_TYPE:-?} desktop=${XDG_CURRENT_DESKTOP:-?}"
systemctl show xgw.service -p MainPID
date -u +%FT%TZ
```

Нужна хотя бы одна строка `OK binding`. Обе `NO` — причина почти наверняка в модуле QtSvg:
разрешена одна установка `sudo apt-get install -y python3-pyqt6.qtsvg` (владелец согласен),
затем повторить цикл. Не помогло — `STOP no_qt`, в отчёт — текст ошибки импорта.
PySide6 отдельно не ставить: если её нет, прогон идёт под PyQt6, это записать.
Записать MainPID демона: в конце он должен совпасть.

## 2. Сверка вёрстки без экрана и на экране

```bash
QT_QPA_PLATFORM=offscreen python3 vpn_ui/verify_layout.py --out "$D/r-dark" | tee "$D/v-dark.txt"
QT_QPA_PLATFORM=offscreen python3 vpn_ui/verify_layout.py --out "$D/r-light" --theme light | tail -7
python3 vpn_ui/verify_layout.py --out "$D/r-screen" --scale 1 | tee "$D/v-screen.txt"
```

Третья команда — из графической сессии: окно на 2–3 секунды появится на экране и закроется.
Ожидается в каждой `VERIFY_LAYOUT=PASS` и пять строк `RESULT …=PASS`. `FAIL` — не остановка:
в отчёт — все строки `FAIL` дословно и строки `RESULT`. Из первого вывода записать строку
`binding=… platform=… scale=…`.

Открыть четыре снимка из `$D/r-dark` и четыре из `$D/r-screen`, по каждому — одно предложение:
1. `state_01_disconnected.png` — три зоны; сверху красноватое свечение; «Самый быстрый
   сервер», кнопка «Подключить» фиолетовая; внизу «Не защищено» красным и три ячейки.
2. `state_02_connecting.png` — свечение белёсое, кнопка «Отмена», «Подключение…» с кольцом.
3. `state_03_connected_with_traffic.png` — свечение бирюзовое, флаг и «Нидерланды», кнопка
   «Отключить», «Защищено» зелёным, четыре ячейки и график с двумя линиями и шкалой.
4. `state_04_settings_open.png` — справа панель «Настройки»: протоколы, переключатели;
   остальное окно затемнено.
Отдельно записать: отличается ли шрифт и чёткость на `r-screen` от `r-dark`; видны ли на
карте границы стран; не обрезаны ли подписи плиток справа.

## 3. Живое окно с имитацией бэкенда

Из графической сессии: `python3 vpn_ui/main_demo.py --demo` (консоль не закрывать — в неё
окно печатает строки `[demo] …`). По каждому пункту — PASS/FAIL и одно предложение.

1. Окно открылось не дольше чем за 3 с; системной рамки нет, своя шапка: «⋮», щит,
   «XGW VPN», справа свернуть, развернуть, закрыть. Записать строку `[demo] привязка Qt: …`.
2. Слева панель: поиск, «Страны / Профили / Шлюзы» с подсказками ctrl + 2/3/4, фильтры,
   карточка «Подписка: …», «Страны (14)», «Самый быстрый сервер», страны с флагами.
   В центре карта и карточка, справа четыре плитки и «Настройки». Ничего не обрезано
   и не налезает; при открытии ни на чём нет рамки фокуса.
3. Без подключения: «Не защищено» красным с открытым замком; внизу «Ваш IP-адрес
   203.0.113.24», «Страна Россия», «Провайдер …»; на карте красная точка.
4. «Подключить»: около 1,5 с «Подключение…» с вращающимся кольцом, кнопка «Отмена»,
   на карте расходится кольцо; затем «Защищено», свечение бирюзовое, в заголовке страна
   с флагом, кнопка «Отключить». Смена цвета свечения плавная, без мигания.
5. Подключено: ячейки «IP-адрес VPN 198.51.100.17», «Задержка», «Протокол», «Объём»;
   график сдвигается раз в секунду, числа скорости меняются, «Объём» растёт. Наблюдать 20 с.
6. «Отключить» возвращает вид п. 3. «Подключить» и сразу «Отмена» — тоже, без «Защищено».
7. Щелчок по названию страны подключает к ней: заголовок карточки — эта страна, карта
   плавно переезжает, строка выделена цветом. Щелчок по стрелке справа в строке раскрывает
   серверы страны с задержкой «NN мс»; щелчок по серверу подключает к нему.
8. Ctrl+F ставит курсор в поиск; «гер» оставляет Германию с её серверами; после очистки
   список полный. «Быстрые», «P2P», «Стриминг» меняют число в «Страны (N)».
9. Ctrl+3 и Ctrl+4 открывают «Профили» и «Шлюзы» (строки без флагов). Профиль «Недоступный
   сервер (проверка ошибки)»: через 1,5 с «Ошибка подключения» жёлтым, под кнопкой плашка
   с текстом, кнопка «Повторить», свечение жёлтое.
10. Щелчок по плитке «Kill switch» меняет её картинку; в «Настройках» переключатель
    «Kill switch» в том же положении. Переключить в настройках — плитка меняется следом.
11. «Настройки»: панель выезжает справа, фон затемнён; закрывается крестиком, клавишей Esc
    и щелчком по затемнению. Переключатель двигается плавно. «Свой DNS-сервер» открывает
    поле адреса. Выбор протокола печатает в консоли `[demo] протокол: …`, выбор «Что идёт
    через VPN» — `[demo] настройки: …`. Выпадающие списки читаются, стрелка у них видна.
12. «⋮» → «Светлая тема»: всё окно светлое, текст и иконки читаются, карта видна.
    «⋮» → «Тёмная тема» возвращает прежний вид.
13. Окно перетаскивается за шапку; двойной щелчок по шапке разворачивает и возвращает;
    размер меняется за правый край, нижний край и правый нижний угол; «свернуть» и
    «закрыть» работают. Что из этого не сработало — записать вместе с типом сеанса.
14. Сузить окно: примерно уже 1000 точек правая панель остаётся без подписей; уже 885 —
    левая панель превращается в полоску значков. Щелчок по значку раскрывает панель поверх
    карты, Esc сворачивает. Меньше 566×609 окно не становится. Вернуть широкое окно —
    раскладка прежняя.
15. Закрыть окно и запустить `python3 vpn_ui/main_demo.py --demo --native-titlebar`:
    рамка системная, своих кнопок окна нет, «⋮» слева осталась и открывает меню.
16. Нагрузка (окно из п. 15 или обычное, открыто и на виду):

    ```bash
    P=$(pgrep -f 'vpn_ui/main_demo.py' | head -1)
    t() { awk '{print $14+$15}' "/proc/$P/stat"; }
    a=$(t); sleep 30; echo "idle_ticks=$(( $(t) - a ))"
    ```

    Первый замер — без подключения, второй — через 10 с после «Подключить». Ожидается:
    без подключения не больше 60 тиков за 30 с, с подключением не больше 300.
17. Свободным текстом, до 12 строк: что выглядит плохо, криво или непривычно для Ubuntu;
    где текст мелкий или малоконтрастный; что мешало пользоваться окном.

## 4. Итог и уборка

Закрыть окно кнопкой закрытия; убедиться, что процесса `main_demo.py` нет (массовые
pkill/killall не применять). `systemctl show xgw.service -p MainPID` — как в §1.

```bash
cd "${XGW_REPO:-$HOME/xgw}"
git worktree remove --force "$D/new"
rm -rf -- "$D"
```

Снимки из `$D` в Git не попадают и удаляются вместе с каталогом. Пакет, установленный
в §1 (если ставился), оставить и назвать в отчёте.
