# ThinkCentre. Источник свежей видеопробы

CODE `c6212f8140edcf2280feafe413bc37a708028082`, база `7377c01`. Исполнитель GLM-5.3-Flash.
Цель — проверить, отдаёт ли настроенная страница готовую ссылку, которую можно использовать
для видеопробы. Эксперимент выполняется через VPN. Код на шлюз не устанавливается.
Не менять службы, маршруты, VPN, pin, пул, подписки, WAN/LAN/Tailscale, настройки и браузер.
Никаких скачиваний программ, cookie, авторизации YouTube или обхода запросов входа.
В отчёт не попадают URL, подписи, домены, имена серверов, сырые статусы и страницы.

## 2. Один запуск по согласию владельца

Получить согласие на два запроса через один живой VPN-сервер, расход до 3 МиБ, до 8 с на запрос.
Запускается один раз. Помощник создаёт приватную квитанцию с O_EXCL, повтор с ней запрещён.
Проба использует youtube_sign_url или первый подходящий watch-адрес из zapret2.probe_urls.
Если такого адреса нет, владелец задаёт HTTPS watch-адрес приватно файлом `$D/page.txt`,
режим 0600, одна строка. Это настройка эксперимента. config.toml и panel.json не менять.
Адреса по умолчанию из интернета не подставлять. Нужен публичный ролик, выбранный владельцем.

Без дополнительного файла выполнить:

```bash
sudo python3 -I "$H" --state "$D/result.json"
```

Если файл подготовлен владельцем заранее, вместо этого выполнить единственный запуск:

```bash
sudo python3 -I "$H" --state "$D/result.json" --page-file "$D/page.txt"
```

Не выполнять оба варианта. При NOT_RUN отсутствующего адреса сетевых запросов ещё не было,
квитанция не создана; допустим один запуск после заполнения файла владельцем.

Помощник проверяет свежий статус, off, VPN и живого участника, читает его служебный вход.
Страница и видео идут через один выход, один User-Agent, без cookie. Перенаправления не проходят.
Ответ страницы читается до 2 МиБ, JSON и gzip ограничены. Разбираются только готовые video URL,
HTTPS выбранной видеосети, с expire от 5 минут до суток. JS, cipher, токены не генерируются.
Видео проверяется до 64 КиБ, успех — 2xx и минимум 16 КиБ. Найденная ссылка не записывается.
Сохраняется только сводка, шлюз и настройки после сверяются с исходными.

## 3. Решение по исходу

| Результат | Значение и следующий шаг разработчика |
|---|---|
| fresh_video_verified | Свежая ссылка загрузилась через VPN. Подготовить отдельный эксперимент получения и проверки через zapret2 с одним домашним IP. Автоматический маршрут ещё не включать. |
| player_missing / player_invalid / streams_missing | Эта страница не дала пригодных данных. Проверять получение ссылки штатным браузером, без добавления эвристик вслепую. |
| player_not_ready | Плеер не подтвердил доступность. Не считать отказом ТСПУ; дальнейший разбор отдельно. |
| cipher_required / direct_video_missing | Готового подходящего URL нет. Простой разбор непригоден для этого случая; следующий вариант — браузер. |
| page_failed / video_failed | Зафиксировать HTTP/объём и причину, не считать путь рабочим. Повторный круг в этом ТЗ не запускать. |
| NOT_RUN | Нет адреса, живого входа или инструментов. Не менять сеть ради выполнения. |
| STOP | Сверка состояния не прошла или ошибка выполнения. Сохранить причину приватно, остановиться. |

Никакой исход автоматически не включает zapret2. Успех не доказывает воспроизведение или прямой
путь, отсутствие готового URL не означает поломку шлюза. Нужен результат именно этой машины.

```bash
sudo xgw diag --no-net >"$D/diag-after"
```

Сверить отсутствие новых FAIL. При штатной смене конфигурации или PID помощник даст STOP,
выяснить причину приватно; не приписывать её эксперименту автоматически. Настройки не менялись,
откат не требуется. Приватный файл страницы и квитанцию не отправлять в Git.
