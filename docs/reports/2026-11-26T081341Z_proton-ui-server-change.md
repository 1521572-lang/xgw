## Наблюдения для Codex

1. **Диалог смены соответствует ТЗ на кандидате `179d63a3`**: при живом
   ручном закреплении появляется предупреждение о замене и возврате к
   автовыбору после срока; «Отмена» физически ничего не отправляет
   (pin-запись не перезаписывается — совпал даже `since`). Повторная
   валидация условий перед отправкой (замена сервера/мёртвый диалог)
   присутствует в коде, в живом прогоне не активировалась.
2. **Кнопка «Выбрать сервер» активна только при выбранной строке**, а
   список и поиск ограничены выбранным источником в «Подписках»; смена
   источника очищает поисковый запрос. Чтобы найти сервер другой страны,
   нужно сначала выбрать источник подписки — для сценария ТЗ стоит
   учитывать этот шаг (или подсказывать его в пустом результате поиска).
3. **Сценарий смены готов к повтору тем же чек-листом** (диалог+отмена
   уже зелёные, цель определена, возврат и CLI-резерв проверены) —
   нужно только согласованное окно.
4. **Harness-замечание:** диалог QMessageBox — отдельное X-окно
   («Выбрать сервер — XGW»), скриншот только главного окна его не
   показывает; при приёмке снимать весь экран или искать окно по имени.
   Отдельное: длительное ожидание ответа на вопрос окна укладывает
   дисплей в DPMS и блокирует сеанс — для живых окон лучше стартовать
   сразу после подтверждения.
