# Следующая проверка Flash на ThinkCentre

На **Ubuntu 24.04 LTS** проверь запуск читателя из `ca7bc7a`.
Временная панель поднимает IPC через штатный `Panel.start()`.
Первый авторизованный запрос запускает reader через systemd.
Сценарий проверяет восстановление IPC, повторный запуск reader
и очистку временной пары служб.
[Готовое ТЗ](PANEL-READ-SERVICE-2026-11-21.md)

В P2.4 на ThinkCentre прошли 97 тестов. Подтверждены штатная
cookie на доверенном входе, одноразовый допуск и IPC v2. Снимок
совпал со штатной панелью, восстановление 503→200 прошло.
Живая ротация Selective ждёт успешного прямого допуска.
[Последний отчёт](../reports/2026-11-21T162144Z_panel-read-session.md)

Код и команды подготовлены Codex. Flash сама запускает проверку,
запрашивает доступ при необходимости и публикует один обезличенный
отчёт при любом исходе в `integration/zapret2-batch1`.
